# 算法模式诊断清单 (Pattern Checklist)

> **用途**: 拿到算法题后的系统化诊断流程。逐步排除，精准定位算法类型。

---

## 第一步：约束分析 (必做)

- [ ] **n 的范围** → 确定时间复杂度上界 (见 route-matrix.md §二)
- [ ] **空间限制** → 256MB ≈ 3×10^7 个 Int64，512MB ≈ 6×10^7
- [ ] **多组测试?** → 总量累加不超限
- [ ] **离线/在线?** → 离线可排序、莫队；在线需数据结构

---

## 第二步：目标类型识别

### 🎯 求最值 (Optimization)
- [ ] 能否贪心？贪心策略能否证明？(交换论证/反证)
- [ ] 满足最优子结构？→ DP
- [ ] 答案有单调性？→ 二分答案
- [ ] 图上最值？→ 最短路 / 最小生成树 / 网络流

### 🔢 求计数 (Counting)
- [ ] 组合数学公式可直接求？
- [ ] 满足转移方程？→ DP
- [ ] 容斥原理？
- [ ] 生成函数/多项式？(极少见)

### ✅ 判定 (Decision)
- [ ] 二分判定？(能否将判定转化为 check 函数)
- [ ] 图连通性？→ 并查集 / BFS
- [ ] 博弈?  → SG函数 / 找规律

### 🏗️ 构造 (Construction)
- [ ] 贪心构造？
- [ ] 归纳构造？(从小到大)
- [ ] 图论构造？(度序列、欧拉回路)

---

## 第三步：数据关系诊断

### 📊 线性序列
| 特征 | 算法 |
|------|------|
| 区间查询/修改 | 线段树 / 树状数组 |
| 前缀关系 | 前缀和 / 差分 |
| 单调性利用 | 单调栈 / 单调队列 |
| 子序列最值 | DP (LIS / LCS) |
| 局部最优 → 全局最优 | 贪心 + 排序 |
| 固定长度滑窗 | 双指针 / 单调队列 |
| 可变长度滑窗 | 双指针 + 条件 |

### 🌲 树
| 特征 | 算法 |
|------|------|
| 节点赋值统计 | 树形 DP |
| 最近公共祖先 | LCA 倍增 |
| 路径修改/查询 | 树链剖分 (HLD) |
| 子树查询 | DFS 序 + BIT/线段树 |
| 两点距离 | LCA: dist = dep[u]+dep[v]-2*dep[lca] |
| 换根 | 换根 DP (两遍 DFS) |
| 树的直径 | 两次 BFS 或 树形DP |
| 虚树 | DFS序 + 栈构造 |

### 📈 图
| 特征 | 算法 |
|------|------|
| 最短路 (非负权) | Dijkstra |
| 最短路 (负权/判负环) | Bellman-Ford / SPFA |
| 全源最短路 (n≤500) | Floyd |
| 连通分量 | 并查集 / DFS |
| 强连通分量 | Tarjan / Kosaraju |
| 拓扑排序 | 入度 BFS (Kahn) |
| 最小生成树 | Kruskal (排序+DSU) |
| 二分图匹配 | 匈牙利 / Hopcroft-Karp |
| 最大流 | Dinic / ISAP |
| 最小割 | = 最大流 (最大流最小割定理) |
| 欧拉路径/回路 | Hierholzer |

### 🔤 字符串
| 特征 | 算法 |
|------|------|
| 模式匹配 | KMP |
| 多模式匹配 | AC自动机 |
| 最长回文 | Manacher |
| 所有子串相关 | 后缀数组 / 后缀自动机 |
| 前缀匹配集合 | Trie |
| 子串哈希判等 | 字符串哈希 (滚动) |

### 🔢 数论
| 特征 | 算法 |
|------|------|
| 取模、a^b mod p | 快速幂 |
| 模逆元 | 费马小定理 (p 为质数) / exGCD |
| 组合数 C(n,k) mod p | 预处理阶乘 + 逆元 |
| 素数判断/枚举 | 线性筛 (欧拉筛) |
| GCD / LCM | std.math.gcd / lcm |
| 递推有矩阵形式 | 矩阵快速幂 |
| 中国剩余定理 | CRT / exCRT |

## 第四步：优化手段检查

- [ ] **可离线?** → 莫队 (O(n√n))、CDQ分治、离线并查集
- [ ] **存在单调性?** → 单调栈/单调队列优化、斜率优化 DP
- [ ] **可二分?** → 二分答案 + check
- [ ] **状态可压缩?** → n ≤ 20 时状压 DP
- [ ] **树上可拆分?** → 点分治、树链剖分
- [ ] **可分块?** → 分块 O(n√n)
- [ ] **转化为经典问题?** → 逆序对(归并排序/BIT)、偏序(CDQ)

---

## 第五步：反例驱动修正

写出算法后，必须验证以下 case:

| 类别 | 必测用例 |
|------|---------|
| 最小 | n=0, n=1, 单元素 |
| 边界 | n=max, 全相同值, 全逆序 |
| 特殊 | 负数, 0, Int64 溢出, 空图, 自环, 重边 |
| 树 | 链 (退化), 菊花图, 完全二叉树 |
| 字符串 | 空串, 单字符, 全同字符 |
| 卡常 | n=10^5 时实际运行是否超时 |

## 第六步：复杂度确认模板

```
Time:  O(?)  — 主操作 × 每次代价
Space: O(?)  — 主数组大小
证明:  [一句话论证为何不会退化]
```

## 速查：常见错误

| 错误 | 修复 |
|------|------|
| 忘记 `import std.convert.*` | `Int64.parse()` 需要此包 |
| 数组越界无提示 | 仓颉数组越界会 panic，检查边界 |
| HashMap 找不到键 | 用 `get(k)` 返回 `Option`，非 `[]` |
| TreeMap 空时调 first/last | 先 `isEmpty()` 检查 |
| 整数溢出 | 用 `std.overflow` 或转 `Int128` 思路 |
| sort 不稳定 | 默认 `sort` 可能不稳定，需要稳定用 `stableSort` |
| readln 末尾空格 | `trim()` 处理 |
| 邻接表忘记双向 | 无向图必须 `add(u,v)` 和 `add(v,u)` |
