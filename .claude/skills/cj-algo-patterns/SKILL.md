# Algorithm Patterns

## 必读参考
- **算法模板库**: `references/algorithm-templates.md` — 30+ 仓颉完整算法实现，可直接使用
- **诊断清单**: `references/pattern-checklist.md` — 六步系统化诊断流程

## 使用目标
在 2-5 分钟内完成：题目诊断 → 算法选型 → 取模板 → 修改提交

本 Skill 只解决“选什么算法、为什么这样选、模板从哪里取”。仓颉代码语法和 import 问题交给 `cj-language-core`，答案组织交给 `cj-ice-contest-protocol`。

## 诊断六步法 (详见 pattern-checklist.md)
1. **约束分析** — n 范围 → O(?) 上界
2. **目标类型** — 最值/计数/判定/构造
3. **数据关系** — 线性/树/图/字符串/数论
4. **优化手段** — 离线/单调/二分/状压/分治
5. **反例验证** — 最小/边界/特殊/退化
6. **复杂度确认** — Time + Space + 论证

## 模板库使用流程
```
1. 诊断确定算法类型 (如 "Dijkstra 最短路")
2. 在 algorithm-templates.md 中找到对应节 (§2.4 Dijkstra)
3. 复制完整模板代码
4. 修改: I/O格式 + 变量名 + 题目特定逻辑
5. 验证: 边界 case + 复杂度一致性
```

## 算法选型决策 (快速版)

### 求最值?
- 贪心可证? → 贪心
- 有最优子结构? → DP
- 答案有单调性? → 二分答案
- 图上? → 最短路/MST

### 求计数?
- 转移方程? → DP
- 组合公式? → 组合数学
- 容斥? → 容斥原理

### 图论?
- 最短路 → Dijkstra (正权) / Bellman-Ford (负权) / Floyd (全源, n≤500)
- 连通 → DSU / DFS
- 拓扑序 → Kahn BFS
- MST → Kruskal
- SCC → Tarjan

### DP 类型?
- 线性序列 → 线性 DP
- 树 → 树形 DP
- 区间合并 → 区间 DP
- 数字每一位 → 数位 DP
- n≤20 → 状压 DP
- 背包 → 01/完全/多重

## 常见误区
| 误区 | 修正 |
|------|------|
| 忽略常数 → TLE | n=10^5 时 O(n log²n) 可能勉强 |
| 不稳定排序用在需要稳定的场景 | 用 stableSort |
| 只给直觉不写不变量 | 必须有形式化论证 |
| 暴力超时但没想到优化 | 先写暴力对拍 |
| 忘记初始化 DP 数组 | 确认初始值 (0? INF? -INF?) |
| 图的边数估算错误 | 无向图: 2m 条有向边 |

## 输出要求
1. 暴力基线 + 瓶颈分析
2. 主方案 + 复杂度论证
3. 备选方案 (主方案失效时)
4. 仓颉代码从 algorithm-templates.md 取模板
