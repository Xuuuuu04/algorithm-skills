# 思路

**核心算法**: Dinic 最大流 — 分层图增广

**关键 insight**: Dinic 通过 BFS 建分层图 + DFS 阻塞流增广，比 EK 算法更快。
每轮 BFS 后层次增加，最多 V-1 轮终止。

**步骤**:
1. 建立邻接表，成对加正向/反向边
2. BFS 从 s 出发标记 level[]
3. DFS 从 s 沿 level 递增方向找增广路
4. 重复直到 BFS 无法到达 t

---

# 复杂度

- **时间复杂度**: O(V^2 × E) — 通用图; O(E√V) — 单位容量图
- **空间复杂度**: O(V + E)

**变量定义**: V = 顶点数, E = 边数

---

# 正确性要点

**方法**: 分层图阻塞流

- **BFS 层次**: 保证增广路最短，每轮至少增加 1 层
- **当前弧优化**: iter[u] 跳过已饱和边，避免重复搜索
- **多路增广**: 一轮 DFS 内找多条增广路
- **终止**: level[t] 不可达时已达最大流

# 仓颉实现

```cangjie
import std.collection.*
import std.math.*

main() {
    let line1 = readln().split(" ")
    let n = Int64.parse(line1[0])
    let m = Int64.parse(line1[1])
    let s = Int64.parse(line1[2])
    let t = Int64.parse(line1[3])

    let head = Array<Int64>(n, {_ => -1})
    let to = ArrayList<Int64>()
    let cap = ArrayList<Int64>()
    let nxt = ArrayList<Int64>()

    var i: Int64 = 0
    while (i < m) {
        let parts = readln().split(" ")
        let u = Int64.parse(parts[0])
        let v = Int64.parse(parts[1])
        let c = Int64.parse(parts[2])
        to.add(v); cap.add(c); nxt.add(head[u]); head[u] = to.size - 1
        to.add(u); cap.add(0); nxt.add(head[v]); head[v] = to.size - 1
        i++
    }

    let INF: Int64 = 0x3f3f3f3f3f3f3f3f
    let level = Array<Int64>(n, {_ => -1})
    let iter = Array<Int64>(n, {_ => 0})

    func bfs(): Bool {
        var j: Int64 = 0
        while (j < n) { level[j] = -1; j++ }
        level[s] = 0
        let q = ArrayList<Int64>(); q.add(s)
        var qi: Int64 = 0
        while (qi < q.size) {
            let v = q[qi]; qi++
            var e = head[v]
            while (e != -1) {
                if (cap[e] > 0 && level[to[e]] < 0) { level[to[e]] = level[v] + 1; q.add(to[e]) }
                e = nxt[e]
            }
        }
        return level[t] >= 0
    }

    func dfs(v: Int64, f: Int64): Int64 {
        if (v == t) { return f }
        while (iter[v] != -1) {
            let e = iter[v]
            if (cap[e] > 0 && level[to[e]] == level[v] + 1) {
                let d = dfs(to[e], min(f, cap[e]))
                if (d > 0) { cap[e] -= d; cap[e ^ 1] += d; return d }
            }
            iter[v] = nxt[e]
        }
        return 0
    }

    var flow: Int64 = 0
    while (bfs()) {
        i = 0
        while (i < n) { iter[i] = head[i]; i++ }
        var d = dfs(s, INF)
        while (d > 0) { flow += d; d = dfs(s, INF) }
    }
    println(flow)
}
```

**编译验证**: cjc 编译通过，6 节点图 s=0,t=5 输出最大流 19 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | 直连 s→t | cap | 单边 |
| 2 | 无路径 | 0 | BFS 不可达 |
| 3 | 平行边 | 容量和 | 多重边 |

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 边号不是从 0 成对 | 高 | 每次加边加两条，e^1 翻转 |
| 2 | 多路增广遗漏 | 中 | while(d>0) 循环 DFS |
| 3 | level/iter 未重置 | 中 | 每轮 BFS 前清 level，BFS 后设 iter |
