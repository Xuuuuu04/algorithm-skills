# 思路

**核心算法**: AC 自动机 (Aho-Corasick) 多模式串匹配

**关键 insight**: 在 Trie 上构建失配指针 (fail)，实现一次扫描文本即可匹配所有模式串。
时间与文本长度+模式总长线性相关。

**步骤**:
1. 将所有模式串插入 Trie，标记终止节点
2. BFS 构建 fail 指针：ch[u][c]=0 时补链 ch[fail[u]][c]
3. 扫描文本，沿 fail 链统计匹配数

---

# 复杂度

- **时间复杂度**: O(Σ|P_i| + |T| × ALPHA) — 建树 + 匹配
- **空间复杂度**: O(Σ|P_i| × ALPHA) — Trie 节点数 × 字符集

**变量定义**: |P_i| = 第 i 个模式串长度, |T| = 文本长度, ALPHA = 字符集大小(26)

---

# 正确性要点

**方法**: 自动机理论

- **Trie 正确性**: 每个 insert 唯一路径对应一个模式串
- **fail 指针**: 保证未匹配时跳转到最长后缀，不遗漏匹配
- **补链优化**: ch[u][c]=0 → ch[fail[u]][c]，避免逐级回退

---

# 仓颉实现

```cangjie
import std.collection.*

main() {
    let ALPHA: Int64 = 26
    var sz: Int64 = 1
    let maxNodes: Int64 = 500010
    let ch = Array<Array<Int64>>(maxNodes, {_ => Array<Int64>(ALPHA, {_ => 0})})
    let fail = Array<Int64>(maxNodes, {_ => 0})
    let cnt = Array<Int64>(maxNodes, {_ => 0})

    let nPat = Int64.parse(readln())
    var p: Int64 = 0
    while (p < nPat) {
        let s = readln()
        var cur: Int64 = 0
        let bytes = s.toArray()
        for (b in bytes) {
            let c = Int64(b) - 97
            if (ch[cur][c] == 0) { ch[cur][c] = sz; sz++ }
            cur = ch[cur][c]
        }
        cnt[cur]++
        p++
    }

    // Build fail
    let q = ArrayList<Int64>()
    var c: Int64 = 0
    while (c < ALPHA) {
        if (ch[0][c] != 0) { q.add(ch[0][c]) }
        c++
    }
    var qi: Int64 = 0
    while (qi < q.size) {
        let u = q[qi]; qi++
        c = 0
        while (c < ALPHA) {
            if (ch[u][c] != 0) {
                fail[ch[u][c]] = ch[fail[u]][c]
                q.add(ch[u][c])
            } else {
                ch[u][c] = ch[fail[u]][c]
            }
            c++
        }
    }

    let text = readln()
    var cur: Int64 = 0
    var ans: Int64 = 0
    let tbytes = text.toArray()
    for (b in tbytes) {
        let cc = Int64(b) - 97
        cur = ch[cur][cc]
        var t = cur
        while (t != 0 && cnt[t] >= 0) {
            ans += cnt[t]
            cnt[t] = -1
            t = fail[t]
        }
    }
    println(ans)
}
```

**编译验证**: cjc 编译通过，模式 {he, she, his, hers}，文本 "ahishers" 输出 4 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | 0 个模式串 | 0 | 空 Trie |
| 2 | 单模式 = 全文本 | 1 | 完全匹配 |
| 3 | 模式串互为前缀 | 各自匹配 | fail 链正确性 |
| 4 | 文本无匹配 | 0 | 无匹配退出 |
| 5 | 10^5 模式 × 10^5 文本 | 性能 | 线性复杂度 |

---

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 节点数爆内存 | 中 | maxNodes = Σ|P_i|+1，或使用 HashMap 代替数组 |
| 2 | cnt 重复计数 | 低 | 匹配后标记 cnt[t]=-1 |
| 3 | 字符集不是小写 | 中 | 调整 ALPHA 和偏移量 |
