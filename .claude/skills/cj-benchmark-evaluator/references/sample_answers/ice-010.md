# 思路

**核心算法**: 重链剖分 (Heavy-Light Decomposition) + 树状数组

**关键 insight**: 将树分解为若干重链，每条链上节点 DFS 序连续。
路径查询/修改可拆为 O(log n) 段连续区间，配合数据结构 O(log n) 处理每段。

**步骤**:
1. DFS1: 求 sz[v], heavy[v] (重子节点), dep[v], par[v]
2. DFS2: 按"重子优先"赋 DFS 序 pos[v] 和链头 chainTop[v]
3. 路径查询: 沿 chainTop 上跳，每段用 BIT/SegTree 查区间

---

# 复杂度

- **时间复杂度**: O(n log^2 n) — 每次查询 O(log n) 段 × 每段 O(log n) BIT 查询
- **空间复杂度**: O(n)

**变量定义**: n = 树节点数

---

# 正确性要点

**方法**: 链剖性质保证

- **重链顶多 log n 条**: 从任意节点到根最多经过 O(log n) 条轻边
- **DFS 序连续**: 重链上节点序号连续，可直接用线段树/BIT
- **上跳正确**: 每次调 dep[chainTop] 较深的一方上跳

# 仓颉实现

```cangjie
import std.collection.*

main() {
    let n = Int64.parse(readln())
    let adj = ArrayList<ArrayList<Int64>>(n, {_ => ArrayList<Int64>()})
    var i: Int64 = 0
    while (i < n - 1) {
        let parts = readln().split(" ")
        let u = Int64.parse(parts[0]); let v = Int64.parse(parts[1])
        adj[u].add(v); adj[v].add(u); i++
    }
    let vals = readln().split(" ")
    let val = Array<Int64>(n, {i => Int64.parse(vals[i])})

    let par = Array<Int64>(n, {_ => -1})
    let dep = Array<Int64>(n, {_ => 0})
    let sz = Array<Int64>(n, {_ => 1})
    let heavy = Array<Int64>(n, {_ => -1})
    let pos = Array<Int64>(n, {_ => 0})
    let chainTop = Array<Int64>(n, {_ => 0})
    var timer: Int64 = 0

    // DFS1
    let stk = ArrayList<(Int64, Int64, Bool)>()
    stk.add((0, -1, false))
    while (!stk.isEmpty()) {
        let (u, p, done) = stk.remove(at: stk.size - 1)
        if (done) {
            var maxSz: Int64 = 0
            for (j in 0..adj[u].size) {
                let v = adj[u][j]
                if (v != p) { sz[u] += sz[v]; if (sz[v] > maxSz) { maxSz = sz[v]; heavy[u] = v } }
            }
        } else {
            par[u] = p; stk.add((u, p, true))
            for (j in 0..adj[u].size) {
                let v = adj[u][j]
                if (v != p) { dep[v] = dep[u] + 1; stk.add((v, u, false)) }
            }
        }
    }

    // DFS2
    let stk2 = ArrayList<(Int64, Int64)>()
    stk2.add((0, 0))
    while (!stk2.isEmpty()) {
        let (u, top) = stk2.remove(at: stk2.size - 1)
        chainTop[u] = top; pos[u] = timer; timer++
        for (j in 0..adj[u].size) {
            let v = adj[u][j]
            if (v != par[u] && v != heavy[u]) { stk2.add((v, v)) }
        }
        if (heavy[u] >= 0) { stk2.add((heavy[u], top)) }
    }

    // BIT
    let bit = Array<Int64>(n + 1, {_ => 0})
    func bitUpdate(idx: Int64, v: Int64): Unit {
        var x = idx + 1
        while (x <= n) { bit[x] += v; x += x & (-x) }
    }
    func bitQuery(idx: Int64): Int64 {
        var s: Int64 = 0; var x = idx + 1
        while (x > 0) { s += bit[x]; x -= x & (-x) }
        return s
    }
    func bitRange(l: Int64, r: Int64): Int64 {
        if (l == 0) { return bitQuery(r) }
        return bitQuery(r) - bitQuery(l - 1)
    }

    i = 0
    while (i < n) { bitUpdate(pos[i], val[i]); i++ }

    func pathSum(u0: Int64, v0: Int64): Int64 {
        var u = u0; var v = v0; var result: Int64 = 0
        while (chainTop[u] != chainTop[v]) {
            if (dep[chainTop[u]] < dep[chainTop[v]]) { let tmp = u; u = v; v = tmp }
            result += bitRange(pos[chainTop[u]], pos[u])
            u = par[chainTop[u]]
        }
        if (dep[u] > dep[v]) { let tmp = u; u = v; v = tmp }
        result += bitRange(pos[u], pos[v])
        return result
    }

    let q = Int64.parse(readln())
    i = 0
    while (i < q) {
        let parts = readln().split(" ")
        let u = Int64.parse(parts[0]); let v = Int64.parse(parts[1])
        println(pathSum(u, v))
        i++
    }
}
```

**编译验证**: cjc 编译通过，7 节点树 pathSum(3,6)=170, pathSum(3,4)=110 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | n=1 | val[0] | 单节点 |
| 2 | 链状树 | 路径 = 全求和 | 退化为线段 |
| 3 | 星型树 | 经过根 | 深度 1 |
| 4 | u=v | val[u] | 自环查询 |
| 5 | n=10^5, q=10^5 | 性能 | O(n log^2 n) |

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | DFS2 重子优先顺序 | 高 | 先加轻子，最后加重子到栈 |
| 2 | BIT 1-indexed 偏移 | 中 | bitUpdate/bitQuery 内 +1 |
| 3 | 上跳方向搞反 | 中 | 比较 dep[chainTop[]] 不是 dep[] |
