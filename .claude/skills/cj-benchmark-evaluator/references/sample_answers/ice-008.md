# 思路

**核心算法**: 数位 DP — 统计 [1,N] 中满足条件的数的个数

**关键 insight**: 按位枚举，维护 (pos, cnt, tight, started) 四个状态。
tight 控制上界约束，started 处理前导零。

**步骤**:
1. 将 N 分解为数字位 digits[]
2. 从高位到低位递归: solve(pos, cnt, tight, started)
3. 对每个位置枚举 0..limit，其中 limit = digits[pos] (tight) 或 9
4. 记忆化避免重复计算

---

# 复杂度

- **时间复杂度**: O(D × S × 2 × 2 × 10) — D=位数, S=状态值上界
- **空间复杂度**: O(D × S × 4) — 记忆化表

**变量定义**: D = log10(N)+1 位数, S = 计数状态上界

---

# 正确性要点

**方法**: 状态完备性

- **tight**: true 时当前位受限于 digits[pos]，false 时可取 0-9
- **started**: 处理前导零，避免将 "007" 中的零计入
- **无后效性**: (pos, cnt, tight, started) 唯一决定后续方案数

# 仓颉实现

```cangjie
import std.collection.*

main() {
    let N = Int64.parse(readln())

    let digits = ArrayList<Int64>()
    var tmp = N
    while (tmp > 0) { digits.add(tmp % 10); tmp /= 10 }
    digits.reverse()
    let n = digits.size

    let memo = HashMap<Int64, Int64>()

    func encode(pos: Int64, cnt: Int64, tight: Int64, started: Int64): Int64 {
        return pos * 1000000 + cnt * 100 + tight * 10 + started
    }

    func solve(pos: Int64, cnt: Int64, tight: Bool, started: Bool): Int64 {
        if (pos == n) { return cnt }
        let key = encode(pos, cnt, if (tight) { 1 } else { 0 }, if (started) { 1 } else { 0 })
        match (memo.get(key)) {
            case Some(v) => return v
            case None => ()
        }
        let limit = if (tight) { digits[pos] } else { 9 }
        var result: Int64 = 0
        var d: Int64 = 0
        while (d <= limit) {
            let newStarted = started || d > 0
            let newCnt = if (d == 1) { cnt + 1 } else { cnt }
            let newTight = tight && (d == limit)
            result += solve(pos + 1, newCnt, newTight, newStarted)
            d++
        }
        memo[key] = result
        return result
    }

    println(solve(0, 0, true, false))
}
```

**编译验证**: cjc 编译通过，N=13 输出 6 (数字 1 在 1~13 中出现 6 次) ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|

| 2 | N=1 | 1 | 最小非零 |

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 前导零计入统计 | 中 | started 状态区分 |
| 2 | 记忆化 key 冲突 | 低 | encode 保证唯一 |
| 3 | 区间 [L,R] 需差分 | 中 | f(R) - f(L-1) |
