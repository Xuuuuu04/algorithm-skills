# 思路

**核心算法**: 最大流 = 最小割 (Dinic 算法)

**关键 insight**: 最大流最小割定理：从 s 到 t 的最大流等于最小割容量。
Dinic 使用 BFS 分层 + DFS 增广，复杂度 O(V^2 × E)。

**步骤**:
1. 建立网络流图：邻接表 + 反向边（容量 0）
2. BFS 建分层图（level 数组）
3. DFS 多路增广（iter 数组避免重复搜索）
4. 重复 BFS+DFS 直到无增广路

---

# 复杂度

- **时间复杂度**: O(V^2 × E) — 最多 V 轮 BFS，每轮 DFS O(V×E)
- **空间复杂度**: O(V + E) — 邻接表 + level/iter 数组

**变量定义**: V = 顶点数, E = 边数

---

# 正确性要点

**方法**: 增广路定理

- **分层图**: BFS 保证最短增广路优先
- **阻塞流**: 每轮 DFS 找到阻塞流后层次增加
- **终止**: 最多 V-1 轮（层次递增到无法到达 t）
- **反向边**: 支持"退流"操作，保证最优性

# 仓颉实现

```cangjie
import std.collection.*
import std.math.*

main() {
    let line1 = readln().split(" ")
    let n = Int64.parse(line1[0])
    let m = Int64.parse(line1[1])
    let s = Int64.parse(line1[2])
    let t = Int64.parse(line1[3])

    let head = Array<Int64>(n, {_ => -1})
    let to = ArrayList<Int64>()
    let cap = ArrayList<Int64>()
    let nxt = ArrayList<Int64>()

    var i: Int64 = 0
    while (i < m) {
        let parts = readln().split(" ")
        let u = Int64.parse(parts[0])
        let v = Int64.parse(parts[1])
        let c = Int64.parse(parts[2])
        // 正向边
        to.add(v); cap.add(c); nxt.add(head[u]); head[u] = to.size - 1
        // 反向边
        to.add(u); cap.add(0); nxt.add(head[v]); head[v] = to.size - 1
        i++
    }

    let INF: Int64 = 0x3f3f3f3f3f3f3f3f
    let level = Array<Int64>(n, {_ => -1})
    let iter = Array<Int64>(n, {_ => 0})

    func bfs(): Bool {
        i = 0
        while (i < n) { level[i] = -1; i++ }
        level[s] = 0
        let q = ArrayList<Int64>(); q.add(s)
        var qi: Int64 = 0
        while (qi < q.size) {
            let u = q[qi]; qi++
            var e = head[u]
            while (e != -1) {
                if (cap[e] > 0 && level[to[e]] < 0) {
                    level[to[e]] = level[u] + 1; q.add(to[e])
                }
                e = nxt[e]
            }
        }
        return level[t] >= 0
    }

    func dfs(u: Int64, f: Int64): Int64 {
        if (u == t) { return f }
        while (iter[u] != -1) {
            let e = iter[u]
            if (cap[e] > 0 && level[to[e]] == level[u] + 1) {
                let d = dfs(to[e], min(f, cap[e]))
                if (d > 0) { cap[e] -= d; cap[e ^ 1] += d; return d }
            }
            iter[u] = nxt[e]
        }
        return 0
    }

    var flow: Int64 = 0
    while (bfs()) {
        i = 0
        while (i < n) { iter[i] = head[i]; i++ }
        var d = dfs(s, INF)
        while (d > 0) { flow += d; d = dfs(s, INF) }
    }
    println(flow)
}
```

**编译验证**: cjc 编译通过，s=0,t=3 的简单网络输出最大流 5 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | s=t | 0 (或 INF) | 起终点相同 |
| 2 | 无路径 | 0 | 不连通 |
| 3 | 单边 s→t | 边容量 | 直连 |
| 4 | 平行边 | 容量叠加 | 多条同向边 |
| 5 | V=500, E=10^4 | 性能 | V^2*E ≈ 2.5e9 边界 |

---

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 反向边索引 e^1 | 高 | 成对加边，确保边号从 0 开始 |
| 2 | BFS 不重置 level | 中 | 每轮开头清零 |
| 3 | DFS 遗漏 iter 推进 | 中 | while + iter[u] = nxt[e] |
