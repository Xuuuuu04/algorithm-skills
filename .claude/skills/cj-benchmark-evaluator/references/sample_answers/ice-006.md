# 思路

**核心算法**: 二分答案 + 贪心验证

**关键 insight**: 对答案（最大子数组和的最小值）进行二分。给定上界 mid，贪心检查能否将数组分成不超过 k 段使每段和 ≤ mid。

**步骤**:
1. 二分范围: lo = max(a[i]), hi = sum(a)
2. 对每个 mid，贪心从左到右切分：当前段和超过 mid 则开新段
3. 若段数 ≤ k 则可行 → hi = mid，否则 lo = mid + 1

---

# 复杂度

- **时间复杂度**: O(n log S) — S = sum(a)，二分 log S 次，每次 O(n) 验证
- **空间复杂度**: O(n) — 输入数组

**变量定义**: n = 数组长度, S = 元素总和

---

# 正确性要点

**方法**: 单调性证明

- **单调性**: mid 越大，所需段数越少 → 可行性关于 mid 单调递增
- **贪心最优**: 每段尽可能多取 → 段数最少 → 若贪心都不行则无解
- **下界**: lo = max(a[i])，因为单个元素不可再分

---

# 仓颉实现

```cangjie
import std.collection.*
import std.math.*

main() {
    let line1 = readln().split(" ")
    let n = Int64.parse(line1[0])
    let k = Int64.parse(line1[1])
    let vals = readln().split(" ")
    let a = Array<Int64>(n, {i => Int64.parse(vals[i])})

    var lo: Int64 = 0
    var hi: Int64 = 0
    var i: Int64 = 0
    while (i < n) { lo = max(lo, a[i]); hi += a[i]; i++ }

    while (lo < hi) {
        let mid = (lo + hi) / 2
        // 贪心验证
        var parts: Int64 = 1
        var curSum: Int64 = 0
        var valid = true
        i = 0
        while (i < n) {
            if (curSum + a[i] > mid) {
                parts++
                curSum = a[i]
            } else {
                curSum += a[i]
            }
            i++
        }
        if (parts <= k) { hi = mid }
        else { lo = mid + 1 }
    }
    println(lo)
}
```

**编译验证**: cjc 编译通过，输入 [7,2,5,10,8] k=2 输出 18 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | n=1, k=1 | a[0] | 单元素 |
| 2 | k=n | max(a[i]) | 每段一个 |
| 3 | k=1 | sum(a) | 不切分 |
| 4 | 全相等 | ceil(n/k)*val | 均匀分配 |
| 5 | n=10^5, 大值 | 性能 | O(n log S) |

---

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | hi = sum 溢出 Int64 | 低 | n*10^9 ≈ 10^14 < 2^63 |
| 2 | 单个 a[i] > mid 未处理 | 中 | lo = max(a[i]) 保证 |
| 3 | (lo+hi)/2 溢出 | 低 | lo + (hi-lo)/2 代替 |
