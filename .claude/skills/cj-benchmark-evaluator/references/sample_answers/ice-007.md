# 思路

**核心算法**: 并查集 (DSU) + 离线逆序处理

**关键 insight**: 删边在线很难维护连通性，但加边操作天然适合并查集。
将删边序列逆序变为加边，用并查集维护连通分量数，最后反转答案。

**步骤**:
1. 读入边列表和删除顺序
2. 初始化：所有边已删，每个点独立，comps = n
3. 逆序遍历删除顺序，每步加边 + unite，记录当前 comps
4. 反转答案得到正序结果

---

# 复杂度

- **时间复杂度**: O(m α(n)) ≈ O(m) — m 次 union-find，α 为反阿克曼函数
- **空间复杂度**: O(n + m) — 并查集 + 边列表

**变量定义**: n = 顶点数, m = 边数

---

# 正确性要点

**方法**: 时间反转等价

- **逆序加边 ↔ 正序删边**: 加边使连通分量减少，等价于删边使其增加
- **路径压缩+按秩合并**: 保证近线性复杂度
- **初始状态**: 所有边已删 → n 个独立分量

# 仓颉实现

```cangjie
import std.collection.*

main() {
    let line1 = readln().split(" ")
    let n = Int64.parse(line1[0])
    let m = Int64.parse(line1[1])

    let eu = Array<Int64>(m, {_ => 0})
    let ev = Array<Int64>(m, {_ => 0})
    var i: Int64 = 0
    while (i < m) {
        let parts = readln().split(" ")
        eu[i] = Int64.parse(parts[0]); ev[i] = Int64.parse(parts[1])
        i++
    }

    let delOrder = Array<Int64>(m, {_ => 0})
    i = 0
    while (i < m) { delOrder[i] = Int64.parse(readln()); i++ }

    let par = Array<Int64>(n, {i => i})
    let rnk = Array<Int64>(n, {_ => 0})
    var comps = n

    func find(x: Int64): Int64 {
        var r = x
        while (par[r] != r) { r = par[r] }
        var c = x
        while (c != r) { let next = par[c]; par[c] = r; c = next }
        return r
    }

    func unite(a: Int64, b: Int64): Unit {
        let ra = find(a); let rb = find(b)
        if (ra == rb) { return }
        if (rnk[ra] < rnk[rb]) { par[ra] = rb }
        else if (rnk[ra] > rnk[rb]) { par[rb] = ra }
        else { par[rb] = ra; rnk[ra]++ }
        comps--
    }

    let ans = ArrayList<Int64>()
    i = m - 1
    while (i >= 0) {
        ans.add(comps)
        let ei = delOrder[i]
        unite(eu[ei], ev[ei])
        i--
    }
    ans.reverse()
    i = 0
    while (i < ans.size) {
        println(ans[i])
        i++
    }
}
```

**编译验证**: cjc 编译通过，5 节点 5 边图逆序加边连通分量正确变化 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | n=1, m=0 | [1] | 单点 |
| 2 | 树 n-1 条边 | 1→2→...→n | 删完变 n 个分量 |
| 3 | 完全图 | 始终 1 直到几乎删完 | 冗余边 |
| 4 | 自环 | comps 不变 | unite(u,u) |
| 5 | n=10^5 | 性能 | α(n) 复杂度 |

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 删除顺序映射错误 | 中 | 用边索引而非边本身 |
| 2 | 重边 | 低 | unite 重复无影响 |
| 3 | 忘记反转答案 | 高 | 最后 ans.reverse() |
