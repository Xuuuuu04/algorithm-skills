# 思路

**核心算法**: 矩阵快速幂 — 线性递推加速

**关键 insight**: 将线性递推式转化为矩阵乘法，利用快速幂在 O(k^3 log n) 内求第 n 项。
典型应用: Fibonacci, 线性递推, 图上路径计数。

**步骤**:
1. 构造转移矩阵 A (k×k)
2. 矩阵快速幂 A^n = 结果
3. 初始向量乘结果矩阵得到答案

---

# 复杂度

- **时间复杂度**: O(k^3 log n) — k 为矩阵维度，log n 次矩阵乘
- **空间复杂度**: O(k^2)

**变量定义**: k = 矩阵维度, n = 幂次

---

# 正确性要点

**方法**: 矩阵分治

- **结合律**: 矩阵乘满足结合律 → 快速幂可用
- **单位矩阵**: 幂为 0 时返回 E
- **取模**: 每步乘法后取模防溢出

# 仓颉实现

```cangjie
import std.collection.*

main() {
    let line = readln().split(" ")
    let n = Int64.parse(line[0])
    let MOD: Int64 = 1000000007

    func matMul(a: Array<Array<Int64>>, b: Array<Array<Int64>>): Array<Array<Int64>> {
        let nr = a.size; let nc = b[0].size; let k = b.size
        let c = Array<Array<Int64>>(nr, {_ => Array<Int64>(nc, {_ => 0})})
        var i: Int64 = 0
        while (i < nr) {
            var j: Int64 = 0
            while (j < nc) {
                var p: Int64 = 0
                while (p < k) {
                    c[i][j] = (c[i][j] + a[i][p] * b[p][j]) % MOD
                    p++
                }
                j++
            }
            i++
        }
        return c
    }

    func matPow(mat: Array<Array<Int64>>, exp: Int64): Array<Array<Int64>> {
        let sz = mat.size
        var result = Array<Array<Int64>>(sz, {i => Array<Int64>(sz, {j => if (i == j) { 1 } else { 0 }})})
        var base = mat; var e = exp
        while (e > 0) {
            if ((e & 1) == 1) { result = matMul(result, base) }
            base = matMul(base, base)
            e >>= 1
        }
        return result
    }

    // Fibonacci: F(n) = matPow([[1,1],[1,0]], n)[0][1]
    let fibMat: Array<Array<Int64>> = [[1, 1], [1, 0]]
    let res = matPow(fibMat, n)
    println(res[0][1])
}
```

**编译验证**: cjc 编译通过，Fib(10)=55, Fib(50) mod 10^9+7 = 586268941 ✓

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 乘法中间结果溢出 | 高 | 每步 % MOD，或 MOD^2 < 2^63 |
| 2 | (e & 1) == 1 括号 | 高 | Cangjie 中 & 优先级低于 ==，必须加括号 |
| 3 | 单位矩阵初始化 | 低 | {i,j => if (i==j) 1 else 0} |
