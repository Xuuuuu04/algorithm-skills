# 思路

**核心算法**: 栈式表达式求值 (运算符优先级解析)

**关键 insight**: 用双栈（数值栈 + 运算符栈）解析中缀表达式。
遇到运算符时，先弹出优先级 ≥ 当前的运算符执行计算，再压入当前运算符。

**步骤**:
1. 扫描表达式，数字直接压入数值栈
2. 左括号压入运算符栈
3. 右括号弹出并计算至左括号
4. 运算符比较优先级后入栈
5. 扫描完弹出所有剩余运算符

---

# 复杂度

- **时间复杂度**: O(n) — 每个字符处理一次
- **空间复杂度**: O(n) — 两个栈

**变量定义**: n = 表达式长度

---

# 正确性要点

**方法**: 运算符优先级正确性

- **优先级**: * / = 2 > + - = 1
- **左结合**: 同优先级从左到右计算 → prec(top) >= prec(cur) 时弹出
- **括号**: 强制提升内部优先级，遇 ) 时清算至 (
- **多位数**: 连续数字字符合并为一个数

# 仓颉实现

```cangjie
import std.collection.*

main() {
    let expr = readln()
    let numStack = ArrayList<Int64>()
    let opStack = ArrayList<Byte>()
    let bytes = expr.toArray()
    let n = bytes.size

    func prec(op: Byte): Int64 {
        if (op == b'+' || op == b'-') { return 1 }
        if (op == b'*' || op == b'/') { return 2 }
        return 0
    }

    func applyOp(): Unit {
        if (numStack.size < 2 || opStack.size == 0) { return }
        let b = numStack[numStack.size - 1]; numStack.remove(at: numStack.size - 1)
        let a = numStack[numStack.size - 1]; numStack.remove(at: numStack.size - 1)
        let op = opStack[opStack.size - 1]; opStack.remove(at: opStack.size - 1)
        var result: Int64 = 0
        if (op == b'+') { result = a + b }
        else if (op == b'-') { result = a - b }
        else if (op == b'*') { result = a * b }
        else if (op == b'/') { result = a / b }
        numStack.add(result)
    }

    var i: Int64 = 0
    while (i < n) {
        let c = bytes[i]
        if (c == b' ') { i++; continue }
        if (c >= b'0' && c <= b'9') {
            var num: Int64 = 0
            while (i < n && bytes[i] >= b'0' && bytes[i] <= b'9') {
                num = num * 10 + Int64(bytes[i]) - 48
                i++
            }
            numStack.add(num)
            continue
        }
        if (c == b'(') { opStack.add(c) }
        else if (c == b')') {
            while (opStack.size > 0 && opStack[opStack.size - 1] != b'(') { applyOp() }
            if (opStack.size > 0) { opStack.remove(at: opStack.size - 1) }
        } else {
            while (opStack.size > 0 && opStack[opStack.size - 1] != b'(' && prec(opStack[opStack.size - 1]) >= prec(c)) { applyOp() }
            opStack.add(c)
        }
        i++
    }
    while (opStack.size > 0) { applyOp() }
    println(numStack[0])
}
```

**编译验证**: cjc 编译通过，"3+2*4"=11, "(3+2)*4"=20, "100/5+3*(2+8)"=50 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | "0" | 0 | 纯零 |
| 2 | "42" | 42 | 纯数字 |
| 3 | "((1+2))" | 3 | 多层括号 |
| 4 | "10-3-2" | 5 | 左结合 |
| 5 | "1000000000*1000000000" | 10^18 | 大数 |

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|

| 2 | 负数输入 | 中 | 特殊处理前置负号 |
| 3 | 多位数解析越界 | 低 | while 循环内检查 i < n |
