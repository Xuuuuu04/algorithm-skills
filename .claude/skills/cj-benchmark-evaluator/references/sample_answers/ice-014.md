# 思路

**核心算法**: 高精度大整数乘法 (竖式模拟)

**关键 insight**: 用字符串存储大整数，逆序逐位相乘累加到 prod[] 数组，最后处理进位。
也可扩展为 Karatsuba / NTT 加速。

**步骤**:
1. 读入两个大整数字符串 a, b
2. 分配 prod[na+nb] 数组存放各位乘积
3. 双重循环: prod[i+j+1] += a[i]*b[j]
4. 从低位到高位处理进位
5. 去前导零，输出

---

# 复杂度

- **时间复杂度**: O(n × m) — n, m 为两数位数
- **空间复杂度**: O(n + m) — 结果位数

**变量定义**: n = |a|, m = |b|

---

# 正确性要点

**方法**: 竖式乘法模拟

- **位对齐**: a[i] × b[j] 贡献到 prod[i+j] 和 prod[i+j+1]
- **进位**: 从右到左处理，prod[i] / 10 进位，prod[i] % 10 保留
- **前导零**: 结果可能有前导零需跳过

---

# 仓颉实现

```cangjie
import std.collection.*

main() {
    let a = readln()
    let b = readln()
    let na = a.size; let nb = b.size
    let aa = a.toArray(); let bb = b.toArray()
    let prod = Array<Int64>(na + nb, {_ => 0})

    var i = na - 1
    while (i >= 0) {
        var j = nb - 1
        while (j >= 0) {
            let d = (Int64(aa[i]) - 48) * (Int64(bb[j]) - 48)
            let p1 = i + j; let p2 = i + j + 1
            let s = d + prod[p2]
            prod[p2] = s % 10
            prod[p1] += s / 10
            j--
        }
        i--
    }

    var sb = StringBuilder()
    var leading = true
    for (d in prod) {
        if (leading && d == 0) { continue }
        leading = false
        sb.append(d.toString())
    }
    if (leading) { println("0") }
    else { println(sb.toString()) }
}
```

**编译验证**: cjc 编译通过，123×456=56088, 999×999=998001 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | "0" × "0" | "0" | 零乘 |
| 2 | "1" × b | b 本身 | 乘一 |
| 3 | "999...9" × "999...9" | 正确 | 大数 |
| 4 | 长度差异大 | 正确 | 非对称 |
| 5 | 10^5 位 × 10^5 位 | 性能 | O(n^2) 或 NTT |

---

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 位偏移搞错 | 中 | p1=i+j, p2=i+j+1 |
| 2 | 前导零输出 | 低 | leading 标志跳过 |
| 3 | O(n^2) 超时 | 中 | n>10^4 用 NTT O(n log n) |
