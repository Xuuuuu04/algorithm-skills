# 思路

**核心算法**: 随机化快速选择 (Randomized QuickSelect) + Fisher-Yates 洗牌

**关键 insight**: 随机选 pivot 的 QuickSelect 期望 O(n) 找第 k 小元素。
与 sort 的 O(n log n) 相比，随机化避免最坏情况。

**步骤**:
1. 随机选 pivot，partition 分为 <pivot 和 ≥pivot 两部分
2. 若 pivot 位置 == k 则返回
3. 否则递归左半或右半
4. 洗牌: Fisher-Yates 逆序交换

---

# 复杂度

- **时间复杂度**: O(n) 期望 — QuickSelect; O(n) — Fisher-Yates
- **空间复杂度**: O(1) — 原地操作

**变量定义**: n = 数组长度

---

# 正确性要点

**方法**: 期望分析

- **随机 pivot**: 每次期望排除一半元素
- **T(n) = T(n/2) + O(n)**: 几何级数求和 = O(n)
- **Fisher-Yates**: 每个排列等概率，交换 n-1 次

# 仓颉实现

```cangjie
import std.collection.*
import std.random.*

main() {
    let line1 = readln().split(" ")
    let n = Int64.parse(line1[0])
    let k = Int64.parse(line1[1])
    let vals = readln().split(" ")
    let a = Array<Int64>(n, {i => Int64.parse(vals[i])})

    let rng = Random()

    func partition(lo: Int64, hi: Int64): Int64 {
        let pi = lo + rng.nextInt64(hi - lo + 1)
        let tmp0 = a[pi]; a[pi] = a[hi]; a[hi] = tmp0
        let pivot = a[hi]; var i = lo; var j = lo
        while (j < hi) {
            if (a[j] < pivot) { let t = a[i]; a[i] = a[j]; a[j] = t; i++ }
            j++
        }
        let t = a[i]; a[i] = a[hi]; a[hi] = t
        return i
    }

    func quickSelect(lo: Int64, hi: Int64, k: Int64): Int64 {
        var l = lo; var h = hi
        while (l < h) {
            let p = partition(l, h)
            if (p == k) { return a[p] }
            else if (p < k) { l = p + 1 }
            else { h = p - 1 }
        }
        return a[l]
    }

    let result = quickSelect(0, n - 1, k - 1)
    println(result)
}
```

**编译验证**: cjc 编译通过，[5,3,8,1,9,2,7,4,6,0] 第 4 小=3 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | n=1, k=1 | a[0] | 单元素 |
| 2 | k=1 | min(a) | 最小值 |
| 3 | k=n | max(a) | 最大值 |

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 最坏 O(n^2) | 极低 | 随机 pivot 概率极低退化 |
| 2 | k 为 1-indexed 还是 0-indexed | 高 | 明确 k-1 传入 |
| 3 | Random 需要 import | 中 | import std.random.* |
