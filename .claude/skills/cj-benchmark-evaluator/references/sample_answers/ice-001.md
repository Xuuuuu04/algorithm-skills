# 思路

**核心算法**: Bellman-Ford 单源最短路 + 负环检测

**关键 insight**: Bellman-Ford 能处理负边权，且可通过第 n 轮松弛检测负环。
与 Dijkstra 不同，无需优先队列；n-1 轮松弛后所有最短路确定。

**步骤**:
1. 初始化 dist[src] = 0，其余 INF
2. 进行 n-1 轮松弛：遍历所有边，若 dist[u] + w < dist[v] 则更新
3. 第 n 轮再松弛一遍，若仍有更新则存在负环
4. 输出 dist 数组和负环判定结果

---

# 复杂度

- **时间复杂度**: O(V × E) — V 轮，每轮遍历所有边
- **空间复杂度**: O(V + E) — dist 数组 + 边列表

**变量定义**: V = 顶点数, E = 边数

---

# 正确性要点

**方法**: 归纳法

- **初始**: dist[src] = 0 正确
- **归纳**: 第 k 轮松弛后，dist[v] 为经过至多 k 条边的最短路
- **终止**: n-1 轮后覆盖无负环图的所有最短路（最多 n-1 条边）
- **负环**: 第 n 轮仍能松弛 ⟹ 存在负权环

---

# 仓颉实现

```cangjie
import std.collection.*

main() {
    let line1 = readln().split(" ")
    let n = Int64.parse(line1[0])
    let m = Int64.parse(line1[1])
    let src = Int64.parse(line1[2])

    let eu = Array<Int64>(m, {_ => 0})
    let ev = Array<Int64>(m, {_ => 0})
    let ew = Array<Int64>(m, {_ => 0})
    var i: Int64 = 0
    while (i < m) {
        let parts = readln().split(" ")
        eu[i] = Int64.parse(parts[0])
        ev[i] = Int64.parse(parts[1])
        ew[i] = Int64.parse(parts[2])
        i++
    }

    let INF: Int64 = 0x3f3f3f3f3f3f3f3f
    let dist = Array<Int64>(n, {_ => INF})
    dist[src] = 0

    // n-1 轮松弛
    var round: Int64 = 0
    while (round < n - 1) {
        var j: Int64 = 0
        while (j < m) {
            if (dist[eu[j]] < INF && dist[eu[j]] + ew[j] < dist[ev[j]]) {
                dist[ev[j]] = dist[eu[j]] + ew[j]
            }
            j++
        }
        round++
    }

    // 负环检测
    var hasNeg = false
    var j: Int64 = 0
    while (j < m) {
        if (dist[eu[j]] < INF && dist[eu[j]] + ew[j] < dist[ev[j]]) {
            hasNeg = true
        }
        j++
    }

    if (hasNeg) { println("NEGATIVE CYCLE") }
    else {
        i = 0
        while (i < n) {
            if (i > 0) { print(" ") }
            if (dist[i] >= INF) { print("INF") } else { print(dist[i]) }
            i++
        }
        println()
    }
}
```

**编译验证**: `cjc` 编译通过，测试输入 4 节点 5 边图输出 `0 1 3 6`，负环检测 false ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | n=1, m=0 | `0` | 最小图，单点 |
| 2 | n=2, m=1 负边 | `0 -5` | 负边正常处理 |
| 3 | 三角负环 | `NEGATIVE CYCLE` | 负环检测 |
| 4 | 线性链 n=10^4 | 累加和 | O(VE) 性能边界 |
| 5 | 断连图 | 含 INF | 不可达节点 |

---

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | dist[u]+w 溢出 Int64 | 低 | INF = 0x3f3f3f3f3f3f3f3f，加法前判 dist[u] < INF |
| 2 | 负环上节点 dist 无限减小 | 中 | 第 n 轮检测后提前终止 |
| 3 | V×E 超时 | 中 | V,E > 10^4 时换 SPFA 或 Dijkstra |
