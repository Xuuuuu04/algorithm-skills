# 思路

**核心算法**: 莫队算法 — 离线处理区间查询

**关键 insight**: 将查询按 (l/B, r) 排序后，双指针 curL/curR 移动总距离 O(n√n)。
每次移动 add/remove 一个元素维护答案。

**步骤**:
1. 分块大小 B = √n
2. 将所有查询按 (l/B, r) 排序
3. 维护 curL, curR 和计数数组 cnt[]
4. 每次查询移动指针至 [ql, qr]，更新 distinct 计数

---

# 复杂度

- **时间复杂度**: O((n + q) √n) — 指针总移动量
- **空间复杂度**: O(n + q)

**变量定义**: n = 数组长度, q = 查询数, B = √n

---

# 正确性要点

**方法**: 指针移动不变量

- **维护**: cnt[v] = v 在 [curL, curR] 中的出现次数
- **add**: cnt[v]++ 后若 == 1 则 distinct++
- **remove**: cnt[v]-- 后若 == 0 则 distinct--
- **排序**: 保证指针总移动 O(n√n)

---

# 仓颉实现

```cangjie
import std.collection.*
import std.sort.*
import std.math.*

main() {
    let line1 = readln().split(" ")
    let n = Int64.parse(line1[0])
    let q = Int64.parse(line1[1])
    let vals = readln().split(" ")
    let a = Array<Int64>(n, {i => Int64.parse(vals[i])})

    let block = max(1, Int64(sqrt(Float64(n))))

    let ql = Array<Int64>(q, {_ => 0})
    let qr = Array<Int64>(q, {_ => 0})
    var i: Int64 = 0
    while (i < q) {
        let parts = readln().split(" ")
        ql[i] = Int64.parse(parts[0])
        qr[i] = Int64.parse(parts[1])
        i++
    }

    let qIdx = Array<Int64>(q, {i => i})
    sort(qIdx, by: {a0: Int64, b: Int64 =>
        let la = ql[a0] / block; let lb = ql[b] / block
        if (la != lb) { if (la < lb) { return Ordering.LT } else { return Ordering.GT } }
        if (qr[a0] < qr[b]) { return Ordering.LT }
        else if (qr[a0] > qr[b]) { return Ordering.GT }
        return Ordering.EQ
    })

    let MAXVAL: Int64 = 1000001
    let cnt = Array<Int64>(MAXVAL, {_ => 0})
    var distinct: Int64 = 0
    var curL: Int64 = 0; var curR: Int64 = -1

    func addVal(idx: Int64): Unit {
        cnt[a[idx]]++
        if (cnt[a[idx]] == 1) { distinct++ }
    }
    func removeVal(idx: Int64): Unit {
        cnt[a[idx]]--
        if (cnt[a[idx]] == 0) { distinct-- }
    }

    let ans = Array<Int64>(q, {_ => 0})
    for (qi in qIdx) {
        let tl = ql[qi]; let tr = qr[qi]
        while (curR < tr) { curR++; addVal(curR) }
        while (curL > tl) { curL--; addVal(curL) }
        while (curR > tr) { removeVal(curR); curR-- }
        while (curL < tl) { removeVal(curL); curL++ }
        ans[qi] = distinct
    }
    i = 0
    while (i < q) { println(ans[i]); i++ }
}
```

**编译验证**: cjc 编译通过，数组 [1,2,1,3,2,1,4] 四组查询输出 3 3 4 4 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | n=1, q=1 | 1 | 单元素 |
| 2 | 全相同 | 始终 1 | cnt 只有一个非零 |
| 3 | 全不同 | r-l+1 | 区间长度 |
| 4 | l=r | 1 | 单点查询 |
| 5 | n=10^5, q=10^5 | 性能 | O(n√n) |

---

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 值域过大 cnt 爆内存 | 中 | 离散化后用较小数组 |
| 2 | 指针移动顺序 | 高 | 先扩展再收缩：R右→L左→R左→L右 |
| 3 | block=0 除零 | 低 | max(1, sqrt(n)) |
