# 思路

**核心算法**: 状态压缩 DP — TSP (旅行商问题)

**关键 insight**: 用 bitmask 表示已访问节点集合。dp[mask][u] = 从起点出发，访问了 mask 中的节点，当前在 u 的最小代价。

**步骤**:
1. dp[1][0] = 0 (从节点 0 出发)
2. 枚举 mask，枚举当前节点 u，枚举下一节点 v
3. 转移: dp[mask|(1<<v)][v] = min(dp[mask][u] + dist[u][v])
4. 答案: min(dp[full][u] + dist[u][0]) — 回到起点

---

# 复杂度

- **时间复杂度**: O(2^n × n^2) — 枚举 mask × u × v
- **空间复杂度**: O(2^n × n)

**变量定义**: n = 节点数 (≤ 20)

---

# 正确性要点

**方法**: 状态空间覆盖

- **完备性**: 所有 2^n 个子集 × n 个终点 = 全部状态
- **无后效性**: dp[mask][u] 仅依赖 mask 子集
- **最优子结构**: 最优路径的前缀也是最优的
- **位运算**: (mask >> v) & 1 判断 v 是否已访问

# 仓颉实现

```cangjie
import std.collection.*

main() {
    let n = Int64.parse(readln())
    let dist = Array<Array<Int64>>(n, {_ => Array<Int64>(n, {_ => 0})})
    var i: Int64 = 0
    while (i < n) {
        let parts = readln().split(" ")
        var j: Int64 = 0
        while (j < n) { dist[i][j] = Int64.parse(parts[j]); j++ }
        i++
    }

    let INF: Int64 = 0x3f3f3f3f3f3f3f3f
    let full = (1 << n) - 1
    let dp = Array<Array<Int64>>(1 << n, {_ => Array<Int64>(n, {_ => INF})})
    dp[1][0] = 0

    var mask: Int64 = 1
    while (mask <= full) {
        var u: Int64 = 0
        while (u < n) {
            if (dp[mask][u] < INF && ((mask >> u) & 1) == 1) {
                var v: Int64 = 0
                while (v < n) {
                    if (((mask >> v) & 1) == 0) {
                        let nm = mask | (1 << v)
                        let nd = dp[mask][u] + dist[u][v]
                        if (nd < dp[nm][v]) { dp[nm][v] = nd }
                    }
                    v++
                }
            }
            u++
        }
        mask++
    }

    var ans = INF
    var u: Int64 = 0
    while (u < n) {
        if (dp[full][u] + dist[u][0] < ans) { ans = dp[full][u] + dist[u][0] }
        u++
    }
    println(ans)
}
```

**编译验证**: cjc 编译通过，4 城市距离矩阵输出 TSP 最小环游代价 80 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | n=1 | 0 | 单点不移动 |
| 2 | n=2 | 2*dist[0][1] | 来回 |
| 3 | 对称矩阵 | 正确 | 对称 TSP |
| 4 | n=20 | 2^20*20^2≈4e8 | 极限 TLE 风险 |
| 5 | dist含 0 | 跳过不移动 | 共位节点 |

---

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | (mask>>v)&1 括号 | 高 | Cangjie 位运算优先级低，必须 ((mask>>v)&1)==1 |
| 2 | 2^20 × 20 空间 | 中 | 约 20M Int64 = 160MB，需检查内存限制 |
| 3 | 忘记回到起点 | 中 | 最后加 dist[u][0] |
