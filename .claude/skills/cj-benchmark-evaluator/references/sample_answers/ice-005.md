# 思路

**核心算法**: 主席树 (可持久化权值线段树) — 静态区间第 k 小

**关键 insight**: 对每个前缀 [0..i] 建一棵权值线段树，利用可持久化共享节点。
查询 [l,r] 第 k 小 = root[r+1] - root[l] 的差分线段树上二分。

**步骤**:
1. 离散化值域
2. 依次插入 a[0]..a[n-1]，每次 update 产生 O(log m) 个新节点
3. 查询 [l,r] 的第 k 小：在 root[l] 和 root[r+1] 上递归，比较左子树差值与 k

---

# 复杂度

- **时间复杂度**: O((n + q) log m) — n 次插入 + q 次查询，每次 O(log m)
- **空间复杂度**: O(n log m) — 每次插入新增 O(log m) 节点

**变量定义**: n = 数组长度, q = 查询数, m = 值域大小

---

# 正确性要点

**方法**: 前缀和性质

- **前缀可减性**: root[r+1] 的权值线段树减 root[l] = [l,r] 区间的权值分布
- **共享结构**: 未修改路径共享旧节点，保证空间 O(n log m)
- **二分定位**: 递归时比较左子树计数与 k，决定向左/右走

# 仓颉实现

```cangjie
import std.collection.*
import std.sort.*

main() {
    let line1 = readln().split(" ")
    let n = Int64.parse(line1[0])
    let q = Int64.parse(line1[1])
    let vals = readln().split(" ")
    let a = Array<Int64>(n, {i => Int64.parse(vals[i])})

    let MAXN: Int64 = n * 40 + 10
    var tot: Int64 = 0
    let ls = Array<Int64>(MAXN, {_ => 0})
    let rs = Array<Int64>(MAXN, {_ => 0})
    let sum = Array<Int64>(MAXN, {_ => 0})

    // 离散化
    var sorted = Array<Int64>(n, {i => a[i]})
    sort(sorted)
    let uniq = ArrayList<Int64>()
    for (v in sorted) {
        if (uniq.isEmpty() || uniq[uniq.size - 1] != v) { uniq.add(v) }
    }
    let m = uniq.size

    func build(l: Int64, r: Int64): Int64 {
        let p = tot; tot++
        sum[p] = 0; ls[p] = 0; rs[p] = 0
        if (l == r) { return p }
        let mid = (l + r) / 2
        ls[p] = build(l, mid)
        rs[p] = build(mid + 1, r)
        return p
    }

    func update(prev: Int64, l: Int64, r: Int64, x: Int64): Int64 {
        let p = tot; tot++
        ls[p] = ls[prev]; rs[p] = rs[prev]; sum[p] = sum[prev] + 1
        if (l == r) { return p }
        let mid = (l + r) / 2
        if (x <= mid) { ls[p] = update(ls[prev], l, mid, x) }
        else { rs[p] = update(rs[prev], mid + 1, r, x) }
        return p
    }

    func query(u: Int64, v: Int64, l: Int64, r: Int64, k: Int64): Int64 {
        if (l == r) { return l }
        let mid = (l + r) / 2
        let leftCnt = sum[ls[v]] - sum[ls[u]]
        if (k <= leftCnt) { return query(ls[u], ls[v], l, mid, k) }
        else { return query(rs[u], rs[v], mid + 1, r, k - leftCnt) }
    }

    // 二分查找离散化 rank
    func getRank(val: Int64): Int64 {
        var lo: Int64 = 0; var hi = uniq.size - 1
        while (lo < hi) {
            let mid = (lo + hi) / 2
            if (uniq[mid] < val) { lo = mid + 1 } else { hi = mid }
        }
        return lo
    }

    let root = Array<Int64>(n + 1, {_ => 0})
    root[0] = build(0, m - 1)
    var i: Int64 = 0
    while (i < n) {
        root[i + 1] = update(root[i], 0, m - 1, getRank(a[i]))
        i++
    }

    var qi: Int64 = 0
    while (qi < q) {
        let parts = readln().split(" ")
        let l = Int64.parse(parts[0])
        let r = Int64.parse(parts[1])
        let k = Int64.parse(parts[2])
        let rank = query(root[l], root[r + 1], 0, m - 1, k)
        println(uniq[rank])
        qi++
    }
}
```

**编译验证**: cjc 编译通过，数组 [3,1,2,5,4] 查询 [0,2] k=1→1, k=2→2, k=3→3 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | n=1, q=1 | a[0] | 单元素 |
| 2 | 全相同值 | 该值 | 去重后值域=1 |
| 3 | k=1 (最小) | min(a[l..r]) | 左边界 |
| 4 | k=r-l+1 (最大) | max(a[l..r]) | 右边界 |
| 5 | n=10^5, q=10^5 | 性能 | 空间 n*40 节点 |

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 节点数不足 | 中 | MAXN = n*40 + 10，每次 update O(log n) 个新节点 |
| 2 | 离散化偏移 | 低 | 用二分查找而非 HashMap |
| 3 | query 区间差分错误 | 中 | root[l] 和 root[r+1] 不是 root[l-1] |
