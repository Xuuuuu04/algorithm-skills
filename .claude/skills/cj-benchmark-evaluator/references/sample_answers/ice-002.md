# 思路

**核心算法**: 换根 DP (Rerooting DP)

**关键 insight**: 先以任意节点为根 DFS 求 dp[root]，再通过父子关系在 O(1) 内推导换根后的答案。
典型应用: 求每个节点到所有其他节点的距离和。

**步骤**:
1. 第一遍 DFS (root=0): 求 sz[v] (子树大小) 和 dp[v] (子树内距离和)
2. 第二遍 BFS 换根: ans[v] = ans[parent] - sz[v] + (n - sz[v])
3. 输出每个节点的 ans

---

# 复杂度

- **时间复杂度**: O(n) — 两次 DFS/BFS
- **空间复杂度**: O(n)

---

# 正确性要点

**方法**: 增量推导

- 从 u 换根到子节点 v: v 子树内 sz[v] 个节点各近 1, 子树外 n-sz[v] 个节点各远 1
- ans[v] = ans[u] - sz[v] + (n - sz[v])

---

# 仓颉实现

```cangjie
import std.collection.*

main() {
    let n = Int64.parse(readln().split(" ")[0])
    let adj = ArrayList<ArrayList<Int64>>(n, {_ => ArrayList<Int64>()})
    var i: Int64 = 0
    while (i < n - 1) {
        let parts = readln().split(" ")
        let u = Int64.parse(parts[0]); let v = Int64.parse(parts[1])
        adj[u].add(v); adj[v].add(u); i++
    }
    let sz = Array<Int64>(n, {_ => 1})
    let dp = Array<Int64>(n, {_ => 0})
    let par = Array<Int64>(n, {_ => -1})
    let stk = ArrayList<(Int64, Int64, Bool)>()
    stk.add((0, -1, false))
    while (!stk.isEmpty()) {
        let (u, p, done) = stk.remove(at: stk.size - 1)
        if (done) {
            for (j in 0..adj[u].size) {
                let v = adj[u][j]
                if (v != p) { sz[u] += sz[v]; dp[u] += dp[v] + sz[v] }
            }
        } else {
            par[u] = p; stk.add((u, p, true))
            for (j in 0..adj[u].size) {
                let v = adj[u][j]
                if (v != p) { stk.add((v, u, false)) }
            }
        }
    }
    let ans = Array<Int64>(n, {_ => 0})
    ans[0] = dp[0]
    let q = ArrayList<Int64>(); q.add(0)
    var qi: Int64 = 0
    while (qi < q.size) {
        let u = q[qi]; qi++
        for (j in 0..adj[u].size) {
            let v = adj[u][j]
            if (v != par[u]) { ans[v] = ans[u] - sz[v] + (n - sz[v]); q.add(v) }
        }
    }
    i = 0
    while (i < n) { if (i > 0) { print(" ") }; print(ans[i]); i++ }
    println()
}
```

**编译验证**: cjc 编译通过，5 节点树输出 6 5 9 8 8

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 递归 DFS 栈溢出 | 高 | 使用迭代 DFS |
| 2 | 换根公式推错方向 | 中 | 明确 v 在 u 子树内侧 |
| 3 | 带权边需额外项 | 中 | 公式改为 ans[v] = ans[u] - w*sz[v] + w*(n-sz[v]) |
