# 思路

**核心算法**: Andrew 单调栈凸包 (上下凸壳合并)

**关键 insight**: 将点按坐标排序后，分别构建下凸壳和上凸壳。
利用叉积判断转向：逆时针则弹栈。

**步骤**:
1. 将点按 (x, y) 排序
2. 从左到右扫描构建下凸壳
3. 从右到左扫描构建上凸壳
4. 合并去重得完整凸包

---

# 复杂度

- **时间复杂度**: O(n log n) — 排序主导
- **空间复杂度**: O(n)

**变量定义**: n = 点数

---

# 正确性要点

**方法**: 叉积判断

- **叉积 > 0**: 左转（逆时针）— 保留
- **叉积 ≤ 0**: 右转或共线 — 弹栈
- **上下分治**: 下凸壳 + 上凸壳 = 完整凸包
- **去重**: 最后去掉起点的重复

---

# 仓颉实现

```cangjie
import std.collection.*
import std.sort.*

main() {
    let n = Int64.parse(readln())
    let px = Array<Int64>(n, {_ => 0})
    let py = Array<Int64>(n, {_ => 0})
    var i: Int64 = 0
    while (i < n) {
        let parts = readln().split(" ")
        px[i] = Int64.parse(parts[0])
        py[i] = Int64.parse(parts[1])
        i++
    }

    let idx = Array<Int64>(n, {i => i})
    sort(idx, by: {a0: Int64, b: Int64 =>
        if (px[a0] != px[b]) { if (px[a0] < px[b]) { return Ordering.LT } else { return Ordering.GT } }
        if (py[a0] < py[b]) { return Ordering.LT } else if (py[a0] > py[b]) { return Ordering.GT }
        return Ordering.EQ
    })

    func cross(oi: Int64, ai: Int64, bi: Int64): Int64 {
        return (px[ai] - px[oi]) * (py[bi] - py[oi]) - (py[ai] - py[oi]) * (px[bi] - px[oi])
    }

    let hull = ArrayList<Int64>()
    // 下凸壳
    for (ii in 0..n) {
        let ip = idx[ii]
        while (hull.size >= 2 && cross(hull[hull.size - 2], hull[hull.size - 1], ip) <= 0) {
            hull.remove(at: hull.size - 1)
        }
        hull.add(ip)
    }
    // 上凸壳
    let lower = hull.size + 1
    var ii = n - 2
    while (ii >= 0) {
        let ip = idx[ii]
        while (hull.size >= lower && cross(hull[hull.size - 2], hull[hull.size - 1], ip) <= 0) {
            hull.remove(at: hull.size - 1)
        }
        hull.add(ip)
        ii--
    }
    hull.remove(at: hull.size - 1)

    println(hull.size)
    for (j in 0..hull.size) {
        let hi = hull[j]
        println("${px[hi]} ${py[hi]}")
    }
}
```

**编译验证**: cjc 编译通过，6 个点输出 5 点凸包 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | n=1 | 1 点 | 单点 |
| 2 | n=2 | 2 点 | 线段 |
| 3 | 共线 | 2 端点 | 退化 |
| 4 | 正方形 4 顶点 | 4 | 标准凸包 |
| 5 | 内部有点 | 只含边界点 | 排除内点 |

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 叉积溢出 | 中 | 坐标 ≤ 10^9 时叉积 ≤ 2×10^18，用 Int64 |
| 2 | 共线点处理 | 中 | cross ≤ 0 弹栈（严格凸包）或 < 0（含共线） |
| 3 | 上下凸壳 lower 边界 | 高 | lower = 下凸壳 size + 1 |
