# 思路

**核心算法**: 后缀自动机 (Suffix Automaton, SAM)

**关键 insight**: SAM 的每个状态代表一个 endpos 等价类，状态数 ≤ 2n-1。
不同子串数 = Σ(len[i] - len[link[i]]) 对所有状态 i。

**步骤**:
1. 在线构建 SAM: 每次插入一个字符，扩展 last 状态
2. 必要时 clone 节点（分裂长状态）
3. 统计: 遍历所有状态求 len[i] - len[link[i]] 之和

---

# 复杂度

- **时间复杂度**: O(n × |Σ|) — n 次插入，每次平摊 O(|Σ|)
- **空间复杂度**: O(n × |Σ|) — 最多 2n-1 个状态

**变量定义**: n = 字符串长度, |Σ| = 字符集大小

---

# 正确性要点

**方法**: endpos 等价类理论

- **len[i]**: 状态 i 代表的最长子串长度
- **link[i]**: 后缀链接，指向最长真后缀所在状态
- **clone**: 当 len[p]+1 ≠ len[q] 时需分裂，保证一对一映射
- **计数**: 每个状态贡献 len[i]-len[link[i]] 个不同子串

# 仓颉实现

```cangjie
import std.collection.*

main() {
    let s = readln()
    let n = s.size
    let MAXN = 2 * n + 2
    let len = Array<Int64>(MAXN, {_ => 0})
    let link = Array<Int64>(MAXN, {_ => -1})
    let ch = Array<HashMap<Byte, Int64>>(MAXN, {_ => HashMap<Byte, Int64>()})
    var sz: Int64 = 1; var last: Int64 = 0
    len[0] = 0; link[0] = -1

    let bytes = s.toArray()
    for (c in bytes) {
        let cur = sz; sz++; len[cur] = len[last] + 1
        var p = last
        while (p != -1 && !ch[p].contains(c)) { ch[p][c] = cur; p = link[p] }
        if (p == -1) { link[cur] = 0 }
        else {
            let q = ch[p].get(c).getOrThrow()
            if (len[p] + 1 == len[q]) { link[cur] = q }
            else {
                let clone = sz; sz++
                len[clone] = len[p] + 1; link[clone] = link[q]
                for (kv in ch[q]) { ch[clone][kv[0]] = kv[1] }
                while (p != -1 && ch[p].get(c).getOrThrow() == q) { ch[p][c] = clone; p = link[p] }
                link[q] = clone; link[cur] = clone
            }
        }
        last = cur
    }

    var total: Int64 = 0
    for (i in 1..sz) { total += len[i] - len[link[i]] }
    println(total)
}
```

**编译验证**: cjc 编译通过，"abab" 输出 7 (不同子串: a,b,ab,ba,aba,bab,abab) ✓

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | clone 遗漏转移 | 高 | 深拷贝 ch[q] 到 ch[clone] |
| 2 | HashMap 性能 | 中 | 字符集小时用数组代替 |
| 3 | MAXN 不足 | 低 | 2*n+2 足够 |
