# 思路

**核心算法**: Sprague-Grundy 定理 — 博弈论

**关键 insight**: 每个公平博弈的局面可计算 SG 值，多堆博弈的 SG = 各堆 SG 值的异或。
SG=0 则后手必胜，SG≠0 则先手必胜。

**步骤**:
1. 对单堆定义后继状态集
2. SG[x] = mex({SG[y] | y 是 x 的后继})
3. 多堆: 总 SG = SG[pile1] ^ SG[pile2] ^ ...
4. 判断总 SG 是否为 0

---

# 复杂度

- **时间复杂度**: O(max_pile × branching) — 每个状态枚举后继
- **空间复杂度**: O(max_pile)

**变量定义**: max_pile = 最大堆数, branching = 每状态后继数

---

# 正确性要点

**方法**: SG 定理

- **mex**: 最小排外值，SG[x] = 不在后继 SG 集中的最小非负整数
- **异或性**: 独立博弈组合的 SG = 各子博弈 SG 的 XOR
- **P/N 位置**: SG=0 为 P-position (前手必败)

---

# 仓颉实现

```cangjie
import std.collection.*
import std.sort.*

main() {
    let line = readln().split(" ")
    let nPiles = Int64.parse(line[0])
    let vals = readln().split(" ")
    let piles = Array<Int64>(nPiles, {i => Int64.parse(vals[i])})

    var maxPile: Int64 = 0
    for (p in piles) { if (p > maxPile) { maxPile = p } }

    // 计算 SG 值 (取 1 或 2 个石子的变种)
    let sg = Array<Int64>(maxPile + 1, {_ => 0})
    sg[0] = 0
    for (i in 1..=maxPile) {
        let reachable = ArrayList<Int64>()
        if (i >= 1) { reachable.add(sg[i - 1]) }
        if (i >= 2) { reachable.add(sg[i - 2]) }
        sort(reachable)
        var mex: Int64 = 0
        for (v in reachable) { if (v == mex) { mex++ } }
        sg[i] = mex
    }

    var xorSum: Int64 = 0
    for (p in piles) { xorSum = xorSum ^ sg[p] }

    if (xorSum != 0) { println("First") }
    else { println("Second") }
}
```

**编译验证**: cjc 编译通过，堆 [3,4,5] 取 1/2 规则 XOR=3 输出 "First" ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | [0] | Second | 无石子可取 |
| 2 | [1] | First | 取走唯一 |
| 3 | [1,1] | Second | XOR=0 |
| 4 | 标准 Nim | SG=堆本身 | 取任意数 |
| 5 | 大堆 10^6 | 性能 | O(N) 预处理 |

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | 后继集定义错误 | 高 | 仔细读题：取 1~k 个还是任意 |
| 2 | mex 计算漏值 | 中 | 先排序再线性扫描 |
| 3 | 多堆异或遗漏 | 低 | 循环所有堆 |
