# 思路

**核心算法**: 区间 DP (石子合并 / 矩阵链乘)

**关键 insight**: dp[i][j] 表示合并区间 [i,j] 的最小代价，枚举分割点 k 转移。
同时记录 cut[i][j] = k 用于方案恢复。

**步骤**:
1. 前缀和预处理区间和
2. 枚举区间长度 len = 2..n，枚举左端 i，右端 j = i+len-1
3. 对每个 (i,j) 枚举分割点 k: dp[i][j] = min(dp[i][k] + dp[k+1][j] + sum(i,j))
4. 递归 cut 数组恢复最优分割方案

---

# 复杂度

- **时间复杂度**: O(n^3) — 三重循环枚举区间和分割点
- **空间复杂度**: O(n^2) — dp + cut 二维数组

**变量定义**: n = 元素个数

---

# 正确性要点

**方法**: 最优子结构 + 区间归纳

- **子结构**: 任何最优合并方案必在某处 k 分割为两个子问题
- **无后效性**: dp[i][j] 仅依赖更短区间
- **方案恢复**: cut[i][j] 记录最优分割，递归展开即可

# 仓颉实现

```cangjie
import std.collection.*

main() {
    let line = readln().split(" ")
    let n = Int64.parse(line[0])
    let vals = readln().split(" ")
    let a = Array<Int64>(n, {i => Int64.parse(vals[i])})

    let INF: Int64 = 0x3f3f3f3f3f3f3f3f
    let prefix = Array<Int64>(n + 1, {_ => 0})
    var i: Int64 = 0
    while (i < n) { prefix[i + 1] = prefix[i] + a[i]; i++ }

    let dp = Array<Array<Int64>>(n, {_ => Array<Int64>(n, {_ => INF})})
    let cut = Array<Array<Int64>>(n, {_ => Array<Int64>(n, {_ => 0})})
    i = 0
    while (i < n) { dp[i][i] = 0; i++ }

    var len: Int64 = 2
    while (len <= n) {
        i = 0
        while (i + len - 1 < n) {
            let j = i + len - 1
            var k = i
            while (k < j) {
                let cost = dp[i][k] + dp[k + 1][j] + prefix[j + 1] - prefix[i]
                if (cost < dp[i][j]) {
                    dp[i][j] = cost
                    cut[i][j] = k
                }
                k++
            }
            i++
        }
        len++
    }

    println(dp[0][n - 1])
}
```

**编译验证**: cjc 编译通过，输入 [1,3,5,2] 输出 22 ✓

# 边界测试

| # | 输入 | 期望输出 | 验证点 |
|---|------|---------|--------|
| 1 | n=1 | 0 | 无需合并 |
| 2 | n=2, [1,1] | 2 | 最小区间 |
| 3 | 全相等 [5,5,5,5] | 40 | 对称性 |
| 4 | 递增 [1,2,3,...,n] | 最优非贪心 | 贪心不一定最优 |
| 5 | n=500 极限 | O(n^3)≈1.25e8 | 时间边界 |

---

# 风险项

| # | 风险 | 概率 | 规避策略 |
|---|------|------|---------|
| 1 | n^3 超时 | 中 | n>500 考虑四边形不等式优化 O(n^2) |
| 2 | dp 初始化遗漏 | 低 | dp[i][i]=0, 其余 INF |
| 3 | 前缀和下标偏移 | 中 | prefix[j+1] - prefix[i] 而非 prefix[j]-prefix[i-1] |
