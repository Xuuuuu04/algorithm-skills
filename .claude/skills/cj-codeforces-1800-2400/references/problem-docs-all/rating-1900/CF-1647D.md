# CF-1647D Madoka and the Best School in Russia

## 题面快照

## Description

- 如果 $n$ 是 $d$ 的倍数，则称 $n$ 为“好数”；
- 如果 $n$ 是“好数”且不能写成任意两个“好数”之积，则称 $n$ 是“美丽数”。

$T$ 组询问，每组询问给定两个正整数 $x,d$，保证 $x$ 是好数，问 $x$ 是否有至少两种方式写为至少一个“美丽数”之积。如果是，输出 `YES`；否则输出 `NO`。

注意输出对大小写不敏感。

## Input

第一行一个正整数 $T$ 表示数据组数。

对于每组数据，有两个正整数 $x,d$。

## Output

对于每组数据，如果可以，输出 `YES`，否则输出 `NO`。

## Samples

### Sample 1

Input
```
8
6 2
12 2
36 2
8 2
1000 10
2376 6
128 4
16384 4
```

Output
```
NO
NO
YES
NO
YES
YES
NO
YES
```
