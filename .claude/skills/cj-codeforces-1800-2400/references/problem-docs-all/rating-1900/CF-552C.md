# CF-552C Vanya and Scales

## 题面快照

## Description

Vanya 有一个天平和一组砝码，这些砝码的质量分别为 $w^{0}, w^{1}, w^{2}, ..., w^{100}$ 克，其中 $w$ 是一个不少于 $2$ 的整数（每种面值的砝码只有一个）。Vanya 想知道，是否可以用给定的这些砝码称出质量为 $m$ 的物体，如果允许将砝码放在天平的两边。形式上，你的任务是判断是否可以将质量为 $m$ 的物体和若干砝码放在天平的左边，将另一些砝码放在天平的右边，使得天平达到平衡。

## Input

第一行包含两个整数 $w, m$（$2 \leq w \leq 10^{9}$，$1 \leq m \leq 10^{9}$），分别表示砝码的基数和物体的质量。

## Output

如果可以称出该物体，请输出 "YES"；否则输出 "NO"。

## Samples

### Sample 1

Input
```
3 7
```

Output
```
YES
```

### Sample 2

Input
```
100 99
```

Output
```
YES
```

### Sample 3

Input
```
100 50
```

Output
```
NO
```

## Note

关于第一个样例的说明。天平的一边可以放上质量为 $7$ 的物体和一个质量为 $3$ 的砝码，另一边则可以放上两个质量分别为 $9$ 和 $1$ 的砝码。这样有 $7+3=9+1$，天平就能平衡。

关于第二个样例的说明。天平的一边可以放上质量为 $99$ 的物体和一个质量为 $1$ 的砝码，另一边则可以放上一个质量为 $100$ 的砝码。

关于第三个样例的说明。无法用上述方法称出该物体的重量。
