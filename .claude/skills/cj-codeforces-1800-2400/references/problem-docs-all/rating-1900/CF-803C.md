# CF-803C Maximal GCD

## 题面快照

## Description

给定一个正整数 $n$。你需要构造一个严格递增的 $k$ 个正整数序列 $a_1, a_2, \ldots, a_k$，使得它们的和等于 $n$，并且它们的最大公约数最大。

一个序列的最大公约数是所有序列元素均能整除的最大整数。

如果不存在这样的序列，输出 $-1$。

## Input

第一行包含两个整数 $n$ 和 $k$（$1 \leq n, k \leq 10^{10}$）。

## Output

如果存在答案，输出 $k$ 个正整数，表示所得序列。否则输出 $-1$。若有多个答案，输出其中任意一个均可。

## Samples

### Sample 1

Input
```
6 3
```

Output
```
1 2 3
```

### Sample 2

Input
```
8 2
```

Output
```
2 6
```

### Sample 3

Input
```
5 3
```

Output
```
-1
```
