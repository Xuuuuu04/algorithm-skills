# CF-1409D Decrease the Sum of Digits

## 题面快照

## Description

给定一个正整数 $n$。每次操作，你可以将 $n$ 增加 $1$（即令 $n := n + 1$）。你的任务是求出最少需要多少次操作，才能使 $n$ 的各位数字之和小于等于 $s$。

你需要回答 $t$ 个独立的测试用例。

## Input

输入的第一行包含一个整数 $t$（$1 \le t \le 2 \cdot 10^4$），表示测试用例的数量。接下来的 $t$ 行，每行包含两个整数 $n$ 和 $s$（$1 \le n \le 10^{18}$；$1 \le s \le 162$）。

## Output

对于每个测试用例，输出一个答案：使 $n$ 的各位数字之和小于等于 $s$ 所需的最少操作次数。

## Samples

### Sample 1

Input
```
5
2 1
1 1
500 4
217871987498122 10
100000000000000001 1
```

Output
```
8
0
500
2128012501878
899999999999999999
```
