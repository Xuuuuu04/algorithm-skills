# CF-1133D Zero Quantity Maximization

## 题面快照

## Description

# 零数最大化
给出两个长度为 $n$ 的数组 $a,b$。

你想要创建一个长度为 $n$ 的数组 $c$，且$c_i=d*a_i+b_i,i\in[1, n]$，要求你给 $d$ 赋值，使得数组 $c$ 中的 $0$ 的个数最多并输出最多的 $0$ 的个数。

## Input

第一行一个整数 $n$，
第二行 $n$ 个整数为数组 $a$，
第二行 $n$ 个整数为数组 $b$，

## Output

一个数为数组 $c$ 中最多的 $0$ 的个数

## Samples

### Sample 1

Input
```
5
1 2 3 4 5
2 4 7 11 3
```

Output
```
2
```

### Sample 2

Input
```
3
13 37 39
1 2 3
```

Output
```
2
```

### Sample 3

Input
```
4
0 0 0 0
1 2 3 4
```

Output
```
0
```

### Sample 4

Input
```
3
1 2 -1
-6 -12 6
```

Output
```
3
```
