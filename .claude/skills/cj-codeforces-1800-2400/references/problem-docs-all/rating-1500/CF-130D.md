# CF-130D Exponentiation

## 题面快照

## Description

You are given integers a, b and c. Calculate ab modulo c.

Input data contains numbers a, b and c, one number per line. Each number is an integer between 1 and 100, inclusive.

Output ab mod c.

## Input

Input data contains numbers a, b and c, one number per line. Each number is an integer between 1 and 100, inclusive.

## Output

Output ab mod c.
