# CF-1201B Zero Array

## 题面快照

## Description

给定一个数组 $a_1, a_2, \ldots, a_n$。

每次操作，你可以选择两个不同的元素 $a_i$ 和 $a_j$（$i \ne j$），并将它们各自减一。

你需要判断是否有可能通过若干次操作使所有元素都变为零。

## Input

第一行包含一个整数 $n$（$2 \le n \le 10^5$），表示数组的大小。

第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^9$），表示数组中的元素。

## Output

如果可以使所有元素都变为零，输出 "YES"；否则输出 "NO"。

## Samples

### Sample 1

Input
```
4
1 1 2 2
```

Output
```
YES
```

### Sample 2

Input
```
6
1 2 3 4 5 6
```

Output
```
NO
```

## Note

在第一个样例中，你可以通过 $3$ 次操作使所有元素变为零：

- 将 $a_1$ 和 $a_2$ 各减 $1$；
- 将 $a_3$ 和 $a_4$ 各减 $1$；
- 再将 $a_3$ 和 $a_4$ 各减 $1$。

在第二个样例中，可以证明无法使所有元素都变为零。
