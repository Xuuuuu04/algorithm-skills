CF977B Two-gram

题目描述

Two-gram 是由两个大写拉丁字母组成的有序对（即长度为 $2$ 的字符串）。例如，“AZ”、“AA”、“ZA”是三个不同的 two-gram。 给定一个由 $n$ 个大写拉丁字母组成的字符串 $s$，你的任务是找出在该字符串中作为子串（即字符串中连续的两个字符）出现次数最多的任意一个 two-gram。例如，对于字符串 $s = \text{BBAABBBA}$，答案是 two-gram “BB”，它在 $s$ 中出现了三次。换句话说，找出出现次数最多的任意一个 two-gram。 注意，two-gram 的出现可以相互重叠。

输入格式

输入的第一行包含一个整数 $n$（$2 \le n \le 100$），表示字符串 $s$ 的长度。第二行包含由 $n$ 个大写拉丁字母组成的字符串 $s$。

输出格式

输出仅一行，包含恰好两个大写拉丁字母，表示在给定字符串 $s$ 中作为子串（即连续的两个字符）出现次数最多的任意一个 two-gram。

说明/提示

在第一个样例中，“BA” 也是一个合法答案。 在第二个样例中，唯一的 two-gram “ZZ” 可以被输出，因为它在字符串 “ZZZAA” 中出现了两次。 由 ChatGPT 4.1 翻译
