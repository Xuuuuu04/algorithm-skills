CF598A Tricky Sum

题目描述

给出一个正整数 $n$，求 $1$ 到 $n$ 的和，但是其中每当遇到一个数是 $2$ 的次幂时，就要变加为减。 例如，输入 $n=4$，那么计算算式为 $-1-2+3-4=-4$，其中 $1 = 2^0$，$2=2^1$，$4 = 2^2$。 共有 $t$ 组数据。

输入格式

第一行输入一个整数 $t$，满足 $1 \le t \le 100$。 接下来 $t$ 行，每行输入一个整数 $n$，满足 $1 \le n \le 10^9$。

输出格式

对于每个询问，输出一行一个整数，表示答案。

说明/提示

第一组样例已在题面中给出解释。
