# CF-26A Almost Prime

## 题面快照

## Description

一个数如果恰好有两个不同质因子，那它被叫做几乎是质数的数。例如：`6,18,24`就是几乎是质数的数，而`4,8,9,42`不是，请你找出 $1$ 到 $n$ 中几乎是质数的数有多少个。

## Input

输入仅包含一个整数 $n$（$1\leq n\leq3000$）。

## Output

输出 $1$ 到 $n$ 中几乎是质数的数的数量。

Translated by Khassar

## Samples

### Sample 1

Input
```
10
```

Output
```
2
```

### Sample 2

Input
```
21
```

Output
```
8
```
