# CF-598A Tricky Sum

## 题面快照

## Description

给出一个正整数 $n$，求 $1$ 到 $n$ 的和，但是其中每当遇到一个数是 $2$ 的次幂时，就要变加为减。

例如，输入 $n=4$，那么计算算式为 $-1-2+3-4=-4$，其中 $1 = 2^0$，$2=2^1$，$4 = 2^2$。

共有 $t$ 组数据。

## Input

第一行输入一个整数 $t$，满足 $1 \le t \le 100$。

接下来 $t$ 行，每行输入一个整数 $n$，满足 $1 \le n \le 10^9$。

## Output

对于每个询问，输出一行一个整数，表示答案。

## Samples

### Sample 1

Input
```
2
4
1000000000
```

Output
```
-4
499999998352516354
```
