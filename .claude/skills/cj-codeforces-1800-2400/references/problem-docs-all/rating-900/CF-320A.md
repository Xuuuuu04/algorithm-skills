# CF-320A Magic Numbers

## 题面快照

## Description

魔法数是通过将 $1$、$14$ 和 $144$ 这三个数字按任意顺序拼接而成的数字。每个数字可以使用任意次数。因此，$14144$、$141414$ 和 $1411$ 是魔法数，而 $1444$、$514$ 和 $414$ 不是魔法数。

给定一个数字，判断它是否为魔法数。

## Input

输入的第一行包含一个整数 $n$，$(1 \leq n \leq 10^{9})$。该数字不包含前导零。

## Output

如果 $n$ 是魔法数，则输出 “YES”；否则输出 “NO”。

## Samples

### Sample 1

Input
```
114114
```

Output
```
YES
```

### Sample 2

Input
```
1111
```

Output
```
YES
```

### Sample 3

Input
```
441231
```

Output
```
NO
```
