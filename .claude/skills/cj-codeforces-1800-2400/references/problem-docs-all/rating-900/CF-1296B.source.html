CF1296B Food Buying

题目描述

Mishka 想在附近的商店买些食物。最初，他的卡上有 $s$ 布尔。 Mishka 可以进行如下操作任意次（也可以一次都不做）：选择一个正整数 $1 \le x \le s$，购买价值恰好 $x$ 布尔的食物，并获得 $\lfloor\frac{x}{10}\rfloor$ 布尔的返现（也就是说，Mishka 花费 $x$ 布尔，并获得 $\lfloor\frac{x}{10}\rfloor$ 的返现）。操作 $\lfloor\frac{a}{b}\rfloor$ 表示 $a$ 除以 $b$ 向下取整。 保证对于任意可能的 $x$，你总能买到价值为 $x$ 的食物。 你的任务是，求出如果 Mishka 以最优方式买食物，他最多能花掉多少布尔。 例如，如果 Mishka 有 $s=19$ 布尔，则他最多能花掉 $21$ 布尔。首先，他可以花 $x=10$ 布尔，获得 $1$ 布尔返现。现在他还有 $s=10$ 布尔，因此可以再花 $x=10$ 布尔，获得 $1$ 布尔返现，并将其也花掉。 你需要回答 $t$ 组独立的测试用例。

输入格式

输入的第一行包含一个整数 $t$（$1 \le t \le 10^4$），表示测试用例的数量。 接下来的 $t$ 行，每行描述一个测试用例，每个测试用例包含一个整数 $s$（$1 \le s \le 10^9$），表示 Mishka 最初拥有的布尔数。

输出格式

对于每个测试用例，输出一个答案——Mishka 以最优方式买食物时最多能花掉的布尔数。
