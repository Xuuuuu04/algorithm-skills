# CF-1339A Filling Diamonds

## 题面快照

## Description

给定一个数字 $n$ ,要求你用 $n$ 个菱形去填满 $4n-2$ 个正三角形。求有多少种不同的填法。

其中，这一个菱形由两个正三角形组成，它可以被平移或是旋转，但是不可以被缩放。

![](https://cdn.luogu.com.cn/upload/vjudge_pic/CF1339A/7fff5be8f830afa5425faaf9881be90640b6bdaf.png) 

上图是 $n \ = 1,2,3,4$ 时的需要填充的三角形。

## Input

**本题有多组数据！**

第一行，一个整数 $T$ ，表示测试数据的组数

接下来的 $T$ 行中，每行只有一个整数 $n$ 。

## Output

总共有 $T$ 行 ，每一行都输出一个整数，代表填充对应的 $4n - 2$ 个三角形的不同方式的种数。

## Samples

### Sample 1

Input
```
2
2
1
```

Output
```
2
1
```

## Note

------------


$1 \le T \le 10^{4}$。

$1 \le n \le 10^{9}$。
 
对于每一个测试数据，保证填充方法的种数 $\le 10^{18}$
