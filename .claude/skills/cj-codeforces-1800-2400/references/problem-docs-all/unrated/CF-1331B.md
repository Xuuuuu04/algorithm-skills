# CF-1331B Limericks

## 题面快照

## Description

```
<pre class="verbatim">曾经有个年轻的姑娘叫 Mary，<br></br>她的笑话有时让人害怕。<br></br>在这个愚人节，<br></br>固定的打油诗规则，<br></br>让她能让粗心的人上当。<br></br><br></br>她能填满所有的诗句，<br></br>让它们始终成立吗？<br></br>在玩弄这些词语时，<br></br>大约在三分之二处，<br></br>她几乎用尽了押韵的词。<br></br>
```

## Input

输入包含一个整数 $a$，其中 $4 \leq a \leq 998$。并不是该范围内的每个整数都是本题的有效输入；但保证输入一定是一个有效的整数。

## Output

输出一个数字。
