# CF-1812D Trivial Conjecture

## 题面快照

## Description

$$
f(n) = \left\{
\begin{array}{ll}
\frac{n}{2} & n \equiv 0 \pmod{2} \\
3n+1 & n \equiv 1 \pmod{2} \\
\end{array}
\right.
$$

请你找到一个整数 $n$，使得数列 $n, f(n), f(f(n)), f(f(f(n))), \dots$ 的前 $k$ 项都不等于 $1$。

## Input

输入仅一行，包含一个整数 $k$（$1 \leq k \leq \min(\textbf{[REDACTED]}, 10^{18})$）。

## Output

输出一个整数 $n$，使得数列 $n, f(n), f(f(n)), f(f(f(n))), \dots$ 的前 $k$ 项都不等于 $1$。

整数 $n$ 的位数不超过 $10^3$。

## Samples

### Sample 1

Input
```
1
```

Output
```
5
```

### Sample 2

Input
```
5
```

Output
```
6
```

## Note

在第一个测试样例中，取 $n=5$，生成的序列为 $5, 16, 8, 4, 2, 1, 4, \dots$，前 $k=1$ 项都不等于 $1$。

在第二个测试样例中，取 $n=6$，生成的序列为 $6, 3, 10, 5, 16, 8, 4, \dots$，前 $k=5$ 项都不等于 $1$。
