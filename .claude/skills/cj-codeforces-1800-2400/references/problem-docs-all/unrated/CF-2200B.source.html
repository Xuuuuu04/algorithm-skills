CF2200B 删除排序

题目描述

AksLolCoding 正在一个由 $n$ 个正整数组成的数组 $a$ 上玩一个游戏。在每个回合中： - 如果 $a$ 是非递减的$^{\text{∗}}$，游戏结束。 - 否则，AksLolCoding 可以选择任意一个元素并将其从数组中移除。 请确定游戏结束后数组中可能剩余的最少元素数量。 $^{\text{∗}}$ 如果对于所有 $1\leq i\leq m-1$（其中 $m$ 是数组 $a$ 的长度），都有 $a_i\leq a_{i+1}$，则称数组 $a$ 是非递减的。

输入格式

第一行包含一个整数 $t$ ($1 \leq t \leq 1000$)，表示测试用例的数量。 每个测试用例的第一行包含一个整数 $n$ ($1 \leq n \leq 10$)。 每个测试用例的第二行包含 $n$ 个整数，即数组 $a$ 的元素 ($1 \leq a_i \leq 100$)。

输出格式

对于每个测试用例，输出一个整数：当数组变为有序时可能剩余的最少元素数量。

说明/提示

### 输入 #1 ``` 3 4 1 4 2 3 1 100 2 6 7 ``` ### 输出 #1 ``` 1 1 2 ``` 在第一个测试用例中，可以按顺序移除 1、2 和 3，从而实现只剩 1 个元素的最少情况。 在第二个和第三个测试用例中，无法移除任何元素。 由DeepseekV3翻译
