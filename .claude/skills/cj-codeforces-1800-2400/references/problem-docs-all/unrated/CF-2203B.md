# CF-2203B Beautiful Numbers

## 题面快照

## Description

定义 $F(x)$ 为 $x$ 的各位数字之和。如果一个整数 $x$ 满足 $F(F(x)) = F(x)$，则称它为美丽的。

给定一个整数 $x$。在一次操作中，你可以选择数字中的任意一位，将其替换为另一个数字。得到的数字不能有前导零。

你的任务是计算出使给定的数字变成美丽的所需的最少操作次数（可能为零）。

## Input

第一行包含一个整数 $t$（$1 \le t \le 10^4$）—— 测试用例的数量。

每个测试用例只有一行，包含一个整数 $x$（$1 \le x \le 10^{18}$）。

## Output

对于每个测试用例，输出一个整数——使给定的数字变成美丽的所需的最少操作次数。

## Samples

### Sample 1

Input
```
4
1
37
645
2374236843276813
```

Output
```
0
1
2
12
```

## Note

在第一个示例中，给定的数字已经是美丽的。

在第二个示例中，通过一次操作，我们可以得到美丽的数 $3\underline{3}$（被更改的数字加了下划线）。

在第三个示例中，通过两次操作，我们可以得到美丽的数 $\underline{1}4\underline{0}$（被更改的数字加了下划线）。
