# CF-399A Pages

## 题面快照

## Description

用户 ainta 正在制作一个网站。这一次，他打算制作页面的导航条。在他的网站中，有 $n$ 个页面，编号为 $1$ 到 $n$ 的整数。假设某人当前在第 $p$ 页。导航条将如下所示：

<< $p-k$ $p-k+1$ $\ldots$ $p-1$ $(p)$ $p+1$ $\ldots$ $p+k-1$ $p+k$ >>

当点击“<<”按钮时，会跳转到第 $1$ 页；点击“>>”按钮时，会跳转到第 $n$ 页。当然，点击某个页码时，会跳转到对应的页面。

导航条需要满足以下条件：

- 如果页面 $1$ 出现在导航条中，则不需要打印“<<”按钮。
- 如果页面 $n$ 出现在导航条中，则不需要打印“>>”按钮。
- 若页码小于 $1$ 或大于 $n$，则不需打印。

下面给出了部分导航条的样例。请编写程序输出正确的导航条。

## Input

第一行包含三个整数 $n$，$p$，$k$（$3 \leq n \leq 100$；$1 \leq p \leq n$；$1 \leq k \leq n$）。

## Output

输出正确的导航条。请参考测试样例的格式进行输出。
