## 题面快照

## Description

## 题目描述

#

## Input

第一行包含一个整数 $t$（$1 \leq t \leq 100$），表示测试用例的数量。

接下来的 $t$ 行，每行包含一个由小写英文字母组成的字符串，长度不超过 $100$。

#

## Output

对于每个测试用例，输出一行 "YES" 或 "NO"，表示答案。
