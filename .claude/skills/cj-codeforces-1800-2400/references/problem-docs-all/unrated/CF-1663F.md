# CF-1663F In Every Generation...

## 题面快照

## Description
In every generation there is a Chosen One. She alone will stand against the vampires, the demons, and the forces of darkness. She is the Slayer. — Joss Whedon

A string $s$ ($3 \le |s| \le 7$) consisting of lowercase English letters.

A single string. If there is no answer, print "none" (without the quotes).

## Input

A string $s$ ($3 \le |s| \le 7$) consisting of lowercase English letters.

## Output

A single string. If there is no answer, print "none" (without the quotes).
