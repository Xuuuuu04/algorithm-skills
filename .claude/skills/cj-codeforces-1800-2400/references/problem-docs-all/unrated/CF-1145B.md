# CF-1145B Kanban Numbers

## 题面快照

## Input

Input

The input contains a single integer $$$a$$$ ($$$1 \le a \le 99$$$).

## Output

Output

Output "YES" or "NO".

## Samples

### Sample 1

Input
```
5
```

Output
```
YES
```

### Sample 2

Input
```
13
```

Output
```
NO
```

### Sample 3

Input
```
24
```

Output
```
NO
```

### Sample 4

Input

```
46
```

Output
```
YES
```
