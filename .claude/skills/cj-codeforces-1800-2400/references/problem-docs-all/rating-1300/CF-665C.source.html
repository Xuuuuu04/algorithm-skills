CF665C Simple Strings

题目描述

zscoder 喜欢简单串！如果一个字符串 $t$ 的任意相邻两个字符都不相同，则称其为简单串。例如，ab、aba、zscoder 都是简单串，而 aa、add 都不是简单串。 现在 zscoder 有一个字符串 $s$。他想最少地修改字符，使得字符串 $s$ 变为简单串。请帮助他完成这个任务！

输入格式

仅一行，包含字符串 $s$（$1 \leq |s| \leq 2 \cdot 10^{5}$）——这是 zscoder 给出的字符串。字符串 $s$ 只包含小写英文字母。

输出格式

输出一个简单串 $s'$ —— 这是对字符串 $s$ 经过最少修改后的结果。如果存在多种方案，你可以输出其中任意一种。 注意，输出的字符串 $s'$ 也只能包含小写英文字母。
