CF236B Easy Number Challenge

题目描述

我们记 $d(n)$ 为正整数 $n$ 的约数的个数。给定三个整数 $a$、$b$ 和 $c$，你的任务是计算以下这个和： ![](https://cdn.luogu.com.cn/upload/vjudge_pic/CF236B/6b4d9893ce96bd0459ff1289a8bf3491052ac12a.png) 求上述和对 $1073741824$（即 $2^{30}$）取模的结果。

输入格式

第一行包含三个用空格分隔的整数 $a$、$b$ 和 $c$，满足 $1 \leq a, b, c \leq 100$。

输出格式

输出一个整数，表示所求的和对 $1073741824$ 取模的结果。

说明/提示

对于第一个样例： - $d(1\times 1\times 1) = d(1) = 1$； - $d(1\times 1\times 2) = d(2) = 2$； - $d(1\times 2\times 1) = d(2) = 2$； - $d(1\times 2\times 2) = d(4) = 3$； - $d(2\times 1\times 1) = d(2) = 2$； - $d(2\times 1\times 2) = d(4) = 3$； - $d(2\times 2\times 1) = d(4) = 3$； - $d(2\times 2\times 2) = d(8) = 4$。 所以结果为 $1 + 2 + 2 + 3 + 2 + 3 + 3 + 4 = 20$。 由 ChatGPT 5 翻译
