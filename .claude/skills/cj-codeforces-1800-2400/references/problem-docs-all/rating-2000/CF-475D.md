# CF-475D CGCDSSQ

## 题面快照

## Description

给定一个整数序列 $a_{1},\dots,a_{n}$，以及 $q$ 个查询 $x_{1},\dots,x_{q}$。对于每个查询 $x_{i}$，你需要统计有多少对 $(l, r)$ 满足 $1 \leq l \leq r \leq n$，并且 $\gcd(a_{l},a_{l+1},\dots,a_{r}) = x_{i}$。

![](https://cdn.luogu.com.cn/upload/vjudge_pic/CF475D/57fa10a542946ca7729b1feeb84648963b002c6d.png) 表示 $v_{1},v_{2},\dots,v_{n}$ 的最大公约数，即能整除所有 $v_{i}$ 的最大正整数。

## Input

给定一个整数序列 $a_{1},\dots,a_{n}$，以及 $q$ 个查询 $x_{1},\dots,x_{q}$。对于每个查询 $x_{i}$，你需要统计有多少对 $(l, r)$ 满足 $1 \leq l \leq r \leq n$，并且 $\gcd(a_{l},a_{l+1},\dots,a_{r}) = x_{i}$。

![](https://cdn.luogu.com.cn/upload/vjudge_pic/CF475D/57fa10a542946ca7729b1feeb84648963b002c6d.png) 表示 $v_{1},v_{2},\dots,v_{n}$ 的最大公约数，即能整除所有 $v_{i}$ 的最大正整数。

## Output

对于每个查询，在单独的一行中输出结果。
