# CF-242E XOR on Segment

## 题面快照

## Description

你得到了一个序列 $a$，其中包含 $n$ 个元素 $a_1,a_2,\cdots,a_n$。
你需要执行 $m$ 个操作，分为两种：

- `1 l r`：求 $a_l\sim a_r$ 的和。
- `2 l r x`：将 $a_l\sim a_r$ 异或上 $x$。

## Input

第一行，一个正整数 $n$，表示序列长度。

第二行，$n$ 个非负整数 $a_1,a_2,\cdots,a_n$。

第三行，一个正整数 $m$，表示操作个数。

接下来 $m$ 行，每行 $3$ 或 $4$ 个正整数，表示一个操作。

## Output

对每个操作 $1$，输出一行一个整数表示答案。

## Samples

### Sample 1

Input
```
5
4 10 3 13 7
8
1 2 4
2 1 3 3
1 2 4
1 3 3
2 2 5 5
1 1 5
2 1 2 10
1 2 3
```

```

0

```

### Sample 2

Input
```
6
4 7 4 0 7 3
5
2 2 3 8
1 1 5
2 3 5 1
2 4 5 6
1 2 3
```

Output
```
38
28
```

## Note

$1\le n\le 10^5$

$1\le m\le 5\times 10^4$

$0\le a_i\le 10^6$

$1\le x \le 10^6$

- 在 `C++` 和 `Java` 中，异或符号为 `^`，在 `Pascal` 中为 `xor`。
