CF1513D GCD and MST

题目描述

输入格式

第一行包含一个整数 $t$（$1 \leq t \leq 10^4$），表示测试用例的数量。 每个测试用例的第一行包含两个整数 $n$（$2 \leq n \leq 2 \times 10^5$）和 $p$（$1 \leq p \leq 10^9$），分别表示节点数和参数 $p$。 第二行包含 $n$ 个整数 $a_1, a_2, a_3, \dots, a_n$（$1 \leq a_i \leq 10^9$）。 保证所有测试用例中 $n$ 的总和不超过 $2 \times 10^5$。

输出格式

输出 $t$ 行，每行一个整数，表示对应图的最小生成树的权值。
