# CF-1082E Increasing Frequency

## 题面快照

## Description

给你一个长度为 $n$ 的数列 $a$ ,你可以任意选择一个区间 $[l,r]$, 并给区间每个数加上一个整数 $k$, 求这样一次操作后数列中最多有多少个数等于 $c$.

## Input

第一行两个整数 $n$, $c$ .
第二行 $n$ 个整数 $a_1,a_2,...,a_n$ .

$1\le n,c,a_i \le 5\cdot 10^5$ .

## Output

输出一个整数表示答案。

## Samples

### Sample 1

Input
```
6 9
9 9 9 9 9 9
```

Output
```
6
```

### Sample 2

Input
```
3 2
6 2 6
```

Output
```
2
```
