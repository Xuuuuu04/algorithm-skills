# CF-153A A + B

## 题面快照

## Description

You are given two integers A and B. Calculate their sum and output it without leading zeros.

Two lines of input data contain integers A and B (1 ≤ A, B ≤ 105).

Output A + B without leading zeros.

## Input

Two lines of input data contain integers A and B (1 ≤ A, B ≤ 105).

## Output

Output A + B without leading zeros.
