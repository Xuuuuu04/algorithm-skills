# CF-1999A A+B Again?

## 题面快照

## Description

给定一个两位正整数 $n$，求其各位数字之和。

## Input

第一行包含一个整数 $t$（$1 \leq t \leq 90$），表示测试用例的数量。

每个测试用例的唯一一行包含一个两位正整数 $n$（$10 \leq n \leq 99$）。

## Output

对于每个测试用例，输出一个整数，表示 $n$ 的各位数字之和。

## Samples

### Sample 1

Input
```
8
77
21
40
34
19
84
10
99
```

Output
```
14
3
4
7
10
12
1
18
```
