# CF-615A Bulbs

## 题面快照

## Description

Vasya 想要点亮一串由 $m$ 只灯泡组成的圣诞彩灯。起初，所有灯泡都是关闭的。有 $n$ 个按钮，每个按钮连接着某些灯泡。Vasya 可以按下其中任意一个按钮。当按下某个按钮时，与该按钮连接的所有灯泡都会被点亮。如果某只灯泡已经被点亮，再次按下与其相连的按钮不会改变它的状态，即它仍然保持点亮状态。请问 Vasya 能否通过按下按钮使所有灯泡都被点亮？

## Input

输入的第一行包含两个整数 $n$ 和 $m$（$1 \leq n, m \leq 100$），分别表示按钮的数量和灯泡的数量。

接下来的 $n$ 行，每行描述一个按钮。第 $i$ 行先给出一个整数 $x_{i}$ ($0 \leq x_{i} \leq m$)，表示第 $i$ 个按钮能点亮的灯泡数量，随后跟着 $x_{i}$ 个整数 $y_{ij}$ ($1 \leq y_{ij} \leq m$)，表示这些灯泡的编号。

## Output

如果能够点亮所有 $m$ 只灯泡，输出 "YES"；否则输出 "NO"。

## Samples

### Sample 1

Input
```
3 4
2 1 4
3 1 3 1
1 2
```

Output
```
YES
```

### Sample 2

Input
```
3 3
1 1
1 2
1 1
```

Output
```
NO
```

## Note

在第一个样例中，每个按钮都按下一次，可以点亮所有灯泡。在第二个样例中，第 $3$ 只灯泡无法被点亮。
