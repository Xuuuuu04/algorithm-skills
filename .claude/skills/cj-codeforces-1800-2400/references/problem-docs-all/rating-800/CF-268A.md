# CF-268A Games

## 题面快照

## Description

Manao 在一家体育电视台工作。他花了很多时间观看某个国家的足球比赛。过了一段时间后，他开始注意到不同的规律。例如，每支球队有两套队服：主场队服和客场队服。当一支球队在自己的主场比赛时，球员们会穿上主场队服；而当球队作为客队在别人的球场比赛时，则会穿上客场队服。唯一的例外是：如果主队的主场队服颜色与客队的客场队服颜色相同，主队也需要穿上客场队服。对于每支队伍，他们的主场和客场队服颜色不同。

有 $n$ 支队伍参加国家锦标赛。锦标赛有 $n \cdot (n-1)$ 场比赛：每支队伍都会邀请其他每一支队伍到自己的主场比赛。这时 Manao 产生了一个疑问：在整个锦标赛期间，主队将有多少次不得不穿上客场队服？注意，比赛的顺序不会影响这一数字。

现在你知道每支队伍主场和客场队服的颜色。为简单起见，所有颜色都被用整数编号，且不同的颜色编号不同。请帮助 Manao 回答他的问题。

## Input

第一行为一个整数 $n$（$2 \leq n \leq 30$）。接下来的 $n$ 行中，每行包含一对不同的用空格分隔的整数 $h_i$，$a_i$（$1 \leq h_i, a_i \leq 100$），表示第 $i$ 支队伍的主场和客场队服的颜色。

## Output

输出一个整数，表示在整个锦标赛期间，主队将不得不穿上客场队服的比赛场数。

## Samples

### Sample 1

Input
```
3
1 2
2 4

```

Output
```

```

### Sample 2

Input


### Sample 3

Input
```
2

1 2
```

Output
```
0
```

## Note

在第一个样例中，锦标赛一共进行 6 场比赛。唯一一次出现主队不得不穿客场队服的比赛是 2 号队伍在主场迎战 1 号队伍的比赛。

在第二个样例中，主队需要穿客场队服的比赛有：1 号对 2 号，2 号对 1 号，2 号对 3 号，3 号对 4 号，4 号对 2 号（主队编号写在前）。
