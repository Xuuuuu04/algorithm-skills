CF1328A Divisibility Problem

题目描述

给定两个正整数 $a$ 和 $b$。每次操作你可以将 $a$ 增加 $1$（即用 $a+1$ 替换 $a$）。你的任务是求出最少需要多少次操作才能使 $a$ 能被 $b$ 整除。如果 $a$ 已经能被 $b$ 整除，则可能不需要进行任何操作。你需要回答 $t$ 个独立的测试用例。

输入格式

输入的第一行包含一个整数 $t$（$1 \le t \le 10^4$），表示测试用例的数量。接下来有 $t$ 行，每行包含两个整数 $a$ 和 $b$（$1 \le a, b \le 10^9$）。

输出格式

对于每个测试用例，输出一个答案，即使 $a$ 能被 $b$ 整除所需的最少操作次数。
