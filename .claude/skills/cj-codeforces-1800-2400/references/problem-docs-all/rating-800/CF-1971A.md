# CF-1971A My First Sorting Problem

## 题面快照

## Description

给定两个整数 $x$ 和 $y$。

输出两个整数：$x$ 和 $y$ 中的较小值，随后输出较大值。

## Input

第一行包含一个整数 $t$（$1 \leq t \leq 100$），表示测试用例的数量。

每个测试用例的一行包含两个用空格分隔的整数 $x$ 和 $y$（$0 \leq x, y \leq 9$）。

## Output

对于每个测试用例，输出两个整数：$x$ 和 $y$ 中的较小值，随后输出较大值。

## Samples

### Sample 1

Input
```
10
1 9
8 4
1 4
3 4
2 0
2 4
6 9
3 3
0 0
9 9
```

Output
```
1 9
4 8
1 4
3 4
0 2
2 4
6 9
3 3
0 0
9 9
```
