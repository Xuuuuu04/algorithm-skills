# CF-1459A Red-Blue Shuffle

## 题面快照

## Description

### 题意翻译


有 $n$ 张卡，第 $i$ 张卡上有一个红色的数码 $R_i$ 和一个蓝色的数码 $B_i$ 。如果将牌随机洗好后从左到右摆放（即`random_shuffle`）后，令红色的数码从左到右连起来**严格大于**蓝色的数码概率为 $r$ ；红色的数码连起来**严格小于**蓝色的数码为 $b$ 。

如果 $r>b$ ，输出`RED`；
如果 $r<b$ ，输出`BLUE`；
否则输出`EQUAL`。

## Input

第一行输入 $T$ ，表示数据组数。

对于每一个数据，第一行输入 $n$ ，表示卡的个数。

接下来输入两个字符串 $R, B$ ，其中 $R_i, B_i$ 分别表示第 $i$ 张卡的红色数码、蓝色数码。

## Output

对于每一组数据输出一行字符串，表示该组数据的答案。

## Samples

### Sample 1

Input
```
3
3
777
111
3
314
159
5
09281
09281
```

Output
```
RED
BLUE
EQUAL
```
