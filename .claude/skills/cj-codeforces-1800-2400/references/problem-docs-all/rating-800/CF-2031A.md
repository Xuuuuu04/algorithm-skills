# CF-2031A Penchick and Modern Monument

## 题面快照

## Description

给出长度为 $n$ 的**单调不增**数列 $h$，你可以进行若干次操作，每次操作中，你可以选择任意一个数 $i$，并将 $h_i$ 改为任意一个数，目标是让数列 $h$ 变成**单调不降**的数列。请问最少需要多少次操作？

## Input

第一行一个数 $t$，表示多测数据组数。

对于每组数据，第一行一个数 $n$，表示数列长度；第二行 $n$ 个数 $h_i$，表示数列。

## Output

共 $t$ 行，每一行为每组数据答案。

## Samples

### Sample 1

Input
```
3
5
5 4 3 2 1
3
2 2 1
1
1
```

Output
```
4
1
0
```

## Note

$1\le t\le1000$，$1\le n\le50$。
