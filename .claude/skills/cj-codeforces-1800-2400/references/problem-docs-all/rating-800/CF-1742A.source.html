CF1742A Sum

题目描述

给定三个整数 $a$、$b$ 和 $c$。判断其中是否存在一个数等于另外两个数之和。

输入格式

第一行包含一个整数 $t$（$1 \leq t \leq 9261$），表示测试用例的数量。 每个测试用例包含三个整数 $a$、$b$、$c$（$0 \leq a, b, c \leq 20$）。

输出格式

对于每个测试用例，如果存在一个数等于另外两个数之和，输出 "YES"；否则输出 "NO"。 输出答案时不区分大小写（例如，"yEs"、"yes"、"Yes" 和 "YES" 都会被识别为肯定答案）。

说明/提示

在第一个测试用例中，$1 + 3 = 4$。 在第二个测试用例中，没有一个数等于另外两个数之和。 在第三个测试用例中，$9 + 11 = 20$。 由 ChatGPT 4.1 翻译
