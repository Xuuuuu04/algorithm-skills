# CF-900A Find Extra One

## 题面快照

## Description

# 题目简述
平面直角坐标系上有n个点，它们都不在y轴上。现在请你检查是否可以去掉一个点，使所有点都位于y轴的同一边。

## Input

第一行为n。（2<=n<=100000）

接下来为n行Xi和Yi(Xi,Yi的绝对值<=1000000000,Xi!=0)，没有任意两点重合。

## Output

如果可以去掉一个点使所有点位于y轴同一边，输出“Yes”，反之输出“No”。

大写小写都可以。

## Samples

### Sample 1

Input
```
3
1 1
-1 -1
2 -1
```

Output
```
Yes
```

### Sample 2

Input
```
4
1 1
2 2
-1 1
-2 2
```

Output
```
No
```

### Sample 3

Input
```
3
1 2
2 1
4 60
```

Output
```
Yes
```

## Note

第一个样例中，删除第二个点。

第二个样例中，无法达到目标。

第三个样例中，随便删除一个点都可以。
