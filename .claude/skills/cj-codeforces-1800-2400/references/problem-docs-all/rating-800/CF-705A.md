# CF-705A Hulk

## 题面快照

## Description

布鲁斯·班纳博士非常讨厌他的敌人（就像其他人一样）。众所周知，当他变身为不可思议的浩克时，他几乎无法说话。因此，他请你帮忙表达他的感受。

浩克非常喜欢电影《盗梦空间》（Inception），他的感情也如同电影中的梦境一样复杂。一共有 $n$ 层。第一层是 hate，第二层是 love，第三层又是 hate，依此类推……

例如如果 $n=1$，那么他的感受是“I hate it”；如果 $n=2$，则是“I hate that I love it”；如果 $n=3$，则是“I hate that I love that I hate it”，以此类推。

请你帮助班纳博士。

## Input

输入仅一行，包含一个整数 $n$（$1 \le n \le 100$），表示爱与恨的层数。

## Output

输出班纳博士的感受字符串，占一行。

## Samples

### Sample 1

Input
```
1
```

Output
```
I hate it
```

### Sample 2

Input
```
2
```

Output
```
I hate that I love it
```

### Sample 3

Input
```
3
```

Output
```
I hate that I love that I hate it
```
