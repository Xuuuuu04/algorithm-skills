# CF-1180A Alex and a Rhombus

## 题面快照

## Description

在玩几何图形时，Alex 偶然发明了一个关于网格中 $n$ 阶菱形的概念。

一个 $1$ 阶菱形就是一个 $1 \times 1$ 的正方形（即一个单元格）。

对于所有 $n \geq 2$，一个 $n$ 阶菱形是通过在 $n-1$ 阶菱形的基础上，添加所有与其有公共边的单元格得到的（可以参考图片更好地理解）。

![](https://cdn.luogu.com.cn/upload/vjudge_pic/CF1180A/ccf29660dcd8bd16597fff06e6153caa2bd347a9.png)Alex 想让你计算一个 $n$ 阶菱形中包含的单元格数量。

## Input

输入的第一行包含一个整数 $n$（$1 \leq n \leq 100$），表示需要计算单元格数量的菱形的阶数。

## Output

输出一个整数，表示 $n$ 阶菱形中包含的单元格数量。
