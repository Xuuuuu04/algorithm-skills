题目描述

每年，成百上千的人们来到夏令营，在这里他们学习新的算法并解决难题。 这是你在夏令营的第一年，你被要求解决以下问题。从 $1$ 开始的所有整数顺次写成一行。该行的前缀为“123456789101112131415...”。你的任务是输出这个字符串的第 $n$ 位数字（数字从 $1$ 开始编号）。

输入格式

输入仅包含一行，一个整数 $n$（$1 \leq n \leq 1000$），表示你需要输出的数字在字符串中的位置。

输出格式

输出该字符串中的第 $n$ 位数字。

说明/提示

在第一个样例中，第 $3$ 位数字是 '3'，因为整数 $1$ 和 $2$ 都只有一位。 在第二个样例中，第 $11$ 位数字是 '0'，它属于整数 $10$。 由 ChatGPT 5 翻译
