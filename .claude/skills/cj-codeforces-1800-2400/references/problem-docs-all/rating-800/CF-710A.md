# CF-710A King Moves

## 题面快照

## Description

唯有一个国王站在标准国际象棋棋盘上。给定他的当前位置，格式为“cd”，其中 $c$ 是表示列的字母（从 'a' 到 'h'），$d$ 是表示行的数字（从 '1' 到 '8'）。请计算国王在该位置上允许的合法移动步数。

有关国王的移动规则，可以参考此链接：<a>https://en.wikipedia.org/wiki/King_(chess)</a>。

![](https://cdn.luogu.com.cn/upload/vjudge_pic/CF710A/c293477e407dd29c222477fd35652e45e6890a3c.png)国王从位置 e4 移动的路径

## Input

输入仅一行，表示国王的当前位置，格式为“cd”，其中 'c' 取 'a' 到 'h' 的任意字母，'d' 取 '1' 到 '8' 的任意数字。

## Output

输出一个整数 $x$，表示国王可以移动的合法步数。

## Samples

### Sample 1

Input
```
e4
```

Output
```
8
```
