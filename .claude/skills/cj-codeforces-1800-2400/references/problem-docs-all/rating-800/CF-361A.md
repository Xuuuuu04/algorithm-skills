# CF-361A Levko and Table

## 题面快照

## Description

Levko 非常喜欢由 $n$ 行 $n$ 列组成的表格。他尤其喜欢美丽的表格。对 Levko 来说，如果一个表格的每一行和每一列的元素之和都等于 $k$，那么这个表格就是美丽的。

不幸的是，他自己还不会构造这样的表格。你的任务是帮助他至少找出一个满足条件的表格。

## Input

一行，包含两个整数 $n$ 和 $k$，满足 $1 \leq n \leq 100$，$1 \leq k \leq 1000$。

## Output

输出任意一个美丽的表格。Levko 不喜欢太大的数字，因此表格中所有元素的绝对值都不超过 $1000$。

如果满足条件的表格有多种，你可以输出任意一个。

## Samples

### Sample 1

Input
```
2 4
```

Output
```
1 3
3 1
```

### Sample 2

Input
```
4 7
```

Output
```
2 1 0 4
4 0 2 1
1 3 3 0
0 3 2 2
```

## Note

在第一个样例中，第一行的元素之和是 $1+3=4$，第二行是 $3+1=4$，第一列是 $1+3=4$，第二列是 $3+1=4$。对于这个样例，还有其他美丽的表格。

在第二个样例中，每一行和每一列的元素之和都是 $7$。此外，也可以构造满足题目要求的其他表格。
