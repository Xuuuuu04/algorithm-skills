CF1975A Bazoka and Mocha's Array

题目描述

Mocha 喜欢数组，所以在她离开之前，Bazoka 送给了她一个由 $n$ 个正整数组成的数组 $a$ 作为礼物。 现在 Mocha 想知道，经过若干次（可能为零次）以下操作后，数组 $a$ 是否可以变为非递减顺序： - 将数组分成两部分——前缀和后缀，然后交换这两部分。换句话说，设 $a = x + y$，那么我们可以将 $a$ 变为 $a := y + x$。这里 $+$ 表示数组的连接操作。 例如，如果 $a = [3,1,4,1,5]$，我们可以选择 $x = [3,1]$，$y = [4,1,5]$，满足 $a = x + y$。然后我们可以将 $a$ 变为 $y + x = [4,1,5,3,1]$。我们也可以选择 $x = [3,1,4,1,5]$，$y = [\,]$，满足 $a = x + y$。然后我们可以将 $a$ 变为 $y + x = [3,1,4,1,5]$。注意，我们不能选择 $x = [3,1,1]$，$y = [4,5]$，也不能选择 $x = [1,3]$，$y = [5,1,4]$，因为这两种选择都不满足 $a = x + y$。

输入格式

每组测试数据包含多个测试用例。第一行包含测试用例的数量 $t$（$1 \leq t \leq 1000$）。接下来是每个测试用例的描述。 每个测试用例的第一行包含一个整数 $n$（$2 \leq n \leq 50$），表示数组 $a$ 的长度。 每个测试用例的第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \leq a_i \leq 10^6$），表示数组 $a$ 的元素。

输出格式

对于每个测试用例，如果经过若干次操作后 $a$ 可以变为非递减顺序，输出 "Yes"；否则输出 "No"。 你可以用任意大小写组合输出 "Yes" 和 "No"（例如，"yEs"、"yes"、"Yes" 和 "YES" 都会被识别为肯定回答）。

说明/提示
