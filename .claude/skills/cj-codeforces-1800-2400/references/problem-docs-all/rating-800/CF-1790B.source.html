CF1790B Taisia and Dice

题目描述

Taisia 有 $n$ 个六面骰子。每个骰子的六个面分别标有 $1$ 到 $6$ 的数字，每个数字只出现一次。 Taisia 同时掷出所有 $n$ 个骰子，得到了一个数列 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 6$），其中 $a_i$ 表示第 $i$ 个骰子朝上的数字。这个数列的和为 $s$。 突然，Taisia 的宠物猫偷走了其中一个点数最大的骰子（即 $a_i$ 最大的那个），并计算剩下 $n-1$ 个骰子的点数和，记为 $r$。 你只知道骰子的数量 $n$ 以及 $s$、$r$ 的值。请还原出一个满足条件的数列 $a$。

输入格式

第一行包含一个整数 $t$（$1 \le t \le 1000$），表示测试用例的数量。 每个测试用例占一行，包含三个整数 $n$、$s$、$r$（$2 \le n \le 50$，$1 \le r < s \le 300$）。 保证一定存在解。

输出格式

对于每个测试用例，输出 $n$ 个整数 $a_1, a_2, \ldots, a_n$，顺序任意。保证一定存在这样的数列。 如果有多组解，输出任意一组即可。
