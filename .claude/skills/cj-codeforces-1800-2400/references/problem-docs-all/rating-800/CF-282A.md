# CF-282A Bit++

## 题面快照

## Description

Bitland 的经典编程语言是 Bit++。这种语言非常奇特且复杂。

该语言的特点是只有一个变量，记为 $x$。此外，有两种操作：

- 操作 ++ 表示将变量 $x$ 的值加 1。
- 操作 -- 表示将变量 $x$ 的值减 1。

Bit++ 语言中的一条语句由一个操作和一个变量 $x$ 组成。这条语句没有空格，只能包含字符 "+"、"-"、"X"。执行一条语句就是执行其中包含的操作。

一个 Bit++ 程序是一系列语句，需要依次执行。执行程序就是依次执行其中的每一条语句。

你将得到一个 Bit++ 语言的程序。$x$ 的初始值为 $0$。请你执行该程序，并输出 $x$ 的最终值（即程序执行完后变量的值）。

## Input

第一行为一个整数 $n$（$1 \leq n \leq 150$）——程序中的语句数量。

接下来的 $n$ 行，每行包含一条语句。每条语句仅包含一种操作（++ 或 --）以及一个变量 $x$（用大写字母「X」表示）。因此，输入中不存在空语句。运算符和变量的顺序可以任意排列。

## Output

输出一个整数，表示 $x$ 的最终值。

## Samples

### Sample 1

Input
```
1
++X
```

Output
```
1
```

### Sample 2

Input
```
2
X++
--X
```

Output
```
0
```
