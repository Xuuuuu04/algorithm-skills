CF1516A Tit for Tat

题目描述

给定一个长度为 $n$ 的数组 $a$，你最多可以对其进行 $k$ 次如下操作： - 选择数组中的两个不同元素，将第一个元素加 $1$，并将第二个元素减 $1$。但操作后数组的所有元素都必须保持非负。 你能得到的字典序最小的数组是什么？ 如果存在某个下标 $i$ 使得 $x_i < y_i$，且对于所有 $1 \le j < i$ 都有 $x_j = y_j$，则数组 $x$ 被认为比数组 $y$ 字典序更小。简单来说，在第一个不同的位置，$x$ 的元素比 $y$ 的元素小，则 $x$ 字典序更小。

输入格式

第一行包含一个整数 $t$（$1 \le t \le 20$），表示需要解决的测试用例数量。 每个测试用例的第一行包含两个整数 $n$ 和 $k$（$2 \le n \le 100$，$1 \le k \le 10000$），分别表示数组的长度和最多可以进行的操作次数。 每个测试用例的第二行包含 $n$ 个用空格分隔的整数 $a_1, a_2, \ldots, a_n$（$0 \le a_i \le 100$），表示数组 $a$ 的元素。

输出格式

对于每个测试用例，输出经过最多 $k$ 次操作后能得到的字典序最小的数组。

说明/提示

在第二个测试用例中，我们首先将第一个元素减 $1$，并将第二个元素加 $1$。然后无法得到更小字典序的数组，因为不能让任何元素变为负数。 由 ChatGPT 4.1 翻译
