CF617A Elephant

题目描述

## 题意简述 数轴起点坐标为0，终点坐标为x，可以向前移动1/2/3/4/5个单位长度，问最少几步可以从起点到终点。 一只大象决定去拜访他的朋友。结果，大象的房子位于0点0，他的朋友的房子位于点X。每一步大象可以向前移动1、2、3、4或5个位置。问：他最少走多少步才能到达他的朋友的房子。

输入格式

输入共一行，只有一个整数x（$ 1

输出格式

输出共一行，只有一个整数，表示大象到达他的朋友的房子的最少步数。

说明/提示

在第一个样例中，大象需要走一步长度为5，以到达X点。 在第二个样例中，如果大象移动3，5和4步，可以到达X点。还有其他方法三步到达，但大象不能以少于三步的方法到达X点。 感谢@仁和_童博扬 提供的翻译
