CF1303A Erasing Zeroes

题目描述

给定一个字符串 $s$，其中每个字符都是 $0$ 或 $1$。 你希望字符串中的所有 $1$ 都形成一个连续的子段。例如，如果字符串为 $0$、$1$、$00111$ 或 $01111100$，那么所有的 $1$ 都形成了一个连续的子段；如果字符串为 $0101$、$100001$ 或 $11111111111101$，则不满足该条件。 你可以删除字符串中的一些（也可以不删）$0$。你需要删除的 $0$ 的最小数量是多少？

输入格式

第一行包含一个整数 $t$（$1 \le t \le 100$），表示测试用例的数量。 接下来有 $t$ 行，每行一个字符串 $s$（$1 \le |s| \le 100$）；$s$ 的每个字符都是 $0$ 或 $1$。

输出格式

输出 $t$ 个整数，第 $i$ 个整数表示对于第 $i$ 个测试用例，最少需要删除多少个 $0$。

说明/提示

在第一个测试用例中，你需要删除字符串 $010011$ 的第三和第四个字符（变成 $0111$）。 由 ChatGPT 4.1 翻译
