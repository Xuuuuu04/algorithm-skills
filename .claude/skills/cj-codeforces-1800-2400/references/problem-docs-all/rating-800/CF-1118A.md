# CF-1118A Water Buying

## 题面快照

## Description

你需要买$n$升水，现在有两种规格的水瓶：1升水的和2升水的，现给出1升水的单价$a$,2升水的单价$b$，求最少需要花费多少钱。有$q$个询问。

## Input

第一行一个正整数$q$($1 \le q \le 500$)，表示有$q$个询问

接下来有$q$行，每行三个正整数$n,a,b$($1\le n \le 10^{12}$,$1\le a,b \le 1000$)，含义如题

## Output

每行一个正整数，表示最少花费

## Samples

### Sample 1

Input
```
4
10 1 3
7 3 2
1 1000 1
1000000000000 42 88
```

Output
```
10
9
1000
42000000000000
```
