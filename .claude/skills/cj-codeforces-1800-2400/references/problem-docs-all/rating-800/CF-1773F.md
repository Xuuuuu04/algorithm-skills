# CF-1773F Football

## 题面快照

## Description

科学家们正在研究足球比赛结果对球迷情绪的影响。他们有一个假设：平局的数量与球迷未来观看足球比赛的意愿之间存在相关性。

在足球比赛中，两支队伍进行比赛。比赛过程中，队伍会进球。比分“$x$:$y$”表示我们关注的队伍进了 $x$ 个球，丢了 $y$ 个球。如果 $x = y$，则比赛以平局结束。如果 $x > y$，则我们关注的队伍获胜；如果 $x < y$，则该队失利。

为了验证相关性，科学家们收集了低级别联赛球队的比赛结果信息。他们获得的信息包括该队参加的比赛场数（$n$）、这些比赛中进球总数（$a$）以及总失球数（$b$）。

现在给你一支球队的这些信息。请你计算该队比赛中可能出现的最小平局场数，并给出一种比分分配方案，使得平局场数最少。

## Input

第一行包含一个整数 $n$，表示该队参加的比赛场数（$1 \le n \le 100$）。  
第二行包含一个整数 $a$，表示该队在所有 $n$ 场比赛中的总进球数（$0 \le a \le 1000$）。  
第三行包含一个整数 $b$，表示该队在所有 $n$ 场比赛中的总失球数（$0 \le b \le 1000$）。

## Output

第一行输出一个整数 $d$，表示最小的平局场数。

接下来的 $n$ 行，每行输出一个比赛比分，格式为“$x$:$y$”，其中 $x$ 表示该场比赛进球数，$y$ 表示该场比赛失球数，使得恰好有 $d$ 场比赛以平局结束。如果存在多种比分分配方案，输出任意一种均可。
