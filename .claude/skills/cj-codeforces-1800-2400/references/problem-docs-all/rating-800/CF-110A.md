# CF-110A Nearly Lucky Number

## 题面快照

## Description

### 题目要求
如果一个数仅包含4和7，那么它就是一个"幸运数字"。
如果一个数**本身不是**幸运数，但是它所含有的数字4和7的个数之和为一个"幸运数字"，那么它就是一个"类幸运数字"。
给您一个数，请编程判断它是不是"类幸运数字"。

## Input

一行一个整数N(N在64位整数(long long / int64)范围内)。

## Output

一行一个字符串，如果N是"类幸运数字"则输出"YES"，否则输出"NO"。

感谢@PC_DOS 提供翻译

## Samples

### Sample 1

Input
```
40047
```

Output
```
NO
```

### Sample 2

Input
```
7747774
```

Output
```
YES
```

### Sample 3

Input
```
1000000000000000000
```

Output
```
NO
```
