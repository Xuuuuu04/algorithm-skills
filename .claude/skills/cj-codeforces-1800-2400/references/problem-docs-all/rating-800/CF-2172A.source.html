CF2172A ASCII Art Contest

题目描述

三位顶尖的 AI 创意助手——Gemini、ChatGPT 和 Claude——参加了首届 ASCII艺术大赛，他们必须用自己的文本杰作打动由人类组成的评审团。 每位参赛者的得分都在 $80$ 到 $100$（包含）之间。主办方只有在评委的评分“足够接近”时才会公布最终排名，否则会要求评委重新评议。 现给出 Gemini、ChatGPT 和 Claude 的三项得分，请判断比赛结果： - 如果三人中最高分与最低分之差不少于 $10$ 分，输出 check again（说明评分偏差较大，需重新评议）。 - 否则，输出 final X，其中 $X$ 是三人分数的中位数（即将三项分数从小到大排序后排在中间的数）。

输入格式

一行输入三个整数 $g, c, \ell$，分别表示 Gemini、ChatGPT 和 Claude 的分数。 - $80\le g, c, \ell \le 100$

输出格式

请输出一行，内容为题目要求的答案。

说明/提示

由 ChatGPT 5 翻译
