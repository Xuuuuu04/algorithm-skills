CF1825A LuoTianyi and the Palindrome String

题目描述

洛天依给了你一个回文串 $s$，她希望你找出 $s$ 的最长非空子序列且不是回文串的长度。如果不存在这样的子序列，则输出 $-1$。 $^{\dagger}$ 回文串是指正着读和反着读都相同的字符串。例如，字符串 "z"、"aaa"、"aba"、"abccba" 都是回文串，而 "codeforces"、"reality"、"ab" 不是回文串。 $^{\ddagger}$ 如果字符串 $a$ 可以通过从字符串 $b$ 中删除若干（可以为零或全部）字符得到，则称 $a$ 是 $b$ 的子序列。例如，字符串 "a"、"aaa"、"bab" 都是字符串 "abaab" 的子序列，而 "codeforces"、"bbb"、"h" 不是。

输入格式

每组测试数据包含多组测试用例。第一行包含一个整数 $t$（$1 \le t \le 1000$），表示测试用例的数量。接下来每组测试用例包含一行，一个仅由小写英文字母组成的字符串 $s$（$1 \le |s| \le 50$），保证 $s$ 是回文串。

输出格式

对于每个测试用例，输出一个整数，表示最长的非空且不是回文串的子序列的长度。如果不存在这样的子序列，输出 $-1$。

说明/提示

在第一个测试用例中，"abcaba" 是 "abacaba" 的一个子序列，因为我们可以删除 "abacaba" 的第三个字母得到 "abcaba"，且 "abcaba" 不是回文串。可以证明 "abcaba" 是 "abacaba" 的最长非回文子序列之一，因此答案为 $6$。 在第二个测试用例中，我们只能得到 "a" 和 "aa"，它们都是回文串，所以答案为 $-1$。 由 ChatGPT 4.1 翻译
