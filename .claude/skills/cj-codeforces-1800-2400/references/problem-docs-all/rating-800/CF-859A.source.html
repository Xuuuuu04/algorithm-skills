CF859A Declined Finalists

题目描述

今年，和往年一样，MemSQL 邀请了 Start\[c\]up 资格赛中排名前 $25$ 的选手现场参加决赛。但并不是所有符合资格的选手都能负担起去公司参赛的旅行费用。最初，排名前 $25$ 的选手将收到现场比赛的邀请。每位符合资格的选手必须选择接受或拒绝邀请。每当有选手拒绝邀请时，排名尚未被邀请的选手中排名最高者将被邀请顶替这一位置。这个过程会持续，直到有 $25$ 位选手接受邀请为止。 在资格赛结束后，你知道其中 $K$ 位最终进入现场决赛的选手，并且知道他们的资格赛排名（排名从 $1$ 开始，没有并列排名）。请你计算最少有多少名选手拒绝了现场决赛的邀请。

输入格式

输入的第一行为一个整数 $K$，表示你已知的现场决赛选手数量，满足 $1 \leq K \leq 25$。 第二行为 $r_1, r_2, ..., r_K$，表示你已知的现场决赛选手的资格赛排名，满足 $1 \leq r_i \leq 10^6$。所有排名均不相同。

输出格式

输出一个整数，表示最少有多少名选手拒绝了现场决赛的邀请。

说明/提示

在第一个样例中，你知道全部 $25$ 位现场决赛选手。第 $1$、第 $13$、第 $27$ 名的选手必须有人拒绝了邀请，所以答案是 $3$。 由 ChatGPT 5 翻译
