# CF-1791A Codeforces Checking

## 题面快照

## Description

给定一个小写拉丁字母，判断它是否出现在字符串 $\texttt{codeforces}$ 中。

## Input

输入的第一行包含一个整数 $t$（$1 \leq t \leq 26$），表示测试用例的数量。

每个测试用例的唯一一行包含一个字符 $c$，即一个小写拉丁字母。

## Output

对于每个测试用例，如果 $c$ 满足条件，输出 "YES"（不带引号）；否则输出 "NO"（不带引号）。

你可以以任意大小写输出答案（例如，"yEs"、"yes"、"Yes" 和 "YES" 都会被识别为肯定答案）。

## Samples

### Sample 1

Input
```
10
a
b
c
d
e
f
g
h
i
j
```

Output
```
NO
NO
YES
YES
YES
YES
NO
NO
NO
NO
```
