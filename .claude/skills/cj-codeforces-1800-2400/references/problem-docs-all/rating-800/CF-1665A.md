# CF-1665A GCD vs LCM

## 题面快照

## Description

本题有多测。  
给定一个正整数 $n$，求一组正整数 $a$, $b$, $c$, $d$，使得 $a+b+c+d=n$，并且 $\gcd(a,b) = \operatorname{lcm}(c,d)$。本题有 SPJ，求出任意一组即可。

## Input

第一行一个正整数 $t$，表示测试数据组数，接下来 $t$ 行，每行一个正整数 $n$。

## Output

对于每组数据，输出任意一组 $a$, $b$, $c$, $d$。数据保证一定有解。

## Samples

### Sample 1

Input
```
5
4
7
8
9
10
```

Output
```
1 1 1 1
2 2 2 1
2 2 2 2
2 4 2 1
3 5 1 1
```

## Note

$4\le n\le 10^9$  
$1\le t\le 10^4$
