# CF-546A Soldier and Bananas

## 题面快照

## Description

一名士兵想要在商店购买 $w$ 根香蕉。他需要为第一根香蕉支付 $k$ 美元，为第二根香蕉支付 $2k$ 美元，以此类推（也就是说，他需要为第 $i$ 根香蕉支付 $i·k$ 美元）。

他手上有 $n$ 美元。他想知道，为了买到 $w$ 根香蕉，他还需要向他的战友借多少钱？

## Input

第一行包含三个正整数 $k, n, w$（$1 \leq k, w \leq 1000$，$0 \leq n \leq 10^9$），分别表示第一根香蕉的价格、士兵手上原有的钱数和想要购买的香蕉数量。

## Output

输出一个整数，表示士兵需要向战友借的钱数。如果他的钱已经足够购买所需香蕉，则输出 $0$。

## Samples

### Sample 1

Input
```
3 17 4
```

Output
```
13
```
