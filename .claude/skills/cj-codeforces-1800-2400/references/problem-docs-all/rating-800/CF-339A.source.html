CF339A Helpful Maths

题目描述

初学数学的Xenia是个小学三年级的学生。她现在正在学习加法运算。 老师写下了多个数字的和。学生们需要计算出这个和。为了便于计算，这个和只包含数字 1、2 和 3。然而，这对Xenia来说还是不够容易。她才刚开始学会计数，只有在加数按照非递减顺序排列时，她才能计算。例如，她无法计算 $1+3+2+1$，但是可以计算 $1+1+2$ 和 $3+3$。 你获得了黑板上写下来的和。请调整加数的顺序，并打印出一种Xenia能够计算的和。

输入格式

第一行包含一个非空字符串 $s$ —— 这是Xenia需要计算的和。字符串 $s$ 中没有空格。它只包含数字和字符 "+"。此外，$s$ 字符串是 1、2 和 3 的正确和。字符串 $s$ 最多 100 个字符。

输出格式

输出一种新的和，使得Xenia可以计算。
