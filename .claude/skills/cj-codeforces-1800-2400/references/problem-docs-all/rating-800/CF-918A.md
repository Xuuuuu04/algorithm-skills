# CF-918A Eleven

## 题面快照

## Description

Eleven 想为自己挑选一个新名字。作为一群极客，她的朋友们为她想了一个选择名字的算法。Eleven 希望她的新名字恰好有 $n$ 个字符。

她的朋友建议她的名字只包含大写和小写的字母 'O'。具体来说，他们建议名字的第 $i$ 个字母应为大写的 'O'，当且仅当 $i$ 是斐波那契数列中的一个数字，否则为小写的 'o'。名字的字母从 $1$ 到 $n$ 编号。斐波那契数列是指 $f$，满足：

- $f_{1}=1$，
- $f_{2}=1$，
- $f_{n}=f_{n-2}+f_{n-1}$（$n>2$）。

由于她的朋友们太年轻，不知道斐波那契数列是什么，于是请你帮 Eleven 决定她的新名字。

## Input

输入的唯一一行包含一个整数 $n$（$1 \leq n \leq 1000$）。

## Output

输出 Eleven 的新名字，恰好包含 $n$ 个字符。

## Samples

### Sample 1

Input
```
8
```

Output
```
OOOoOooO
```

### Sample 2

Input
```
15
```

Output
```
OOOoOooOooooOoo
```
