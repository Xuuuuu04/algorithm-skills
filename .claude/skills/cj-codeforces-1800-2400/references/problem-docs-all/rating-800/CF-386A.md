# CF-386A Second-Price Auction

## 题面快照

## Description

在本题中，我们考虑一种特殊类型的拍卖，称为“第二高价拍卖”。与普通拍卖一样，有 $n$ 名竞标者，每位竞标者会出价（即他愿意支付的金额）。这是一场密封式拍卖，也就是说，每位竞标者会秘密地把他愿意支付的价格告知拍卖组织者。之后，竞标者中，出价最高者获胜。然而，获胜者最终需要支付的不是他自己报的价格，而是其他竞标者中报出的最高价格（因此被称为第二高价拍卖）。

编写一个程序，读取每位竞标者的出价，并找出获胜者以及他实际需要支付的价格。所有出价都各不相同。

## Input

输入的第一行包含一个整数 $n$（$2 \leq n \leq 1000$），表示竞标者人数。 第二行包含 $n$ 个互不相同的正整数 $p_1, p_2, \ldots, p_n$，用空格隔开，$p_i$ 表示第 $i$ 位竞标者的报价（$1 \leq p_i \leq 10000$）。

## Output

输出一行，包含两个整数：获胜者的编号，以及他需要支付的价格。编号从 1 开始。
