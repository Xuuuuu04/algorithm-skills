CF1703B ICPC Balloons

题目描述

在一场 ICPC 比赛中，气球的分发规则如下： - 每当一支队伍解决一道题目时，该队伍会获得一个气球。 - 第一个解决某道题目的队伍会额外获得一个气球。 比赛共有 $26$ 道题目，编号为 $ \textsf{A} $、$ \textsf{B} $、$ \textsf{C} $、……、$ \textsf{Z} $。你将获得一个字符串 $ s $，表示比赛中题目的被解决顺序，其中第 $i$ 个字符表示有队伍解决了题目 $ s_i $。没有队伍会重复解决同一道题目。请你计算所有队伍一共获得了多少个气球。注意，有些题目可能没有被任何队伍解决。

输入格式

输入的第一行包含一个整数 $ t $（$ 1 \leq t \leq 100 $），表示测试用例的数量。 每个测试用例的第一行包含一个整数 $ n $（$ 1 \leq n \leq 50 $），表示字符串的长度。 每个测试用例的第二行包含一个长度为 $ n $ 的字符串 $ s $，由大写英文字母组成，表示题目的被解决顺序。

输出格式

对于每个测试用例，输出一个整数，表示所有队伍一共获得的气球数量。

说明/提示

在第一个测试用例中，共发放了 $5$ 个气球： - 题目 $ \textsf{A} $ 被解决。该队伍获得 $2$ 个气球：一个因为解决了题目，另一个因为他们是第一个解决 $ \textsf{A} $ 的队伍。 - 题目 $ \textsf{B} $ 被解决。该队伍获得 $2$ 个气球：一个因为解决了题目，另一个因为他们是第一个解决 $ \textsf{B} $ 的队伍。 - 题目 $ \textsf{A} $ 再次被解决。该队伍只获得 $1$ 个气球，因为他们解决了题目，但不是第一个解决 $ \textsf{A} $ 的队伍。 因此，总共发放的气球数为 $2+2+1=5$。在第二个测试用例中，只解决了一道题目。解决该题目的队伍获得 $2$ 个气球：一个因为解决了题目，另一个因为他们是第一个解决 $ \textsf{A} $ 的队伍。 由 ChatGPT 4.1 翻译
