CF1085A Right-Left Cipher

题目描述

Polycarp喜欢密码。 他发明了自己的密码，称为“右-左”（？应该是这个意思吧？）。 “右-左”密码用于加密字符串。 Polycarp使用以下算法加密字符串，$S = S_1S_2S_3 ... S_n$: 他写下$S_1$，他用$S_2$接上当前的单词（即将$S_2$写到当前结果的右边）， 他在$S_3$前面加上当前的单词（即在当前结果的左边写下$S_3$）， 他将$S_4$接上当前单词（即将$S_4$写到当前结果的右侧）， 他在$S_5$前面加上当前的单词（即在当前结果的左边写下$S_5$）... 这么做直到处理完$S$。 举个例子，如果$S = $"techno"，那么处理过程就是： "t" → "te" → "cte" → "cteh" → "ncteh" → "ncteho"。所以加密"techno"后的字符串就是"ncteho"。 现在给你一个字符串$t$，即加密后的字符串，你的任务就是找到原来的字符串$S$

输入格式

只有一行，$t$，加密后的字符串，只包含小写字母，$1

输出格式

一行，原字符串$S$。
