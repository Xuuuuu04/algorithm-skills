# CF-937A Olympiad

## 题面快照

## Description

题意：

现在有n个人，每个人都有一些分数（0<=a[i]<=600）,你要做的是统计有多少种分数（0和重复的都不算）。

## Input

第一行：一个n，接下来的一行里有n个数。

## Output

输出分数的种类。

感谢 @（T_T）   提供的翻译。

## Samples

### Sample 1

Input
```
4
1 3 3 2
```

Output
```
3
```

### Sample 2

Input
```
3
1 1 1
```

Output
```
1
```

### Sample 3

Input
```
4
42 0 0 42
```

Output
```
1
```
