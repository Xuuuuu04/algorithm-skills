# CF-278A Circle Line

## 题面快照

## Description

有$n$个车站排成一个环形，给定$n$个车站之间的距离，求从第$s$个车站到第$t$个车站所需的最短距离。

## Input

第一行给定车站个数$n$。

第二行给定$n$个车站之间的距离，其中第$i$个数表示第$i$个车站到第$i+1$个车站的距离$d_{i}$。特别地，最后一个数表示第一个车站与最后一个车站之间的距离。

第三行给定两个整数$s$和$t$，表示起点和终点。

## Output

输出共一行，表示第$s$个车站到第$t$个车站之间的最短距离。

## Samples

### Sample 1

Input
```
4
2 3 4 9
1 3
```
