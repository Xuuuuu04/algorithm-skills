CF1114A Got Any Grapes?

题目描述

[The Duck song](https://www.youtube.com/watch?v=MtN1YnoL46Q) 为简化问题，我们假设只有三种葡萄：绿色葡萄、紫色葡萄和黑色葡萄。 Andrew、Dmitry 和 Michal 都是葡萄爱好者，但他们对葡萄的偏好各不相同。为了让他们都满意，需要满足以下条件： - Andrew、Dmitry 和 Michal 分别至少要吃 $x$、$y$ 和 $z$ 颗葡萄。 - Andrew 极度偏爱绿色葡萄，因此他只会吃绿色葡萄。 - Dmitry 不喜欢黑色葡萄——除了黑色葡萄外的任何葡萄他都可以吃。换句话说，Dmitry 可以吃绿色和紫色葡萄。 - Michal 口味广泛——他喜欢所有种类的葡萄，只要数量足够即可。 Aki 知道他的朋友们如此喜欢葡萄，于是决定和他们举办一场葡萄派对。他准备了一个盒子，里面有 $a$ 颗绿色葡萄，$b$ 颗紫色葡萄和 $c$ 颗黑色葡萄。 然而，Aki 不确定他准备的葡萄是否足够让每个人都满意。你能帮他判断是否可以分配葡萄让每个人都满意，还是 Aki 需要再去买一些葡萄吗？ 不要求分配完所有的葡萄，因此可能会有一些葡萄剩下。

输入格式

第一行包含三个整数 $x$、$y$ 和 $z$（$1 \le x, y, z \le 10^5$），分别表示 Andrew、Dmitry 和 Michal 想要吃的葡萄数量。 第二行包含三个整数 $a$、$b$ 和 $c$（$1 \le a, b, c \le 10^5$），分别表示盒子中绿色、紫色和黑色葡萄的数量。

输出格式

如果存在一种分配方式可以让每个人都满意，输出 "YES"；否则输出 "NO"。

说明/提示

在第一个样例中，只有一种可能的分配方式： Andrew 应该拿 $1$ 颗绿色葡萄，Dmitry 应该拿剩下的 $3$ 颗绿色葡萄和 $3$ 颗紫色葡萄，Michal 将从剩下的 $3$ 颗黑色葡萄中拿 $2$ 颗。 在第二个测试中，没有可能的分配方式，因为 Andrew 无法吃到足够的绿色葡萄。:( 由 ChatGPT 4.1 翻译
