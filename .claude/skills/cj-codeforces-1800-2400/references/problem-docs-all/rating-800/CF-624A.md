# CF-624A Save Luke

## 题面快照

## Description

****题意****：

现在，有个人站在一条路宽度为 d 的马路上，这条路有两个压路机，而这个人在两个压路机左右端点的中间，两个压路机的移动速度为 v1 和 v2 ，距离为 l ，人可以在两个压路机中间左右任意位置，求人最多的存活时间。

## Input

按顺序输入宽度、距离和两辆压路机的速度，即 d、l、v1、v2。

## Output

这个人最多存活的时间，保留小数点后20位。

由 @是qjx呀 提供。

## Samples

### Sample 1

Input
```
2 6 2 2
```

Output
```
1.00000000000000000000
```

### Sample 2

Input
```
1 9 1 2
```

Output
```
2.66666666666666650000
```
