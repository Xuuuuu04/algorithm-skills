CF2175A Little Fairy's Painting

题目描述

小仙女有一条包含 $10^{18}$ 个格子的丝带，并且有无限种颜色可供选择。丝带的前 $n$ 个格子已经被染色，其中第 $i$ 个格子的颜色为 $a_i$。 小仙女将按顺序从第 $n+1$ 个格子一直染色到第 $10^{18}$ 个格子。对于第 $i$ 个格子： - 小仙女首先统计当前丝带上已有多少种不同的颜色，记为 $c_i$。 - 然后她会把第 $i$ 个格子染为颜色 $c_i$。 请问，第 $10^{18}$ 个格子会被染成什么颜色？

输入格式

每组测试数据包含多组测试用例。第一行包含测试用例个数 $t$（$1 \le t \le 500$）。 接下来每组测试用例描述如下： 每组测试用例的第一行包含一个整数 $n$（$1 \le n \le 100$），表示已经被染色的格子数。 第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^3$），表示各个格子的颜色。

输出格式

对于每个测试用例，输出最后一个格子的颜色。

说明/提示

在第一个示例中，每次丝带上只有一种颜色出现，因此小仙女始终选择颜色 $1$。 在第二个示例中，小仙女会将接下来的 $1000$ 个格子分别染为颜色 $1$ 到 $1000$，之后所有格子都将被染为颜色 $1000$。 由 ChatGPT 5 翻译
