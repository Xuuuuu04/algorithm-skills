# CF-712A Memory and Crow

## 题面快照

## Description

有 $n$ 个整数 $b_1, b_2, ..., b_n$ 被依次写成一排。对于所有的 $i$ 从 $1$ 到 $n$，通过如下方式定义 $a_i$ ：

- 乌鸦最初将 $a_i$ 设为 $0$。
- 然后乌鸦将 $b_i$ 加到 $a_i$，再减去 $b_{i+1}$，再加上 $b_{i+2}$，依此类推，直到第 $n$ 个数为止。即 $a_i = b_i - b_{i+1} + b_{i+2} - b_{i+3} + \cdots$ 。

现在，Memory 给出了所有的 $a_1, a_2, ..., a_n$ 的值，他想让你找回原始顺序的 $b_1, b_2, ..., b_n$。你能做到吗？

## Input

输入的第一行包含一个整数 $n$（$2 \leq n \leq 100000$），表示写成一排的整数个数。

下一行包含 $n$ 个整数，第 $i$ 个数为 $a_i$（$-10^9 \leq a_i \leq 10^9$），表示第 $i$ 个 $a$ 的值。

## Output

输出 $n$ 个整数，依次对应原始序列 $b_1, b_2, ..., b_n$。题目保证答案唯一且所有 $b_i$ 均在 32 位整型范围内。

## Samples

### Sample 1

Input
```
5
6 -4 8 -2 3
```

Output
```
2 4 6 1 3
```

### Sample 2

Input
```
5
3 -2 -1 5 6
```

Output
```
1 -3 4 11 6
```

## Note

在第一个样例中，乌鸦从第 $1$、$2$、$3$、$4$、$5$ 个位置出发分别报告 $6$、$-4$、$8$、$-2$、$3$。可以验证，数列 $2$、$4$、$6$、$1$、$3$ 满足这些结果。例如：$6=2-4+6-1+3$，$-4=4-6+1-3$。

在第二个样例中，数列 $1$、$-3$、$4$、$11$、$6$ 满足乌鸦报告的结果。例如，$5=11-6$，$6=6$。
