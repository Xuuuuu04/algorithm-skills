# CF-1786A1 Non-alternating Deck (easy version)

## 题面快照

## Description

这是该问题的简单版本。在这个版本中，所有的牌都是同一种颜色。

Alice 有 $n$ 张牌，每张牌都是白色的，这些牌叠成一叠。Alice 按如下顺序依次从牌堆顶部分发牌给自己和 Bob：第一步给自己 1 张，第二步给 Bob 2 张，第三步给 Bob 3 张，第四步给自己 4 张，第五步给自己 5 张，第六步给 Bob 6 张，第七步给 Bob 7 张，第八步给自己 8 张，依此类推。也就是说，在第 $i$ 步时，Alice 会将牌堆顶的 $i$ 张牌分给某一位玩家；第一步分给自己，然后每两步轮换一次分牌对象。当某一步剩余的牌不足 $i$ 张时，Alice 会将所有剩余的牌都分给当前玩家，分牌过程就此结束。

![](https://cdn.luogu.com.cn/upload/vjudge_pic/CF1786A1/9b5c59f025613ef63ec148ccf27b2fa7eb55eceb.png)

如图所示，是在有很多牌的情况下 Alice 的前几步操作。请问最后 Alice 和 Bob 各有多少张牌？

## Input

每组测试数据包含多组测试用例。第一行包含一个整数 $t$（$1 \le t \le 200$），表示测试用例的组数。

接下来的每组测试用例包含一行，一个整数 $n$（$1 \le n \le 10^6$），表示牌的总数。

## Output

对于每组测试用例，输出两个整数，分别表示 Alice 和 Bob 最后各自拥有的牌数，顺序为：Alice 的牌数，Bob 的牌数。
