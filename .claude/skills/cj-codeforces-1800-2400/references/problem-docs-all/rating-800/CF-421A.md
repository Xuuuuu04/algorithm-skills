# CF-421A Pasha and Hamsters

## 题面快照

## Description

Pasha 有两只仓鼠：Arthur 和 Alexander。Pasha 在它们面前放了 $n$ 个苹果。Pasha 知道 Arthur 喜欢哪些苹果，同样也知道 Alexander 喜欢哪些苹果。由于这两只仓鼠可能都喜欢某些相同的苹果，Pasha 不希望它们之间发生冲突，因此他决定亲自给两只仓鼠分配苹果。他会将一些苹果分给 Arthur，一些分给 Alexander。每只仓鼠能分到多少苹果无关紧要，但重要的是，每只仓鼠只能获得自己喜欢的苹果。可能会有仓鼠一个苹果都没有分到。

请你帮助 Pasha 把所有苹果分给两只仓鼠。注意，Pasha 想要分掉所有的苹果，而不是其中的一部分。

## Input

第一行包含三个整数 $n$、$a$、$b$，$(1 \leq n \leq 100;\ 1 \leq a,b \leq n)$，分别表示苹果的总数，Arthur 喜欢的苹果数，Alexander 喜欢的苹果数。

第二行包含 $a$ 个不同的整数，表示 Arthur 喜欢的苹果编号。

第三行包含 $b$ 个不同的整数，表示 Alexander 喜欢的苹果编号。

假设苹果的编号从 $1$ 到 $n$。输入保证一定有解。

## Output

输出 $n$ 个字符，每个字符为 1 或 2。如果第 $i$ 个字符是 1，则表示第 $i$ 个苹果分给 Arthur，否则分给 Alexander。如果有多种合法分法，你可以输出任意一种。

## Samples

### Sample 1

Input
```
4 2 3
1 2
2 3 4
```

Output
```
1 1 2 2
```

### Sample 2

Input
```
5 5 2
3 4 1 2 5
2 3
```

Output
```
1 1 1 1 1
```
