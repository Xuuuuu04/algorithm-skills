CF1772B Matrix Rotation

题目描述

你有一个 $2 \times 2$ 的矩阵，矩阵中的元素都是互不相同的整数。你希望将你的矩阵变得“美丽”。如果矩阵满足以下两个条件，则称其为美丽的： - 每一行中，第一个元素小于第二个元素； - 每一列中，第一个元素小于第二个元素。 ![](https://cdn.luogu.com.cn/upload/vjudge_pic/CF1772B/3883cb5d5c3c3237649026ca712db7066e7d51ae.png) 你可以对矩阵进行如下操作任意次：顺时针旋转 $90$ 度。这样，左上角元素会移动到右上角，右上角元素会移动到右下角，依此类推： ![](https://cdn.luogu.com.cn/upload/vjudge_pic/CF1772B/a844c7395726cf76b3147efc79ccce4d8f167fbf.png) 请判断是否可以通过若干次（可以为零次）操作，使矩阵变得美丽。

输入格式

第一行包含一个整数 $t$（$1 \le t \le 1000$），表示测试用例的数量。 每个测试用例包含两行，每行包含两个整数，表示矩阵对应行的元素。在每个矩阵中，四个元素都是 $1$ 到 $100$ 之间互不相同的整数。

输出格式

对于每个测试用例，如果可以将矩阵变得美丽，输出 YES，否则输出 NO。你可以用任意大小写输出（YES、yes、Yes 都视为正答，NO、no、nO 都视为负答）。
