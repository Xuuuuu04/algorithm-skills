CF361A Levko and Table

题目描述

Levko 非常喜欢由 $n$ 行 $n$ 列组成的表格。他尤其喜欢美丽的表格。对 Levko 来说，如果一个表格的每一行和每一列的元素之和都等于 $k$，那么这个表格就是美丽的。 不幸的是，他自己还不会构造这样的表格。你的任务是帮助他至少找出一个满足条件的表格。

输入格式

一行，包含两个整数 $n$ 和 $k$，满足 $1 \leq n \leq 100$，$1 \leq k \leq 1000$。

输出格式

输出任意一个美丽的表格。Levko 不喜欢太大的数字，因此表格中所有元素的绝对值都不超过 $1000$。 如果满足条件的表格有多种，你可以输出任意一个。

说明/提示

在第一个样例中，第一行的元素之和是 $1+3=4$，第二行是 $3+1=4$，第一列是 $1+3=4$，第二列是 $3+1=4$。对于这个样例，还有其他美丽的表格。 在第二个样例中，每一行和每一列的元素之和都是 $7$。此外，也可以构造满足题目要求的其他表格。 由 ChatGPT 5 翻译
