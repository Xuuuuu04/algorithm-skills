# CF-760A Petr and a calendar

## 题面快照

## Description

Petr 想为当前月份制作一个日历。为此，他绘制了一个表格，其中每一列对应一周（每周包括从星期一到星期日的七天），每一行对应一个星期中的一天，单元格中填写日期。例如，2017 年 1 月的日历应如下图所示：

![](https://cdn.luogu.com.cn/upload/vjudge_pic/CF760A/70f7bb298739f0018d24699e43e0bdba58d6965c.png)

Petr 想知道，给定一个月份和该月第一天是星期几，他的表格应该有多少列？假设年份为非闰年。

## Input

一行包含两个整数 $m$ 和 $d$（$1 \leq m \leq 12$，$1 \leq d \leq 7$）——分别代表月份的编号（1 表示 1 月，12 表示 12 月）和该月第一天对应的星期几（1 表示星期一，7 表示星期日）。

## Output

输出一个整数，表示表格应有的列数。

## Samples

### Sample 1

Input
```
1 7
```

Output
```
6
```

### Sample 2

Input
```
1 1
```

Output
```
5
```

### Sample 3

Input
```
11 6
```

Output
```
5
```

## Note

第一个样例对应描述中的 2017 年 1 月份的日历图片。

第二个样例中，1 月 1 日是星期一，整个 1 月可放在 5 列内。

第三个样例中，11 月 1 日是星期六，5 列即可。
