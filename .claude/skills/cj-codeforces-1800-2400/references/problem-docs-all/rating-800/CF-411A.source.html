CF411A Password Check

题目描述

你可能已经在互联网站点上注册过许多次，每次都需要输入你自己创建的密码。通常注册表单会自动检测密码的安全性。如果用户的密码不够复杂，就会弹出提示信息。今天你的任务就是实现这样一个自动检测功能。 公司 Q 的网页开发者们认为，如果一个密码满足以下所有条件，则密码足够复杂： - 密码长度至少为 5 个字符； - 密码至少包含一个大写英文字母； - 密码至少包含一个小写英文字母； - 密码至少包含一个数字。 现已给定一个密码，请为公司 Q 实现自动复杂度检测。

输入格式

第一行包含一个非空的字符序列（最多 $100$ 个字符）。每个字符可能是大写英文字母、小写英文字母、数字，或者字符："!"、"?"、"."、","、"\_"。

输出格式

如果密码足够复杂，输出 "Correct"（不含引号）；否则输出 "Too weak"（不含引号）。
