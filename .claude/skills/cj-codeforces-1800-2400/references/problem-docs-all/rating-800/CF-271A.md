# CF-271A Beautiful Year

## 题面快照

## Description

似乎 2013 年仿佛就在昨天。你知道一个有趣的事实吗？2013 年是自 1987 年之后，第一个所有数字都互不相同的年份。

现在给你一个问题：给定一个年份，找到比它严格大且所有数字都不相同的最小年份。

## Input

一行包含一个整数 $y$（$1000 \leq y \leq 9000$）——年份。

## Output

输出一个整数——严格大于 $y$ 的、所有数字互不相同的最小年份。保证一定存在答案。

## Samples

### Sample 1

Input
```
1987
```

Output
```
2013
```

### Sample 2

Input
```
2013
```

Output
```
2014
```
