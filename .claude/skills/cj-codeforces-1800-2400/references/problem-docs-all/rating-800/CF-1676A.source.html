题目描述

一张票据是由六位数字组成的字符串。如果前三位数字之和等于后三位数字之和，则这张票据被认为是“幸运的”。给定一张票据，判断它是否是幸运的。注意，票据可以有前导零。

输入格式

输入的第一行包含一个整数 $t$（$1 \leq t \leq 10^3$），表示测试用例的数量。 每个测试用例的描述占一行，包含一个由六位数字组成的字符串。

输出格式

输出 $t$ 行，每行对应一个测试用例的答案。如果给定的票据是幸运的，输出 "YES"；否则输出 "NO"。 你可以以任意大小写输出答案（例如，"yEs"、"yes"、"Yes" 和 "YES" 都会被识别为肯定答案）。

说明/提示

在第一个测试用例中，前三位数字之和为 $2 + 1 + 3 = 6$，后三位数字之和为 $1 + 3 + 2 = 6$，它们相等，所以答案是 "YES"。 在第二个测试用例中，前三位数字之和为 $9 + 7 + 3 = 19$，后三位数字之和为 $8 + 9 + 4 = 21$，它们不相等，所以答案是 "NO"。 在第三个测试用例中，前三位数字之和为 $0 + 4 + 5 = 9$，后三位数字之和为 $2 + 0 + 7 = 9$，它们相等，所以答案是 "YES"。 由 ChatGPT 4.1 翻译
