CF177A2 Good Matrix Elements

题目描述

ABBYY 的聪明海狸迷上了方阵。现在他正在研究一个大小为 $n \times n$ 的矩阵，其中 $n$ 是奇数。聪明海狸认为以下矩阵元素是“好”的： - 主对角线上的元素。 - 副对角线上的元素。 - “中间”行上的元素——即上方和下方各有 $\frac{n-1}{2}$ 行的那一行。 - “中间”列上的元素——即左侧和右侧各有 $\frac{n-1}{2}$ 列的那一列。 下图展示了一个 $5 \times 5$ 的矩阵。绿色标记的元素即为“好”的元素。请帮助聪明海狸计算给定矩阵中所有“好”元素的和。

输入格式

输入的第一行包含一个奇整数 $n$。接下来的 $n$ 行，每行包含 $n$ 个用空格分隔的整数 $a_{ij}$，表示矩阵的元素，$0 \leq a_{ij} \leq 100$。 获得 30 分的输入范围： - $1 \leq n \leq 5$ 获得 100 分的输入范围： - $1 \leq n \leq 101$

输出格式

输出一个整数，表示所有“好”元素的和。
