CF791A Bear and Big Brother

题目描述

**题意翻译** 给定两个数 $a, b$，每个单位时间中，$a \leftarrow a \times 3,b\leftarrow b\times 2$，求在第多少个单位时间时，$a>b$。

输入格式

共一行，为两个正整数 $a,b$，详见题面。

输出格式

共一行，为在第多少个单位时间时，$a>b$。
