# CF-486A Calculating Function

## 题面快照

## Description

对于一个正整数 $n$，定义函数 $f$ 为：

$$
f(n) = -1 + 2 - 3 + \dots + (-1)^{n} n
$$

你的任务是，对于给定的整数 $n$，计算 $f(n)$。

## Input

一行包含一个正整数 $n$（$1 \leq n \leq 10^{15}$）。

## Output

输出一行，表示 $f(n)$ 的值。

## Samples

### Sample 1

Input
```
4
```

Output
```
2
```

### Sample 2

Input
```
5
```

Output
```
-3
```

## Note

$f(4) = -1 + 2 - 3 + 4 = 2$

$f(5) = -1 + 2 - 3 + 4 - 5 = -3$
