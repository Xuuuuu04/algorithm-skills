CF1438A Specific Tastes of Andre

题目描述

Andre 有非常独特的品味。最近他开始喜欢上了数组。 Andre 称一个非空数组 $b$ 是好的，如果它的所有元素之和能被该数组的长度整除。例如，数组 $[2, 3, 1]$ 是好的，因为其元素之和 $6$ 能被 $3$ 整除；但数组 $[1, 1, 2, 3]$ 不是好的，因为 $7$ 不能被 $4$ 整除。 Andre 称长度为 $n$ 的数组 $a$ 是完美的，如果满足以下条件： - 该数组的每一个非空子数组都是好的。 - 对于每个 $i$（$1 \le i \le n$），都有 $1 \leq a_i \leq 100$。 给定一个正整数 $n$，请输出任意一个长度为 $n$ 的完美数组。可以证明，在给定的约束条件下，总是存在这样的数组。 数组 $c$ 是数组 $d$ 的子数组，如果 $c$ 可以通过从 $d$ 的开头和结尾各删除若干（可能为零或全部）元素得到。

输入格式

每组测试数据包含多组测试用例。第一行包含一个整数 $t$（$1 \le t \le 100$），表示测试用例的数量。接下来的每组测试用例，每组仅包含一行，一个整数 $n$（$1 \le n \le 100$）。

输出格式

对于每组测试用例，输出任意一个长度为 $n$ 的完美数组，每组输出占一行。

说明/提示

数组 $[19, 33]$ 是完美的，因为它的所有 $3$ 个子数组：$[19]$、$[33]$、$[19, 33]$，它们的元素之和都能被对应的长度整除，因此都是好的。 由 ChatGPT 4.1 翻译
