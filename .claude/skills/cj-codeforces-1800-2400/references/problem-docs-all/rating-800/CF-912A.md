# CF-912A Tricky Alchemy

## 题面快照

## Description

在寒假期间，圣诞球的需求异常高涨。由于现在已经是 $2018$ 年，炼金技术的进步使得利用魔法水晶轻松且高效地制造圣诞球成为可能。

Grisha 需要获得一些黄色、绿色和蓝色的圣诞球。已知制作一个黄色圣诞球需要两个黄色水晶，制作一个绿色圣诞球需要一个黄色水晶和一个蓝色水晶，而制作一个蓝色圣诞球只需三个蓝色水晶。

现在，Grisha 手中有 $A$ 个黄色水晶和 $B$ 个蓝色水晶。请你计算，Grisha 至少还需要再获得多少个水晶才能制造出所需数量的圣诞球。

## Input

第一行包含两个整数 $A$ 和 $B$（$0 \leq A, B \leq 10^{9}$），分别表示 Grisha 当前拥有的黄色和蓝色水晶的数量。

第二行包含三个整数 $x$，$y$ 和 $z$（$0 \leq x, y, z \leq 10^{9}$），分别表示需要获得的黄色、绿色和蓝色圣诞球的数量。

## Output

输出一个整数，表示 Grisha 最少还需要再获得多少个水晶。
