# CF-1047A Little C Loves 3 I

## 题面快照

## Description

**题目大意：**
找三个数$a,b,c$，使得$a+b+c==n$且$a,b,c$都不能被$3$整除

## Input

一行一个正整数$n$

## Output

三个正整数$a,b,c$，输出任意一组即可

## Samples

### Sample 1

Input
```
3
```

Output
```
1 1 1
```

### Sample 2

Input
```
233
```

Output
```
77 77 79
```
