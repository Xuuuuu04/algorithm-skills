CF1422A Fence

题目描述

Yura 需要建造一个封闭的篱笆，其形状为任意非退化的简单四边形。他已经有了三段已知长度的直线篱笆段，长度分别为 $a$、$b$ 和 $c$。现在他需要确定第四段直线篱笆的某个可能的整数长度 $d$，使得可以用这四段篱笆建成一个四边形篱笆。换句话说，这个篱笆应当是一个边长分别为 $a$、$b$、$c$ 和 $d$ 的四边形。请帮助 Yura，找出第四边的任意一个可能的长度。 一个非退化的简单四边形是指没有三点共线且不自交的四边形。

输入格式

第一行包含一个整数 $t$，表示测试用例的数量（$1 \le t \le 1000$）。接下来的 $t$ 行，每行描述一个测试用例。 每行包含三个整数 $a$、$b$ 和 $c$，表示三段篱笆的长度（$1 \le a, b, c \le 10^9$）。

输出格式

对于每个测试用例，输出一个整数 $d$，表示可以用来建造篱笆的第四段篱笆的长度。如果有多个答案，输出任意一个即可。可以证明总是存在解。

说明/提示

我们可以用长度为 $1$、$2$、$3$、$4$ 的边建成一个四边形。 我们可以用长度为 $12$、$34$、$56$、$42$ 的边建成一个四边形。 由 ChatGPT 4.1 翻译
