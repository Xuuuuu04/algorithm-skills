题目描述

Berland 语言由恰好两个字母组成的单词构成。此外，一个单词的第一个字母与第二个字母不同。任意两个不同的 Berland 字母（顺便说一下，这些字母与小写拉丁字母相同）的组合，都是 Berland 语言中的合法单词。 Berland 字典包含了该语言的所有单词。单词的排列顺序与通常字典的排序方式相同。形式化地说，单词 $a$ 在字典中排在单词 $b$ 之前，当且仅当满足以下条件之一： - $a$ 的第一个字母小于 $b$ 的第一个字母； - $a$ 和 $b$ 的第一个字母相同，且 $a$ 的第二个字母小于 $b$ 的第二个字母。 因此，字典的排列如下： - 单词 $1$：ab - 单词 $2$：ac - ... - 单词 $25$：az - 单词 $26$：ba - 单词 $27$：bc - ... - 单词 $649$：zx - 单词 $650$：zy 现在给定一个 Berland 语言中的单词 $s$，请你找出它在字典中的序号。

输入格式

第一行包含一个整数 $t$（$1 \le t \le 650$），表示测试用例的数量。 每个测试用例包含一行，包含一个字符串 $s$，即由两个不同的小写拉丁字母组成的字符串（即 Berland 语言中的合法单词）。

输出格式

对于每个测试用例，输出一个整数，表示单词 $s$ 在字典中的序号。
