# CF-595A Vitaly and Night

## 题面快照

## Description

一天晚上，Vitaly 很晚才回家，他在想：这个时候有多少人还没睡觉？为了估算，Vitaly 决定看看他路过的一栋楼里哪些窗户还亮着灯。

Vitaly 看到一栋有 $n$ 层的建筑，每层有 $2m$ 扇窗户。每层楼有 $m$ 套公寓，编号从 $1$ 到 $m$，每套公寓有连续的两扇窗户。如果按从左到右编号，每层楼的第 $j$ 套公寓对应第 $2j-1$ 和 $2j$ 号窗户（楼层按照从下到上编号）。Vitaly 认为，如果某套公寓至少有一扇窗户亮着灯，那么这套公寓里的人此时还没睡觉。

给定这栋房子的窗户亮灯情况，请你计算有多少套公寓里根据 Vitaly 的判断还有人没睡。

## Input

第一行包含两个整数 $n$ 和 $m$（$1\le n,m\le 100$），分别表示楼层数和每层的公寓数。

接下来有 $n$ 行，每行有 $2m$ 个字符，描述从顶层到底层每层的窗户情况。对于每层，如果第 $i$ 个窗户亮着灯，则该行第 $i$ 个字符为 '1'，否则为 '0'。

## Output

输出一个整数，表示至少有一扇窗户亮着灯的公寓数量，即 Vitaly 认为此时还没睡觉的公寓数量。

## Samples

### Sample 1

Input
```
2 2
0 0 0 1
1 0 1 1
```

Output
```
3
```

### Sample 2

Input
```
1 3
1 1 0 1 0 0
```

Output
```
2
```

## Note

在第一个测试样例中，这栋楼有两层，每层有两套公寓，总共有 4 套公寓。只有二楼左侧的公寓两扇窗户都没有亮灯。

在第二个测试样例中，这栋楼有一层，这一层有三套公寓。最左侧公寓两扇窗户都有灯，正中间公寓至少有一扇窗户有灯，右侧公寓两扇窗户都没灯。
