# CF-785A Anton and Polyhedrons

## 题面快照

## Description

Anton 最喜欢的几何体是正多面体。需要注意的是，正多面体一共有五种：

- 四面体。四面体有 $4$ 个三角形面。
- 立方体。立方体有 $6$ 个正方形面。
- 八面体。八面体有 $8$ 个三角形面。
- 十二面体。十二面体有 $12$ 个五边形面。
- 二十面体。二十面体有 $20$ 个三角形面。

下图展示了所有五种正多面体：

![](https://cdn.luogu.com.cn/upload/vjudge_pic/CF785A/19c5088ea45f2a6c0e1d14f3df7fa76121b5787c.png)

Anton 拥有一组共 $n$ 个正多面体。一天他想知道，自己这些正多面体一共拥有多少个面。请你帮 Anton 计算这些正多面体一共有多少个面。

## Input

输入的第一行包含一个整数 $n$ $(1 \leq n \leq 200000)$，表示 Anton 收藏的正多面体的数量。

接下来的 $n$ 行中，每一行包含一个字符串 $s_i$，表示 Anton 收藏的第 $i$ 个正多面体的名称。字符串可能为如下之一：

- “Tetrahedron”，如果第 $i$ 个多面体是四面体。
- “Cube”，如果第 $i$ 个多面体是立方体。
- “Octahedron”，如果第 $i$ 个多面体是八面体。
- “Dodecahedron”，如果第 $i$ 个多面体是十二面体。
- “Icosahedron”，如果第 $i$ 个多面体是二十面体。

## Output

输出一个数字，表示 Anton 所有正多面体的面数总和。

## Samples

### Sample 1

Input
```
4
Icosahedron
Cube
Tetrahedron
Dodecahedron
```

Output
```
42
```

### Sample 2

Input
```
3
Dodecahedron
Octahedron
Octahedron
```

Output
```
28
```

## Note

在第一个样例中，Anton 有一个二十面体、一个立方体、一个四面体和一个十二面体。二十面体有 $20$ 个面，立方体有 $6$ 个面，四面体有 $4$ 个面，十二面体有 $12$ 个面。它们一共有 $20+6+4+12=42$ 个面。
