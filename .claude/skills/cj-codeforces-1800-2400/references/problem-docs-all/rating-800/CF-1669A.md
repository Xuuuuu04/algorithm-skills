# CF-1669A Division?

## 题面快照

## Description

Codeforces 根据用户的分数将其分为 $4$ 个组别：

- 第一组别：$1900 \leq \mathrm{rating}$
- 第二组别：$1600 \leq \mathrm{rating} \leq 1899$
- 第三组别：$1400 \leq \mathrm{rating} \leq 1599$
- 第四组别：$\mathrm{rating} \leq 1399$

给定一个分数 $\mathrm{rating}$，请输出该分数所属的组别。

## Input

输入的第一行包含一个整数 $t$（$1 \leq t \leq 10^4$），表示测试用例的数量。

接下来的每个测试用例包含一行，一个整数 $\mathrm{rating}$（$-5000 \leq \mathrm{rating} \leq 5000$）。

## Output

对于每个测试用例，输出一行，格式为 "Division X"，其中 $X$ 是 $1$ 到 $4$ 之间的整数，表示该分数所属的组别。

## Samples

### Sample 1

Input
```
7
-789
1299
1300
1399
1400
1679
2300
```

Output
```
Division 4
Division 4
Division 4
Division 4
Division 3
Division 2
Division 1
```

## Note

对于第 $1$ 到 $4$ 个测试用例，对应的分数分别为 $-789$、$1299$、$1300$、$1399$，因此它们都属于第 $4$ 组别。

对于第 $5$ 个测试用例，分数为 $1400$，因此属于第 $3$ 组别。

对于第 $6$ 个测试用例，分数为 $1679$，因此属于第 $2$ 组别。

对于第 $7$ 个测试用例，分数为 $2300$，因此属于第 $1$ 组别。
