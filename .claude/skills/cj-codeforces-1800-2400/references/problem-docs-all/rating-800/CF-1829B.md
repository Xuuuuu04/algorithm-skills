# CF-1829B Blank Space

## 题面快照

## Description

给定一个长度为 $n$ 的二进制数组 $a$，二进制数组是指只包含 $0$ 和 $1$ 的数组。

“空白区间”指的是一段连续的、只包含 $0$ 的元素的区间。

你的任务是找出最长空白区间的长度。

## Input

第一行包含一个整数 $t$（$1 \leq t \leq 1000$），表示测试用例的数量。

每个测试用例的第一行包含一个整数 $n$（$1 \leq n \leq 100$），表示数组的长度。

每个测试用例的第二行包含 $n$ 个用空格分隔的整数 $a_i$（$0 \leq a_i \leq 1$），表示数组的元素。

## Output

对于每个测试用例，输出一个整数，表示最长空白区间的长度。

## Samples

Input
```
5
5
1 0 0 1 0
4
0 1 1 1
1
0
3
1 1 1
9
1 0 0 0 1 0 0 0 1
```

Output
```

```
