# CF-1614A Divan and a Store

## 题面快照

## Description

给定一个长为 $n$ 的数组 $a$，从中选出若干个在 $[l,r]$ 区间的数，使得总和不大于 $k$。求最多个数。

## Input

第一行一个 $t$，表示数据组数。

每一组数据中：

第一行有四个整数  $ n $ , $ l $ , $ r $ , $ k $ ( $ 1 \le n \le 100 $ , $ 1 \le l \le r \le 10^9 $ , $ 1 \le k \le 10^9 $ )。

第二行有 $n$ 个整数，表示数组 $a$。

## Output

对于每一组数据输出一行一个整数，表示最大个数。
