CF469A I Wanna Be the Guy

题目描述

有一个名叫“I Wanna Be the Guy”的游戏，它包含 $n$ 个关卡。小 X 和他的朋友小 Y 沉迷于这个游戏，他们俩都想通关整个游戏。 小 X 只能通过这个游戏中的 $p$ 个关卡，小 Y 只能通过 $q$ 个关卡。已知小 X 能通过的关卡编号和小 Y 能通过的关卡编号，若他们合作，能通关整个游戏吗？

输入格式

第一行包含一个整数 $n$（$1 \leq n \leq 100$）。 接下来一行首先是一个整数 $p$（$0 \leq p \leq n$），后面跟着 $p$ 个不同的整数 $a_1,a_2,\ldots,a_p$（$1 \leq a_i \leq n$），这些整数表示小 X 能通过的关卡编号。再下一行以相同的格式给出小 Y 能通过的关卡。假定关卡编号为1到 $n$ 。

输出格式

如果他们能通过所有关卡，输出 `I become the guy.`。如果不能，输出 `Oh, my keyboard!`。

说明/提示

**数据范围** 对于 100% 的数据，$1 \leq n \leq 100$，$0 \leq p \leq n$，$1 \leq a_i \leq n$。 **样例解释** 在第一个样例中，小 X 能通过的关卡是`[1,2,3]`，小 Y 能通过的关卡是`[2,4]`，所以他们合作能通过所有关卡。 在第二个样例中，没有人能通过第4关。
