# CF-837A Text Volume

## 题面快照

## Description

给定一段由单个空格分隔单词组成的文本，单词只包含小写和大写拉丁字母。

一个单词的“音量”定义为该单词中大写字母的个数。文本的“音量”是所有单词音量的最大值。

请计算给定文本的音量。

## Input

第一行包含一个整数 $n$（$1 \leq n \leq 200$）——文本的长度。

第二行包含由单个空格分隔的文本 $s_1, s_2, ..., s_i$，每个单词只由小写和大写拉丁字母组成。

## Output

输出一个整数，表示文本的音量。

## Samples

### Sample 1

Input
```
7
NonZERO
```

Output
```
5
```

### Sample 2

Input
```
24
this is zero answer text
```

Output
```
0
```

### Sample 3

Input
```
24
Harbour Space University
```

Output
```
1
```

## Note

在第一个样例中，只有一个单词，该单词中有 5 个大写字母。

在第二个样例中，所有单词中均无大写字母。

由 ChatGPT 5 翻译
