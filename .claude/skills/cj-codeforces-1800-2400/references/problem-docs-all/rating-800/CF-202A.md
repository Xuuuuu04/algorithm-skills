# CF-202A LLPS

## 题面快照

## Description

给你一个字符串 $S$，你要在字符串中选一些字符（一个也行），使它们组成一个回文字符串，输出可以组成的最大回文串（按字典序排）。

## Input

一个不为空串的字符串 $S$，$S$只包含小写字母，且长度不超过 $10$。

## Output

一个字符串，即最大回文串。

## Samples

### Sample 1

Input
```
radar
```

Output
```
rr
```

### Sample 2

Input
```
bowwowwow
```

Output
```
wwwww
```

### Sample 3

Input
```
codeforces
```

Output
```
s
```

### Sample 4

Input
```
mississipp
```

Output
```
ssss
```

## Note

第一个样例“rader”中可以得到的回文串为"a", "d", "r", "aa", "rr", "ada", "rar", "rdr", "raar" and "radar"，其中“rr“最大。
