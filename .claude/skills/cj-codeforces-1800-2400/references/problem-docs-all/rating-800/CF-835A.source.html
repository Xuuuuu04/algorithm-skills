CF835A Key races

题目描述

两个男孩决定在网站“Key races”上比拼打字。在比赛中，他们需要输入一段长度为 $s$ 个字符的文本。第一个参赛者输入一个字符需要 $v_1$ 毫秒，Ping 值为 $t_1$ 毫秒。第二个参赛者输入一个字符需要 $v_2$ 毫秒，Ping 值为 $t_2$ 毫秒。 如果连接 Ping（延迟）为 $t$ 毫秒，则比赛过程如下： 1. 比赛开始后恰好 $t$ 毫秒后，参赛者收到需要输入的文本。 2. 紧接着他便开始输入。 3. 输入完成全部文本后，恰好 $t$ 毫秒后，网站收到相关信息。 获胜者为其成绩信息最先送达网站的参赛者。如果两位选手的信息同时到达，则判为平局。 给定文本长度以及参赛者的相关信息，判断比赛结果。

输入格式

第一行包含五个整数 $s$、$v_1$、$v_2$、$t_1$、$t_2$（$1 \leq s, v_1, v_2, t_1, t_2 \leq 1000$），分别表示文本的字符数、第一个参赛者每输入一个字符所需时间、第二个参赛者每输入一个字符所需时间、第一个参赛者的 Ping 和第二个参赛者的 Ping。

输出格式

如果第一个参赛者获胜，输出 "First"；如果第二个参赛者获胜，输出 "Second"；如果平局，输出 "Friendship"。

说明/提示

在第一个样例中，第一个参赛者的信息在 $7$ 毫秒送达，第二个参赛者的信息在 $14$ 毫秒送达，所以第一个参赛者获胜。 在第二个样例中，第一个参赛者的信息在 $11$ 毫秒送达，第二个参赛者的信息在 $5$ 毫秒送达，所以第二个参赛者获胜。 在第三个样例中，两位参赛者的信息均在 $22$ 毫秒送达，所以是平局。 由 ChatGPT 5 翻译
