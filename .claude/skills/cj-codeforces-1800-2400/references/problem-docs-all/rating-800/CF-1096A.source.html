CF1096A Find Divisible

题目描述

给定一个正整数区间 $l$ 到 $r$。 请你找到一对整数 $(x, y)$，满足 $l \le x, y \le r$，$x \ne y$ 且 $x$ 能整除 $y$。 如果有多组答案，输出任意一组即可。 你还需要回答 $T$ 个独立的询问。

输入格式

第一行包含一个整数 $T$（$1 \le T \le 1000$），表示询问的数量。 接下来的 $T$ 行，每行包含两个整数 $l$ 和 $r$（$1 \le l \le r \le 998244353$），表示区间的左右端点（包含端点）。 保证每个询问都至少存在一组满足条件的整数对。

输出格式

输出 $T$ 行，每行输出两个整数 $x$ 和 $y$，满足 $l \le x, y \le r$，$x \ne y$ 且 $x$ 能整除 $y$。第 $i$ 行的答案对应输入的第 $i$ 个询问。 如果有多组答案，输出任意一组即可。
