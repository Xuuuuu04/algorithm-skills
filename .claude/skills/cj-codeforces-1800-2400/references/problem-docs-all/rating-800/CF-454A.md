# CF-454A Little Pony and Crystal Mine

## 题面快照

## Description

暮光闪闪曾经从水晶矿获得了一块水晶。一个大小为 $n$（$n$ 是奇数且 $n>1$）的水晶，是一个 $n \times n$ 的矩阵，其中内嵌有一个菱形。

给定一个奇数 $n$，你需要画出一个大小为 $n$ 的水晶。矩阵中属于菱形的格子，用字符 "D" 表示，其他格子则用字符 "\*" 表示。请参见示例以了解你需要绘制的内容。

## Input

一行，一个整数 $n$（$3 \leq n \leq 101$，且 $n$ 是奇数）。

## Output

输出一个 $n$ 大小的水晶。

## Samples

### Sample 1

Input
```
3
```

Output
```
*D*
DDD
*D*
```

### Sample 2

Input
```
5
```

Output
```
**D**
*DDD*
DDDDD
*DDD*
**D**
```

### Sample 3

Input
```
7
```

Output
```
***D***
**DDD**
*DDDDD*
DDDDDDD
*DDDDD*
**DDD**
***D***
```
