# CF-1285A Mezo Playing Zoma

## 题面快照

## Description

### 题意简述

给定长度为 $n$ 的字符串，只包含 `L` 和 `R`。这是一个命令串。

有一个机器人会按照顺序执行字符串上的命令。它一开始在点 $0$。如果当前命令是 `L`，那么它会向左移动一单位距离。如果当前命令是 `R`，那么它会向右移动一单位距离。

机器人是坏的，它可能会只执行一部分命令，并且我们不知道机器人会执行哪些命令。您需要求出机器人执行完命令后可能会停在的点的数量。

## Input

第一行一个正整数 $n(1\leq n \leq 10^5)$。

接下来一行一个长度为 $n$ 的字符串，只包含 `L` 和 `R`。

## Output

输出一行一个整数，表示机器人执行完命令后可能会停在的点的数量。

翻译贡献者 U108949

## Samples

### Sample 1

Input
```
4
LRLR
```

Output
```
5
```
