# CF-1106A Lunar New Year and Cross Counting

## 题面快照

## Description

在一个 $n \times n$ 的地图中寻找有几个图案，满足

$M(i,j)=M(i-1,j-1)=M(i-1,j+1)=M(i+1,j-1)=M(i+1,j+1)=X$

形似下图。
```
X.X
.X.
X.X
```
如果图案中心所在位置不同即视作不同。

## Input

第一行正整数 $n (1 \le n \le 500)$，表示地图的大小。
接下来 $n$ 行每行 $n$ 个字符，只包含 **'X' 或 '.'**。

## Output

一行一个整数 $k$ 表示图案个数。

## Samples

### Sample 1

Input
```
5
.....
.XXX.
.XXX.
.XXX.
.....
```

Output
```
1
```

### Sample 2

Input
```
2
XX
XX
```

Output
```
0
```

### Sample 3

Input
```
6
......
X.X.X.
.X.X.X
X.X.X.
.X.X.X
......
```

Output
```
4
```
