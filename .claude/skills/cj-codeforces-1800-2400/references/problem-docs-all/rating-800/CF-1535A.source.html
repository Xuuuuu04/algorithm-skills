CF1535A Fair Playoff

题目描述

有四名选手参加季后赛锦标赛。比赛按照以下方式进行：第一名选手与第二名选手比赛，第三名选手与第四名选手比赛，然后两组的获胜者将在决赛中对决。 已知在两名选手的比赛中，技能值更高的选手获胜。第 $i$ 名选手的技能值为 $s_i$，并且所有技能值两两不同（即数组 $s$ 中没有两个相同的值）。 如果技能值最高的两名选手在决赛中相遇，则称该锦标赛是公平的。 请判断给定的锦标赛是否公平。

输入格式

第一行包含一个整数 $t$（$1 \le t \le 10^4$），表示测试用例的数量。 每个测试用例占一行，包含四个整数 $s_1, s_2, s_3, s_4$（$1 \le s_i \le 100$），表示四名选手的技能值。保证这四个数各不相同。

输出格式

对于每个测试用例，如果锦标赛公平，输出 YES，否则输出 NO。

说明/提示

例如： 1. 在第一个测试用例中，技能值为 $7$ 和 $9$ 的第 2 名和第 3 名选手进入决赛； 2. 在第二个测试用例中，技能值为 $5$ 和 $9$ 的第 2 名和第 4 名选手进入决赛。技能值为 $6$ 的选手未进入决赛，但技能值为 $5$ 的选手进入了决赛，因此该锦标赛不公平； 3. 在第三个测试用例中，技能值为 $5$ 和 $8$ 的第 1 名和第 3 名选手进入决赛； 4. 在第四个测试用例中，技能值为 $6$ 和 $3$ 的第 1 名和第 3 名选手进入决赛。技能值为 $5$ 的选手未进入决赛，但技能值为 $3$ 的选手进入了决赛，因此该锦标赛不公平。 由 ChatGPT 4.1 翻译
