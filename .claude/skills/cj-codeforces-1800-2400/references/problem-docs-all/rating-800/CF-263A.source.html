题目描述

你有一个 $5\times5$ 的矩阵，这个矩阵由 $24$ 个零和一个一组成。我们将矩阵的行从上到下编号为 $1$ 到 $5$，将矩阵的列从左到右编号为 $1$ 到 $5$。每次操作，你可以对矩阵进行以下两种变换之一： 1. 交换相邻的两行，即交换编号为 $i$ 和 $i+1$ 的两行，其中 $1\leq i < 5$。 2. 交换相邻的两列，即交换编号为 $j$ 和 $j+1$ 的两列，其中 $1\leq j < 5$。 当矩阵中唯一的一个 $1$ 位于中间位置（第三行第三列，即第 $3$ 行与第 $3$ 列的交点）时，我们认为这个矩阵是“美丽的”。请你计算，将矩阵变为美丽状态所需的最少操作次数。

输入格式

输入包含五行，每行包含五个整数：输入的第 $i$ 行第 $j$ 个整数表示矩阵中第 $i$ 行第 $j$ 列的元素。保证矩阵中有且只有一个 $1$，其它位置均为 $0$。

输出格式

输出一个整数，表示将矩阵变为美丽所需的最小操作次数。
