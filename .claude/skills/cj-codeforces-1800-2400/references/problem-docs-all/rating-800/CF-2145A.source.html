CF2145A Candies for Nephews

题目描述

Monocarp 有三个侄子。新年快到了，Monocarp 有 $n$ 颗糖果要送给他的侄子们。 为了确保没有哪个侄子被冷落，Monocarp 想要让每个侄子都分到相同数量的糖果。 请你计算，Monocarp 至少还需要再买多少颗糖果，这样他才能把糖果均分给三个侄子。需要注意的是，Monocarp 最初拥有的所有 $n$ 颗糖果都要分给侄子们。

输入格式

第一行包含一个整数 $t$（$1 \le t \le 100$），表示测试用例的数量。 每个测试用例包含一行，一个整数 $n$（$1 \le n \le 100$），表示 Monocarp 最初拥有的糖果数。

输出格式

对于每个测试用例，输出一个整数，表示 Monocarp 至少还需要再买多少颗糖果，这样才能将糖果均分给三个侄子。

说明/提示

在第一个样例中，Monocarp 还需再买 $2$ 颗糖果。增加后，他将拥有 $9$ 颗糖果，可以给每个侄子分 $3$ 颗。 在第二个样例中，Monocarp 不需要再买任何糖果，因为他原本就有 $24$ 颗糖果，可以每个侄子分 $8$ 颗。 由 ChatGPT 5 翻译
