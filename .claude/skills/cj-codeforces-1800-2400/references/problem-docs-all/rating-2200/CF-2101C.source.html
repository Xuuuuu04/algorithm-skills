多组数据，第一行一个整数 $t(1\le t\le 10^4)$ 表示数据组数。 对于每组数据：\ 第一行一个整数 $n(1\le n\le 2\times 10^5)$。\ 第二行 $n$ 个整数 $a_1,a_2,\cdots,a_n(1\le a_i\le n)$。 保证单个测试点中 $\sum n\le 2\times 10^5$。
