# CF-622E Ants in Leaves

## 题面快照

## Description

给定一棵 $n$ 个节点的树，根节点是 $1$。这棵树的每一个叶节点都有一只小蚂蚁。每过 $1$ 秒钟，可以选择让一些蚂蚁向父节点走一步。注意，除根节点外，两只蚂蚁不能同时在同一节点上。

问最少用多少秒的时间，使得所有蚂蚁都走到根节点。

## Input

第一行输入一个整数 $n$（$2 \le n \le 5\times10^5$）。

接下来 $(n-1)$ 行每行两个整数 $x_i, y_i$（$1 \le x_i,y_i \le n$），表示节点 $x_i, y_i$ 间有一条边。数据保证给定的边组成一颗合法的树。

## Output

输出一个整数 $t$，表示答案。
