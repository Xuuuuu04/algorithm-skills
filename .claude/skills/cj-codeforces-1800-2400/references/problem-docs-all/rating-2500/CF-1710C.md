# CF-1710C XOR Triangle

## 题面快照

## Description

给你一个数 $n$，问：有多少对数 $0\leq a,b,c \leq n$ 满足 $a \oplus b,b \oplus c,a \oplus c$  。三个数字构成了一个非退化三角形，也就是两条短边之和大于第三边的长度。$\oplus$ 表示二进制下的异或操作。

## Input

一个数字 $n$，表示给定的 $n$ 在二进制下的表示。

## Output

输出答案 $\bmod 998244353$。

## Samples

### Sample 1

Input
```
101
```

Output
```
12
```

### Sample 2

Input
```
1110
```

Output
```
780
```

### Sample 3

Input
```
11011111101010010
```

Output
```
141427753
```

## Note

$0 < n < 2^{200000}$。
