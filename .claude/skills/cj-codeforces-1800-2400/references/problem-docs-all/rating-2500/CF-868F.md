# CF-868F Yet Another Minimization Problem

## 题面快照

## Description

给定一个序列 $a$，要把它分成 $k$ 个子段。每个子段的费用是其中相同元素的对数。求所有子段的费用之和的最小值。

## Input

第一行输入 $n$（序列长度）和 $k$（需分子段数）。接下来一行有 $n$ 个数，第 $i$ 个数表示序列的第 $i$ 个元素 $a_i$。

## Output

输出一个数，费用和的最小值。

## Samples

### Sample 1

Input
```
7 3
1 1 3 3 3 2 1
```

Output
```
1
```

### Sample 2

Input
```
10 2
1 2 1 2 1 2 1 2 1 2
```

Output
```
8
```

### Sample 3

Input
```
13 3
1 2 2 2 1 2 1 1 1 2 2 1 1
```

Output
```
9
```

## Note

$2 \leq n \leq 10^5$，$2 \leq k \leq \min(n,20)$，$1 \leq a_i \leq n$ 。
