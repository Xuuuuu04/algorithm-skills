CF2026E Best Subsequence

题目描述

给定一个长度为 $n$ 的整数数组 $a$。 我们将数组的“值”定义为：数组的长度减去数组所有元素按位或的结果中 1 的个数。 例如，对于数组 $[1, 0, 1, 2]$，按位或的结果为 $3$（其中包含 $2$ 个 1），因此该数组的值为 $4-2=2$。 你的任务是计算给定数组的某个子序列可能获得的最大值。

输入格式

第一行包含一个整数 $t$（$1 \le t \le 100$），表示测试用例的数量。 每个测试用例的第一行包含一个整数 $n$（$1 \le n \le 100$）。 每个测试用例的第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$（$0 \le a_i < 2^{60}$）。

输出格式

对于每个测试用例，输出给定数组的某个子序列可能获得的最大值。
