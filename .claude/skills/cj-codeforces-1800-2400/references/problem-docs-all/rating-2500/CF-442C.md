# CF-442C Artem and Array

## 题面快照

## Description

给定长度为 $n$ 的数组 $a$ ，你需要进行 $n$ 次操作：删去某一元素 $a_i$ ，并获得 $\min\{a_{i-1}, a_{i+1}\}$ 的分数。若不存在 $a_{i-1}$ 或 $a_{i+1}$，则此次操作不得分。

请你计算至多能得到多少分。

## Input

两行：第一行一个数 $n$ ；第二行 $n$ 个数，第 $i$ 个数为 $a_i$

## Output

一行共一个数，表示最大得分。

【数据规模】

$1\leq n \leq 5*10^5$

$1 \leq a_i \leq 10^6$

## Samples

### Sample 1

Input
```
5
3 1 5 2 6
```

Output
```
11
```

### Sample 2

Input
```
5
1 2 3 4 5
```

Output
```
6
```

### Sample 3

Input
```
5
1 100 101 100 1
```

Output
```
102
```
