# CF-710D Two Arithmetic Progressions

## 题面快照

## Description

给你两个等差数列 $a_1k+b_1$ 和 $a_2l+b_2$。找出满足 $L\le x\le R$ 且存在 $k',l'\ge0$ 满足 $x=a_1k'+b_1=a_2l'+b_2$ 的整数 $x$ 的个数。

## Input

一行六个整数 $a_1,b_1,a_2,b_2,L,R(0<a_1,a_2\le 2\times 10^9,-2\times 10^9\le b_1,b_2,L,R\le 2\times 10^9,L\le R)$。

## Output

一行一个整数，表示满足条件的 $x$ 的个数。

## Samples

### Sample 1

Input
```
2 0 3 3 5 21
```

Output
```
3
```

### Sample 2

Input
```
2 4 3 0 6 17
```

Output
```
2
```
