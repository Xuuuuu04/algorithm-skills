# CF-336A Vasily the Bear and Triangle

## 题面快照

## Description

熊 Vasily 有一个最喜欢的矩形，这个矩形有一个顶点在点 $(0,0)$，对角顶点在点 $(x,y)$。当然，这个最喜欢的矩形的边都是平行于坐标轴的。

Vasya 也很喜欢三角形，尤其是那些有一个顶点在点 $B=(0,0)$ 的三角形。因此，今天他要求你找到两个点 $A=(x_{1},y_{1})$ 和 $C=(x_{2},y_{2})$，使得满足以下条件：

- 两点的坐标 $x_{1}$、$x_{2}$、$y_{1}$、$y_{2}$ 均为整数，并且满足不等式 $x_{1}<x_{2}$；
- 由 $A$、$B$、$C$ 形成的三角形是直角等腰三角形（![](https://cdn.luogu.com.cn/upload/vjudge_pic/CF336A/722fcc24f0ddfe8fedfe378a89e62bfed7c996ca.png) 示意图）；
- 最喜欢的矩形的所有点都位于三角形 $ABC$ 内部或边界上；
- 三角形 $ABC$ 的面积应尽可能小。

请帮助熊找到符合条件的点。这些点的选择是唯一的，证明这一点并不困难。

## Input

第一行包含两个整数 $x$ 和 $y$（$-10^{9} \leq x, y \leq 10^{9},\ x \neq 0,\ y \neq 0$）。

## Output

在一行中输出四个整数 $x_{1}$、$y_{1}$、$x_{2}$、$y_{2}$，即所需点的坐标。

## Samples

### Sample 1

Input
```
10 5
```

Output
```
0 15 15 0
```

### Sample 2

Input
```
-10 5
```

Output
```
-15 0 0 15
```
