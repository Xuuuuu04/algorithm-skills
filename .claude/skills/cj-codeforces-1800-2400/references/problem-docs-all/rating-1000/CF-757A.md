# CF-757A Gotta Catch Em' All!

## 题面快照

## Description

Bash 希望有一天能成为宝可梦大师。虽然他喜欢很多宝可梦，但他一直最着迷妙蛙种子。很快，事情变得严肃起来，他的迷恋变成了痴迷。由于他太小，还不能外出捕捉妙蛙种子，所以他想出了自己“捕捉”妙蛙种子的方法。

每天，他拿起报纸的头版，把上面任意位置的字母一个个剪下来，拼成单词“Bulbasaur”（不包含引号），并把它粘在墙上。Bash 对大小写非常讲究——“Bulbasaur”的第一个字母必须大写，其余字母必须小写。每做一次，他就认为自己“捕捉”到了一只妙蛙种子。然后他用剩下的报纸继续这个步骤。只要还能拼出“Bulbasaur”，他就一直这样做。

给定报纸头版上的全部文本，请你告诉 Bash 今天他最多能“捕捉”多少只妙蛙种子？

注意：大写和小写字母视为不同的字母。

## Input

输入包含一行字符串 $s$（$1 \leq |s| \leq 10^{5}$），表示报纸头版上的文本，没有空格和标点符号。$|s|$ 表示字符串 $s$ 的长度。

字符串 $s$ 只包含小写和大写英文字母。

## Output

输出一个整数，表示最多可以“捕捉”多少只妙蛙种子。

## Samples

```
Bulbbasaur
```

Output

```
1
```

```
F
```


## Note

第一组样例中，你可以选出：Bulbbasaur。

第二组样例中，无法选出哪怕一只妙蛙种子。

第三组样例中，你可以将字符串重排为 BulbasaurBulbasauraddrgndgddgargndbb，从而可以拼出两个“Bulbasaur”。
