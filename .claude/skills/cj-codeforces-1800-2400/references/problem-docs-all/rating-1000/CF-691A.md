# CF-691A Fashion in Berland

## 题面快照

## Description

根据伯兰德时装的规则，夹克除了一个钮扣外，所有的钮扣都应该扣紧，但不一定是最后一个。另外，如果夹克只有一个按钮，它应该紧固，这样夹克就不会摆动打开。

给你一件夹克的纽扣。确定它是否以正确的方式固定。

## Input

第一行包含整数 $n$ $(1\le n\le 1000)$，$n$ 是外套上的按钮数。

第二行包含 $n$ 个整数 $a_i$。如果第 $i$ 个按钮没有紧固，则数字 $a_i=0$。否则 $a_i=1$。

## Output

输出只有一行。如果夹克是正确的方式紧固，在一行内输出 ```YES``` 。否则输出 ```NO``` 。

## Samples

### Sample 1

Input
```
3
1 0 1
```

Output
```
YES
```

### Sample 2

Input
```
3
1 0 0
```

Output
```
NO
```
