输入格式

每个测试包含多个测试用例。第一行包含测试用例数量 $t$（$1 \le t \le 10^3$）。接下来描述各个测试用例。 每个测试用例： - 第一行包含一个整数 $n$（$2 \le n \le 5000$）——好对的数量。 - 接下来 $n$ 行，每行包含两个整数 $l_i$ 和 $r_i$，表示第 $i$ 条线索（$1 \le l_i < r_i \le 2n$）。 同一测试用例中的线索互不相同且互不矛盾。 保证所有测试用例的 $n$ 之和不超过 $5000$。

输出格式

对于每个测试用例，输出一行 $n+1$ 个整数： - 第一个整数表示未接收任何线索前的答案，对 $998\,244\,353$ 取模。 - 对于所有 $i \ge 1$，第 $i+1$ 个整数表示接收前 $i$ 条线索后的答案，对 $998\,244\,353$ 取模。

说明/提示
